Docker и сервисы

Поднимаем всю инфраструктуру одной командой: PostgreSQL, Redis, Qdrant, MinIO. После этого этапа у тебя работающие БД, готовые принять данные.

Section 01Что мы поднимаем

Каждый сервис — изолированный контейнер Docker. Можно перезапустить, обновить, удалить отдельно, не трогая остальное.

Service 01 / Database

PostgreSQL 16

Основная реляционная БД. Хранит клиентов, диалоги, сообщения, действия, аналитику.

PORT 5432 (внутренний)
Service 02 / Cache & Queue

Redis 7

Кеш и брокер очередей Celery. Через него агенты получают задачи на обработку сообщений.

PORT 6379 (внутренний)
Service 03 / Vector DB

Qdrant

Векторная база для RAG. Хранит embeddings базы знаний, по которым ищут агенты.

PORT 6333 (внутренний)
Service 04 / Object Storage

MinIO (S3-совместимое)

Хранение аудио, видео-кружочков, скриншотов. API совместим с AWS S3 — позже легко мигрировать.

PORT 9000 + 9001 (внутренний)

Section 02Установка Docker

Подключись к серверу: ssh aisales@твой-ip.

01
Удаляем старые версии
2 мин

На свежей Ubuntu могут быть старые пакеты Docker. Убираем:

sudo apt remove docker docker-engine docker.io containerd runc -y

Может вывести «not installed» — это нормально.

02
Зависимости
3 мин
sudo apt update sudo apt install -y ca-certificates curl gnupg lsb-release
03
GPG-ключ Docker
2 мин
sudo install -m 0755 -d /etc/apt/keyrings curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg sudo chmod a+r /etc/apt/keyrings/docker.gpg
04
Репозиторий Docker
2 мин

Одной строкой, скопируй полностью:

echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
05
Установка Docker Engine
5 мин
sudo apt update sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
06
Запускаем Docker без sudo
3 мин

Чтобы не писать sudo перед каждой командой docker:

sudo usermod -aG docker $USER

Переподключись по SSH (выйди и зайди снова), чтобы группы применились:

exit # на Маке снова: ssh aisales@твой-ip
07
Проверка
2 мин
docker --version docker compose version docker run hello-world

Последняя команда скачает тестовый контейнер и напечатает «Hello from Docker». Если так — всё работает.

Проверка: docker run hello-world выводит приветствие без ошибок.

Section 03Структура проекта

Создаём папки и конфиги для платформы.

08
Папка проекта
2 мин
mkdir -p ~/aisales cd ~/aisales mkdir -p data/postgres data/redis data/qdrant data/minio

Так выглядит структура:

~/aisales/ ├── docker-compose.yml # создадим дальше ├── .env # секреты └── data/ ├── postgres/ # данные БД ├── redis/ ├── qdrant/ └── minio/
09
Файл .env с секретами
5 мин

Сгенерируем сильные пароли. Выполни на сервере:

openssl rand -base64 24 # повтори 4 раза, получишь 4 разных пароля

Создай файл .env:

nano ~/aisales/.env

Вставь содержимое (вместо PASTE_HERE — твои сгенерированные пароли):

# PostgreSQL POSTGRES_USER=aisales POSTGRES_PASSWORD=PASTE_HERE_1 POSTGRES_DB=aisales # Redis REDIS_PASSWORD=PASTE_HERE_2 # Qdrant QDRANT_API_KEY=PASTE_HERE_3 # MinIO MINIO_ROOT_USER=aisales MINIO_ROOT_PASSWORD=PASTE_HERE_4

Сохрани: Ctrl+O → Enter → Ctrl+X.

Сохрани .env в безопасное место (например, в твой менеджер паролей). Если потеряешь — потеряешь доступ к БД.

Section 04docker-compose.yml

Главный файл — описывает все сервисы. Запускается одной командой.

10
Создаём docker-compose.yml
10 мин
nano ~/aisales/docker-compose.yml

Вставь полностью этот блок:

services: postgres: image: postgres:16-alpine container_name: aisales-postgres restart: unless-stopped environment: POSTGRES_USER: ${POSTGRES_USER} POSTGRES_PASSWORD: ${POSTGRES_PASSWORD} POSTGRES_DB: ${POSTGRES_DB} volumes: - ./data/postgres:/var/lib/postgresql/data ports: - "127.0.0.1:5432:5432" healthcheck: test: ["CMD-SHELL", "pg_isready -U ${POSTGRES_USER}"] interval: 10s timeout: 5s retries: 5 networks: - aisales-net redis: image: redis:7-alpine container_name: aisales-redis restart: unless-stopped command: redis-server --requirepass ${REDIS_PASSWORD} --appendonly yes volumes: - ./data/redis:/data ports: - "127.0.0.1:6379:6379" healthcheck: test: ["CMD", "redis-cli", "-a", "${REDIS_PASSWORD}", "ping"] interval: 10s timeout: 5s retries: 5 networks: - aisales-net qdrant: image: qdrant/qdrant:latest container_name: aisales-qdrant restart: unless-stopped environment: QDRANT__SERVICE__API_KEY: ${QDRANT_API_KEY} volumes: - ./data/qdrant:/qdrant/storage ports: - "127.0.0.1:6333:6333" - "127.0.0.1:6334:6334" networks: - aisales-net minio: image: minio/minio:latest container_name: aisales-minio restart: unless-stopped command: server /data --console-address ":9001" environment: MINIO_ROOT_USER: ${MINIO_ROOT_USER} MINIO_ROOT_PASSWORD: ${MINIO_ROOT_PASSWORD} volumes: - ./data/minio:/data ports: - "127.0.0.1:9000:9000" - "127.0.0.1:9001:9001" healthcheck: test: ["CMD", "curl", "-f", "http://localhost:9000/minio/health/live"] interval: 30s timeout: 10s retries: 3 networks: - aisales-net networks: aisales-net: driver: bridge
Все порты привязаны к 127.0.0.1 — это значит, что сервисы доступны только изнутри сервера, не торчат в интернет. Это критично для безопасности.

Section 05Запуск

11
Первый старт
5 мин
cd ~/aisales docker compose up -d

Флаг -d — запуск в фоне. Скачаются образы (~500 МБ), создадутся контейнеры. Подожди 1–2 минуты.

12
Проверка статусов
2 мин
docker compose ps

Должны быть 4 строки со статусом running и healthy (у тех, где есть healthcheck).

Логи если что-то странное:

docker compose logs postgres docker compose logs redis docker compose logs qdrant docker compose logs minio

Section 06Проверка каждого сервиса

Подключаемся к каждой БД и убеждаемся, что работает.

13
PostgreSQL
3 мин
docker exec -it aisales-postgres psql -U aisales -d aisales

Зайдёшь в консоль БД. Проверь:

SELECT version(); \q

Должна напечатать версию PostgreSQL 16.x. \q — выход.

14
Redis
2 мин
docker exec -it aisales-redis redis-cli

В redis-cli:

AUTH "твой_REDIS_PASSWORD_из_env" PING exit

На PING должен ответить PONG.

15
Qdrant
2 мин

Проверь через curl:

curl -H "api-key: твой_QDRANT_API_KEY" http://localhost:6333/collections

Должен вернуть JSON с пустым массивом коллекций. Это норма — коллекции создадим позже.

16
MinIO
3 мин

MinIO имеет веб-консоль. Чтобы попасть в неё с Мака, открой SSH-туннель:

В новом окне Терминала на Маке:

ssh -L 9001:localhost:9001 aisales@твой-ip

Затем в браузере на Маке: http://localhost:9001

Зайди с логином aisales и паролем из MINIO_ROOT_PASSWORD. Должна открыться панель.

Создай первый bucket: «Buckets» → «Create Bucket» → имя aisales-media.

Все 4 сервиса работают. У тебя готовая инфраструктура для агентов: реляционная БД, кеш-очередь, векторная БД и хранилище файлов.

Section 07Управление

Команды, которые понадобятся в работе.

Запустить всёdocker compose up -d
Остановитьdocker compose stop
Перезапуститьdocker compose restart
Удалить + данныеdocker compose down -v
Логи в реальном времениdocker compose logs -f
Статусdocker compose ps
Использование ресурсовdocker stats
Никогда не запускай down -v без бэкапа — это удалит все данные. Команда down без -v безопасна, она только останавливает.

Section 08Бэкапы

Раз в сутки автоматически бэкапим БД.

17
Скрипт бэкапа
5 мин
nano ~/aisales/backup.sh

Вставь:

#!/bin/bash DATE=$(date +%Y%m%d_%H%M%S) BACKUP_DIR=~/aisales/backups mkdir -p $BACKUP_DIR docker exec aisales-postgres pg_dump -U aisales aisales | gzip > $BACKUP_DIR/postgres_$DATE.sql.gz find $BACKUP_DIR -name "postgres_*.sql.gz" -mtime +30 -delete echo "Backup done: postgres_$DATE.sql.gz"

Сделай исполняемым:

chmod +x ~/aisales/backup.sh ~/aisales/backup.sh

Проверь, что файл появился:

ls -lh ~/aisales/backups/
18
Cron — автозапуск
3 мин
crontab -e

Если спросит редактор — выбери nano (вариант 1). В конец файла добавь:

0 3 * * * /home/aisales/aisales/backup.sh >> /home/aisales/aisales/backups/backup.log 2>&1

Это значит «каждый день в 3:00 ночи». Сохрани и выйди.

Позже добавим выгрузку бэкапов на S3 — пока хватит локальных. Они хранятся 30 дней, потом старые удаляются автоматически.
