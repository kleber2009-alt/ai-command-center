# 🎙️ Voice Input · подкасты для анализа

**Что это:** место куда ты складываешь свои аудиоподкасты, я их транскрибирую и извлекаю твой голос/стиль/смыслы для всей системы.

---

## Workflow

```
1. audio/        ← ты кладёшь сюда .mp3/.m4a/.mp4 файлы
   ↓
2. transcripts/  ← скрипт создаёт здесь .txt и .srt
   ↓
3. analysis/     ← я анализирую → JSON со структурой
   ↓
4. → agent-prompts/ + Notion (через MCP)
```

---

## Шаг 1 · Как достать аудио из Telegram

### Если это голосовые сообщения / TG-подкаст с малого количеством файлов
Самый простой способ:

1. Открой **Telegram Desktop** (не мобильный)
2. Найди голосовое / аудио сообщение
3. Правая кнопка → **«Сохранить как...»** (Save As)
4. Сохрани в `~/ai-sales-system/voice-input/audio/`

### Если у тебя свой подкаст в TG-канале с многими эпизодами
Используй встроенный экспорт:

1. Telegram Desktop → открой канал
2. ⋮ (три точки в правом верхнем углу) → **Export chat history**
3. Включи **Voice messages** + **Audio files** в чекбоксах
4. **Format:** Machine-readable JSON (или HTML, неважно)
5. **Path:** укажи `~/ai-sales-system/voice-input/audio/` (или экспортируй куда удобно и потом перетащи)
6. **Size limit:** убери — пусть выгрузит всё
7. Жми Export — займёт пару минут

После экспорта внутри созданной папки найди подпапку `voice_messages/` или `audio/` — оттуда перетащи `.ogg`/`.mp3`/`.m4a` файлы в `~/ai-sales-system/voice-input/audio/`.

### Если хочешь только конкретные эпизоды
Прямо в Telegram Desktop → переадресуй (forward) аудио себе в «Избранное» (Saved Messages), оттуда удобнее качать пачкой.

## Шаг 2 · Транскрипция (для тебя — одна команда)

```bash
cd ~/ai-sales-system/code
source venv/bin/activate
python -m utils.voice_transcribe
```

Скрипт сам:
- Найдёт все аудиофайлы в `voice-input/audio/`
- Транскрибирует через локальный whisper (модель `medium`, русский язык)
- Создаст `.txt` и `.srt` файлы в `voice-input/transcripts/`
- Не транскрибирует то, что уже было обработано (резюмируемая работа)

**Время:** на M1/M2 Mac — примерно ~0.3-0.5x от длительности аудио. То есть 1 час аудио = 20-30 минут обработки. Можешь запустить и пить кофе.

**Опции:**

```bash
# Изменить модель (small = быстро, medium = баланс, large-v3 = точнее)
python -m utils.voice_transcribe --model small

# Конкретный файл
python -m utils.voice_transcribe --file podcast-01.mp3

# Английский язык
python -m utils.voice_transcribe --lang en
```

## Шаг 3 · Анализ (это делаю я)

После того как у тебя в `voice-input/transcripts/` появятся `.txt` файлы — напиши мне «транскрипты готовы». Я:

1. Прочитаю их через Read
2. Извлеку:
   - **Identity**: кто ты, чем занимаешься, кому продаёшь
   - **Voice**: тон, любимые обороты, запретные слова
   - **Values**: что для тебя важно
   - **Red lines**: чего никогда не делаешь
   - **Products**: что и за сколько (если упоминал)
   - **Cases**: реальные истории клиентов
   - **Objections**: возражения, на которые ты отвечал в подкасте
3. Сохраню структуру в `voice-input/analysis/voice-profile.json`
4. Заполню `[ПЛЕЙСХОЛДЕРЫ]` в промптах агентов
5. Заведу записи в Notion через MCP
6. Покажу тебе draft → ты подтверждаешь / правишь

## Troubleshooting

**«No module named 'faster_whisper'»** — venv не активирован. Запусти `source ~/ai-sales-system/code/venv/bin/activate`.

**Очень медленно** — попробуй модель `small` или `tiny`. Качество чуть хуже, но в 3-5 раз быстрее.

**Транскрипт перепутал слова** — это нормально для модели `small`. Перезапусти на `medium` или `large-v3`.

**Audio formats** — поддерживаются: mp3, m4a, mp4, ogg, wav, flac. Если что-то другое — конвертируй через `ffmpeg` или онлайн.
