# 🎬 Reels — система производства

**Версия:** v1.0 · 15 мая 2026
**Назначение:** сценарии Reels с раскадровкой, тайминги, монтажные планы

---

## Что здесь

3 готовых сценария Reels:
- `reel-01-hook-revelation.html` — формат «провокация в hook → раскрытие» (60s)
- `reel-02-tutorial.html` — мини-обучение, 3 шага (75s)
- `reel-03-case-talking-head.html` — Илья говорит на камеру про кейс (90s)

Каждый файл — это **сценарий с раскадровкой** (storyboard) и тайминг-планом. Не готовое видео.

---

## Связка процесса (для будущей автоматизации)

1. **Идея** ← из контент-памяти / темы клиентов / трендов
2. **Сценарий** ← AI генерирует по шаблону из этой папки
3. **Раскадровка** ← HTML-визуализация каждого кадра с таймингом
4. **Озвучка** ← ElevenLabs PVC по сценарию (когда будет готов)
5. **Видеомонтаж** ← 
   - Вариант A: вручную в CapCut/Premiere по раскадровке
   - Вариант B: Wav2Lip + AI-генерация B-roll
   - Вариант C: запись Ильи + AI-монтаж по разметке
6. **Субтитры** ← Whisper API auto
7. **Hook-тест** ← первые 3 секунды → CTR анализ
8. **Публикация** ← IG API + TG канал

## Правила хороших Reels (для агента, который их будет писать)

### Длина
- **15-30s** — для viral hook content (одна мысль)
- **45-60s** — обучающий контент
- **60-90s** — глубокий разбор / кейс
- **никогда** >90s — конверсия падает катастрофически

### Hook (первые 3 секунды)
**Цель:** заставить пальцем НЕ свайпать.

Хорошие hook-приёмы:
- Цифра + неожиданность: «Я уволил 4 сотрудников. И вырос на 30%»
- Прямой вызов: «Если ты делаешь N — ты теряешь деньги»
- Контрастная установка: «Все говорят X. На самом деле — Y»
- Личный момент: «3 года назад я был банкрот»
- Вопрос с интригой: «Почему 80% агентств умирают на 2-м году?»

Плохие hooks:
- ❌ «Привет, меня зовут...»
- ❌ «Сегодня поговорим о...»
- ❌ «Ребят, я тут подумал...»

### Структура
1. **Hook** (0-3s) — зацепить
2. **Tease** (3-10s) — пообещать что узнают
3. **Body** (10-50s) — суть, разбитая на блоки по 7-12s
4. **Climax** (50-60s) — главный инсайт / поворот
5. **CTA** (60-75s) — что сделать («сохрани», «напиши X в директ», «следи за каналом»)

### Visual
- Talking head — только если есть **сильная личность** или сильный сценарий
- B-roll должен меняться **каждые 3-5 секунд** — иначе скролл
- Subtitles **обязательны** — 85% смотрят без звука
- Subtitles стиль: моноширинный шрифт, белый текст на тёмном bg, не «забавный кейс»

### Audio
- Голос **громче музыки на 12-15 dB**
- Музыка — на тренде, но не «кринж-trending»
- Звуковые акценты (whoosh, ding) на смене блоков — улучшают retention
