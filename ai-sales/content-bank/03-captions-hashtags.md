## 📜 Структура подписи для IG-карусели

Идеальная подпись = **4 блока × 60-80 слов = 280 слов**.

### Блок 1 — HOOK (1-2 строки, без точки в конце)

Зеркалит хук на первом слайде. Если первый слайд: «3 часа в день. Впустую.» — то подпись начинается:

```
3 часа в день — вот сколько съедает ручной постинг у среднего агентства.

И самое обидное — большинство этого вообще не считает.
```

### Блок 2 — PROBLEM (3-5 строк)

Разворачиваешь боль. Лично, на уровне опыта.

```
Сам ходил по этой дорожке. У клиента 8 проектов — на каждый
2 поста в неделю — это 16 публикаций. Контент-план,
тексты, верстка в Canva, планирование. И так каждую неделю.
Месяц. Год.

73% этой работы — повторяющиеся действия.
```

### Блок 3 — SOLUTION / SHIFT (3-5 строк)

Что изменилось когда нашёл другой подход.

```
Что сработало — не «нанять SMM-щика», не «купить Buffer».

Сработала система, которая знает каждого моего клиента,
пишет в его стиле, планирует контент-план и постит вовремя.

Не «AI-помощник». А полноценная замена SMM-отдела.
Один пакет на 10 клиентов параллельно.
```

### Блок 4 — CTA (1-2 строки + хэштеги)

Конкретное действие. Сохрани / поделись / напиши в директ.

```
Если работаешь с агентскими клиентами — листай слайды,
там разобрал детальнее.

Напиши «SMM» в директ — пришлю кейс и расчёт под твою ситуацию.
```

## 🎬 Структура подписи для Reel

Короче — потому что меньше места в IG (или используется как заголовок в TG-канале).

```
[1 строка — повтор хука или его перефраз]

[2-3 строки — суть в которые ушло видео, без спойлеров]

[CTA: «Сохрани, если узнал себя.»]

[5-7 хэштегов]
```

**Пример:**
```
Уволил 4 продажников. И за 2 месяца вырос на 30%.

Не потому что они плохие. А потому что я понял три вещи
про продажи, которые делают наёмников ненужными.

Если хочешь узнать как — напиши «AI» в директ.

#автоматизацияSMM #отделпродаж #AIагенты
#маркетинг #предпринимательство
```

## 📱 Структура подписи для TG-канала

В Telegram длинные подписи ОК. Можно полностью развернуть мысль.

```
[ЖИРНЫЙ ЗАГОЛОВОК — повтор хука]

[3-5 абзацев, по 2-4 строки]

[Личный комментарий / опыт]

[Призыв к действию + ссылка]

P.S. [приписка с человеческой нотой]
```

**Markdown в TG:**
- `*жирный*` — для акцента
- `_курсив_` — для цитат
- ``` ``` — для блоков
- Списки с эмодзи ✅ работают

## 📊 Стратегия использования хэштегов

**Правило 70/20/10:**
- 70% — нишевые, низкоконкурентные (твой сегмент)
- 20% — средне-конкурентные (твоя широкая ниша)
- 10% — хайповые/трендовые (для discovery)

**Количество:**
- IG посты: 8-15 хэштегов (Instagram оптимизирует под 8-15 в 2026)
- IG карусели: 8-12 в посте + 5-7 в первом комменте
- Reels: 3-5 в подписи (больше — выглядит спамом)
- TG: 1-3 (не больше, иначе кажется накруткой)

## ✏️ Шаблон подписи под каждый тип контента

### Шаблон 1 — Carousel «Pain/Solution»

```
[HOOK — повтор первого слайда, 1-2 строки]

[PROBLEM — личный опыт боли, 3-5 строк]

[REVELATION — что я понял, 2-3 строки]

[SOLUTION — что сработало, 2-3 строки]

[CTA — листай слайды + DM]

[8-12 хэштегов]
```

### Шаблон 2 — Carousel «Case Study»

```
[HOOK — цифра-результат]

[CONTEXT — кто клиент, в чём была проблема]

[WHAT WE DID — 1-2 предложения, без раскрытия деталей]

[RESULT — что получили]

[QUOTE — короткая цитата клиента]

[CTA — «хочешь так же — напиши КЕЙС»]

[8-12 хэштегов]
```

### Шаблон 3 — Reel «Hook Reveal»

```
[ХУК — повтор первой строки в видео]

[НАМЁК на что узнаешь — 2-3 строки]

[CTA — «сохрани» или «DM "X"»]

[3-5 хэштегов]
```

### Шаблон 4 — Reel «Tutorial»

```
[ХУК — что узнаешь]

[ЧТО ВНУТРИ — 3 буллета]

[CTA — «сохрани» обязательно для tutorial]

[3-5 хэштегов]
```

### Шаблон 5 — POST «Opinion / Manifesto»

```
[ЗАГОЛОВОК-ПРОВОКАЦИЯ]

[ТЕЗИС в 1 строке]

[АРГУМЕНТ 1, 2, 3 — каждый абзац 3-4 строки]

[ВЫВОД — твоя позиция]

[Открытый вопрос — стимулирует комментарии]

[5-8 хэштегов]
```

## 🎯 CTA — банк формулировок

**Прямой:**
- Напиши «X» в директ
- Открой ссылку в шапке
- Запишись на созвон по ссылке

**Мягкий:**
- Сохрани этот пост на потом
- Покажи команде
- Дай знать в комментариях — было полезно?

**Engagement:**
- А ты как считаешь? — пиши в комменты
- Поделись с тем, кому это нужно
- Какой пункт удивил больше всего?

**Lead-gen:**
- В директ — пришлю PDF
- Напиши «КЕЙС» — расскажу детали
- DM «AUDIT» — сделаю быстрый разбор твоего IG

## 🤖 AI-генератор подписей (будущее)

```
Дано:
- Контент: [идея, тип, шаблон]
- Голос: [load from БЗ]
- Сегмент: [A/B/C]
- Длина: [короткая / средняя / длинная]

Сгенерируй:
1. Подпись в нужном шаблоне
2. 3 варианта CTA
3. Подобранные хэштеги (8-12 для IG, 3-5 для Reel)

Не используй:
- Канцеляризмы
- «Дорогие подписчики»
- Эмодзи >2 на пост
```
