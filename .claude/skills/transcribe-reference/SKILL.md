# Транскрибатор

Первый шаг работы с референсом: ссылка на ролик (свой или конкурента) → текст, который дальше
берут агенты контента (сценарии, карусели, аватар, Threads, анализ аудитории).

## Как запустить

```bash
python3 ~/.claude/skills/transcribe-reference/scripts/transcribe_ref.py "<ссылка или файл>" [ещё до 4] --out out/
```

- В `--out` появятся `transcript-<n>.md` (для людей и агентов) и `transcript-<n>.json` (со словами и таймкодами).
- Последняя строка вывода — JSON с итогом; строки `STEP …` — что делается сейчас.
- `--lang ru` — если язык известен заранее (по умолчанию `auto`).

Скачивание — `yt-dlp` (куки: `~/.config/yt-dlp/cookies.txt` или `YTDLP_COOKIES`), для Instagram запасной путь — Apify
(`APIFY_TOKEN`). Расшифровка — ElevenLabs Scribe → OpenAI whisper-1 → `stt.py` скилла монтажа → faster-whisper.
Ключи — из окружения или из `~/.bashrc` / `~/.profile` / `~/.zshrc`.

## Если не вышло

- «по ссылке не скачалось» — Instagram ограничил анонимный доступ или это карусель/фото. Попроси видео файлом и
  запусти скрипт с путём к файлу.
- «расшифровать не вышло» — нет ни одного ключа и нет локального whisper; скажи, какой ключ нужен.

## Что делать с расшифровкой дальше

Расшифровка — сырьё, а не результат: не копируй чужой текст в свой контент. Агент контента берёт из неё
структуру, хук, аргументы и приёмы и пишет своё — в стиле и для аудитории Ильи.

В живом офисе hq2.aicex.club этот скилл — агент «Транскрибатор» (`transcriber`): диспетчер рабочего стола
сам ставит его первым, если в задаче есть ссылка на ролик, и передаёт расшифровку следующему агенту
(файлы `in/transcript-<n>.md`).
