# Карусель Люкс

Дизайн-слой для каруселей Ильи. Что писать (хук, число слайдов, кодовое слово, подпись) — правила скилла
`carousel-pro` (`../carousel-pro/references/carousel-rules.md`). Как это выглядит — этот скилл.

Готовая серия-пример: `examples/lisa10.py` — 10 каруселей Лизы, адаптированных под Илью (29.10.2026).

## Когда какой стиль

- **Тёмный / светлый @ilia.paliy** (`carousel-pro`, `ilia-carousel-style`) — ремикс уже вышедших каруселей Ильи пиксель в пиксель.
- **Люкс** (этот скилл) — новая карусель с нуля или адаптация чужой: обложка-портрет, фактуры, много визуальных слоёв.

## Шаги

1. **Формат.** Возьми механику залёта (своего или конкурента — `references/formats.md`: подборка инструментов, пак
   промптов, «старое / новое правило», инсайд, пошаговая инструкция, VS). Определи хук, 6–8 слайдов, кодовое слово
   из живых автоматизаций ChatPlace (`references/code-words.md`) и что человек получит за слово.
2. **Обложка.** Нужен кинопортрет Ильи по теме. Готовые — `assets/covers/c01…c10.jpg` (кейс в библиотеке, лампы,
   ночной город, киностудия, ступени, ч/б, монтажная, кресло с ноутбуком, зелёный костюм, звезда Claude). Новый —
   промпт и способ генерации в `references/generation.md` (ChatPlace `virale_image_generate`, `gemini_pro`, 2K,
   фото Ильи как референс лица; ≈$0.17 за портрет). Перед генерацией скажи Илье цену: тот же баланс тратит ИИ в Директе.
3. **Фактура.** Одна на карусель: `assets/textures/` (leather, tokyo, concrete, smoke, stone, brush, edit, walnut,
   marble, steel). Новая — тоже `references/generation.md` (`gemini_2`, 2K, ≈$0.13).
4. **Скрины.** Свои — `assets/ilia/` (profile, stats, payments, direct, table, reels, montage, result, icons3, иконки).
   Сайты — `assets/sites/` или свежий скрин Playwright (1440×900, deviceScaleFactor 2). Чужие лица, ники, логотипы и
   тексты автора-конкурента не переносим.
5. **Сборка.** Карусель — функция на компонентах `scripts/lux.py` (ниже), список функций → `build()`:
   ```bash
   npm i playwright @fontsource/cormorant-garamond @fontsource/manrope @fontsource/jetbrains-mono @fontsource/oswald
   python3 examples/lisa10.py out/          # или свой файл по образцу
   node scripts/render.mjs out/jobs.json    # PNG 3240×4050 (LUX_SCALE=1 — быстрый черновик 1080×1350)
   ```
6. **Проверка.** Посмотри каждый слайд превью-листом: текст не наезжает на скрины, обложка читается на телефоне,
   цифры не «старинные» (lining-nums уже включены), подпись — первая строка с кодовым словом, «Сохраняй, чтобы не потерять 🤝».
7. **Выдача.** По папке на карусель: `slide-NN.png` + `podpis.txt`. Один архив на серию — JPEG q95 без субдискретизации
   (PNG с зерном весят ~11 МБ на слайд). Публикация — только после «публикуй», от **ilia.paliy**.

## Компоненты `scripts/lux.py`

| Функция | Что рисует |
|---|---|
| `cover(photo, top, accent, sub, size, accent_size, badge)` | Обложка: портрет, антиква капсом, золотой курсив с рукописным подчёркиванием и стрелкой |
| `bg(texture, shade)` | Фактурный фон + затемнение (зерно добавляется само) |
| `window(x, y, w, img, url)` | Скрин сайта в окне браузера macOS |
| `shot(x, y, w, img, rot, radius)` | Скрин/карточка с тенью, можно повернуть |
| `arrow`, `arrow2`, `oval`, `underline`, `strike` | Рукописные стрелки, овал вокруг слова, подчёркивание, мазок-перечёркивание |
| `tape`, `clip` | Скотч и чёрный канцелярский зажим (для «бумажных» слайдов) |
| `leadmag(x, y, title, sub, photo)` | Мокап материала (файл/скилл) в CTA |
| `cta(i, n, texture, word, before, after, mag_title, mag_sub, proof)` | Финал: мокап, стрелка, слово на золотой плашке, выгода; `proof` — профиль и статистика |
| `foot(i, n)` | Подвал: @ilia.paliy · точки · «Листай дальше →» |

CSS-классы: `.h1` антиква 84px, `.h2` гротеск 48px, `.p` текст 31px, `.it` золотой курсив, `.tag`/`.mono` машинопись,
`.glass`, `.paper`, `.card`, `.plaque`, `.chip`, `.num`. Токены и правила — `references/design-system.md`.

## Рилс в том же стиле (`scripts/reel.py`)

Сценарий карусели легко становится рилсом: слайд = реплика, заголовок слайда = титр вставки. `Reel` собирает
кадр 1080×1920: обложка-портрет, вставки «золотой титр + окно браузера со скрином» (высокий скрин плавно
скроллится, низкий — медленный наезд), финал с кодовым словом на золотой плашке. Длина вставки — по реплике
(2,5 слова/с, как у голоса-клона). На выходе `inserts/NN-<роль>.mp4` без субтитров (для монтажа поверх аватара),
`animatic.mp4` с субтитрами (посмотреть ритм до рендера аватара), `cover.png`, `timeline.txt`.
Текст реплик — по правилам `../remake-top-reel/references/script-rules.md` (хук до 3 с, контракт с числом,
пары «было → стало», два микро-крючка, только реальные цифры, кодовое слово в конце).
Материал для вставок про ИИ-офис — живой офис `hq2.aicex.club` (досье агентов, история задач, «Работы», план).

## Правила дизайна (коротко)

- Один слайд — одна мысль и один визуальный якорь (скрин, карточка, список). Пустую нижнюю треть заполняй визуалом, а не воздухом.
- Обложка: 2–4 строки антиквы капсом + 1–2 строки золотого курсива. На портрете текст только в нижних 45%.
- Фактура одна на карусель; светлые «бумажные» слайды можно чередовать с тёмными (как «старое / новое правило»).
- Минимальный кегль на слайде 1080 — 26px; основной текст 30–34px.
- Цифры и факты — только Ильи (300 000 подписчиков, 15–20 тыс./мес., 1 500 диалогов в день, 8,4 млн просмотров, 11 252 оплаты / 84,8 млн ₽, ≈46 000 заявок). Чужие цифры — только «у автора».
