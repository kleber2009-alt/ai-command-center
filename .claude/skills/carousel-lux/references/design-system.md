# Дизайн-система «Карусель Люкс»

Откуда: разбор 20 топ-каруселей Лизы Ткачук (сентябрь–октябрь 2026) → тот же язык, но мужская палитра и фактуры.

## Токены

| Токен | Значение |
|---|---|
| Фон по умолчанию | `#0c0c0c` под фактурой |
| Текст | `#F3EEE4` (слоновая кость) |
| Акцент | `#E0B46A` (золото) — курсив, плашка кодового слова, номера, стрелки |
| Тёмная бумага/текст | `#151311` на `#F1EBDF` |
| «Нет / старое» | `#C2412D` (кирпич) |
| Плашка «промпт» | `#B8322A` |
| Медная плашка | `#6B2A12` |

## Шрифты (npm @fontsource)

- **Cormorant Garamond** 500–700 — обложки капсом, заголовки, курсив-акценты. Обязательно `lnum` (иначе «2026» → «2o26»).
- **Manrope** 400–800 — текст, подписи, жирные выделения.
- **JetBrains Mono** — «машинопись»: шаги, промпты, теги «01 · ...», подвал обложки.
- **Oswald** 500–600 — капс-метки («СТАРОЕ ПРАВИЛО ✕», «✓ ДОСМАТРИВАЮТ»).

## Слои слайда (снизу вверх)

1. Фактура (`assets/textures`) или портрет.
2. Затемнение `rgba(0,0,0,.25–.55)` или градиент (на ярком фоне — сильнее вверху, где текст).
3. Контент: заголовок → визуальный якорь → пояснение.
4. Рукописный слой: стрелка от текста к скрину, овал/подчёркивание вокруг цифры.
5. Подвал и зерно (SVG feTurbulence, opacity .11, overlay).
