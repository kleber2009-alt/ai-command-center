# Карусель Pro

Объединяет скилл `ilia-carousel-style` (ремикс вышедших каруселей Ильи пиксель в пиксель) и отбор залётов у
конкурентов — так же, как `remake-top-reel` делает для рилсов. Правила текста, хука, числа слайдов и CTA —
`references/carousel-rules.md` (их же читает бот). Настройки — `config.json`.

## Где работает

1. **Ветка «Instagram Карусели» в Telegram** — `apps/remake-site/carousel-bot.mjs` (бот «Карусель Pro», свой токен
   `CAROUSEL_TG_BOT_TOKEN`). Каждый день ищет карусели-залёты у конкурентов и в аккаунте Ильи, шлёт 2–3 карточки:
   почему залетело, новый хук, план слайдов с их числом, кодовое слово, подпись. «✅ Одобрено» → готовые слайды
   альбомом и файлами без сжатия в ту же ветку. Ответ на карточку текстом — переписать план с пожеланием,
   ссылка на карусель в ветке — сразу в работу. Стили — только карусельные, из блога Ильи (`styles` в `config.json`):
   «Тёмный @ilia.paliy», «Светлый @ilia.paliy», «Обложка с вашим фото», «Люкс-редакция» (дизайн-слой — скилл `carousel-lux`); 🎨 на карточке — выбор с превью обложки,
   `/styles` — все стили альбомом. На сервере к правилам добавляются карусельные скиллы,
   установленные у Студии Кадрика (`~/.claude/skills/*carousel*`, `*карусел*`).
2. **В чате** — вручную, с браузером Ильи, по шагам ниже. Нужна карусель «как у топовых блогов» с нуля — дизайн по скиллу
   `../carousel-lux/SKILL.md` (кинопортрет, фактуры, скрины в окнах, рукописные стрелки), текст — по правилам этого скилла.

## Как работать в чате

1. **Выбор.** Статистика последних 20 публикаций (комментарии дают кодовые слова, репосты, лайки если видны).
   Два типа исходников: **победители** (много комментариев) — повторяем с новым хуком; **сильная начинка,
   слабый хук** — меняем обложку, начинку оставляем. Залёты конкурентов — сила = (3×комментарии + лайки) /
   медиана автора. Для каждой карусели предложи: новый хук и почему, какие слайды берём, что меняем, число слайдов,
   кодовое слово, что проверяем (хук А против хука Б). Жди «ок».
2. **Оригиналы в полном размере** (свои). На странице поста в браузере Ильи — приём из `ilia-carousel-style`:
   полноэкранная подложка с меткой, слайд двумя половинами, склейка `python3 scripts/assemble.py <скриншоты> src`
   → `src/c<N>-s<NN>.png` 1080×1350.
3. **Ремикс текста** — `python3 scripts/remix.py spec.json` (стирает старый текст inpaint-ом и ставит новый теми же
   шрифтами: Jost вместо Futura PT, Tinos Italic `#DE984A` для акцента). Spec, классы текста (`h`, `it`, `pill`,
   `caps`, `cover`, `coversub`, `badge`, `pishi`, `cta-word`, `lcover`, `lcardm`) и координаты — как в
   `ilia-carousel-style`: верх блока ≈ верх заглавных минус ~10 px, заголовки с x≈110, текст в капсулах с x≈162,
   `erase` `mode:"text"` для тёмных слайдов, `mode:"fill"` для светлых.
4. **Чужая карусель** — слайды в стиле Ильи (тёмный фон, Jost, курсив-акцент), скриншоты интерфейсов вырезаем
   из оригинала; лица, ники, логотипы и тексты автора — нет.
5. **Проверка и выдача.** Каждый изменённый слайд — в полный размер против исходника; JPEG качества 93, по папке на
   карусель + превью-лист; подпись по шаблону (кодовое слово первой строкой, 2–3 абзаца, «Сохраняй, чтобы не
   потерять 🤝»). Публикация — только после явного «публикуй», окно публикации от **ilia.paliy**.

## Установка (для remix.py)

```bash
npm i @fontsource/jost @fontsource/tinos
pip install --break-system-packages opencv-python-headless pillow numpy playwright
```

`remix.py` ищет шрифты в `../node_modules/@fontsource` относительно `scripts/`, исходники — в `scripts/src/`.
