# Балансы и подписки

```bash
python3 ~/.claude/skills/service-balances/scripts/balances.py --out out/
```

- `out/index.html` — страница со светофором: «Срочно», «Скоро», «В порядке»; `out/balances.json` — то же данными.
- Последняя строка вывода — JSON: `critical` и `warn` — списки строк «сервис (аккаунт): что случилось».
- Ключи — из окружения или `~/hq-runner/keys.env`; каждый ключ проверяется один раз, даже под разными именами.
- Подписки без API (сервер, домены, Claude, Higgsfield…) — переменная `HQ_SUBSCRIPTIONS_JSON` в GitHub:
  `[{"name":"Claude Max","renews":15,"price":"$200","url":"https://claude.ai/settings/billing"}]` — `renews` число месяца
  или дата `YYYY-MM-DD`.

Пороги: подписка через ≤7 дней — «Скоро», ≤2 — «Срочно»; осталось ≤20 % лимита — «Скоро», ≤5 % — «Срочно»;
кончились кредиты или ключ не принят — «Срочно».

Проверка Anthropic и OpenAI — крошечный запрос (доли цента): остаток денег их API не отдают, видно только «работает /
кончились деньги». Если в ответе есть «Срочно» — скажи владельцу первым делом, со ссылкой, где пополнить.
