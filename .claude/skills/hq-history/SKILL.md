# Задача в историю hq2.aicex.club

История — правая панель офиса. Её показывают на вебинарах как доказательство, поэтому
каждая задача — реальная работа с проверяемой ссылкой и датой.

- `apps/hq-office/tasks.js` — история, которую ведут вручную (сюда добавляешь ты).
- `apps/hq-office/tasks.auto.js` — пополняется сама: новые PR после каждого слияния и раз
  в сутки (`.github/workflows/hq-office-history.yml`). Новые PR вручную не добавляй.

## Шаги

1. **Прочитай ссылку.** Артефакт Claude (`claude.ai/artifact/…`, `claude.ai/code/artifact/…`)
   — инструментом Artifact (`read`): название, что внутри, дата последнего обновления.
   PR — через GitHub. Сайт — заголовок и описание страницы. Не можешь прочитать — спроси
   название и одну фразу «что сделано».
2. **Проверь, что ссылки ещё нет** в `tasks.js` и `tasks.auto.js` (поиск по id артефакта, номеру
   PR или адресу). Есть — скажи, в какой она задаче, и предложи дополнить её.
3. **Добавь объект в `tasks.js`** в раздел своего отдела, в формате соседних задач, через
   помощники `art(id, label)`, `pr(...ns)`, `site(url, label)`, `file(p, label)`, `img`, `vid`, `page`
   и константы дат `UPD` (артефакт), `MERGED` (PR), `COMMIT`:
   - `id` — латиницей, уникальный; `date` — ГГГГ-ММ-ДД, проверяемая (обновление артефакта, слияние PR);
   - `dept` — `ceo | marketing | sales | traffic`; `agents` — id из `agent-content.js`, кто делал работу;
     `people` — `['ilia']` и id руководителей, если работу делали они (спроси, если не ясно);
   - `title` — до 90 знаков, понятным языком; `summary` — одно-два предложения: что это даёт.
     Только факты из источника, без выдуманных цифр.
4. **Проверь** тем же скриптом, что и выкладка (шаг «Check data files» в
   `.github/workflows/deploy-hq-office.yml`), и что `https://hq2.aicex.club/#task-<id>` откроется.
5. **Выкати:** коммит в рабочую ветку, PR в `main`; слияние — после «ок» пользователя (или сразу,
   если он просил выкатить). После слияния офис выкладывается сам за пару минут.

## Без Claude

GitHub → Actions → **hq-office-history** → Run workflow: ссылка, название (для артефакта Claude
обязательно), отдел, пара предложений. Задача появится в `tasks.auto.js` и на сайте.
