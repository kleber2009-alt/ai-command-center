# Правила «Одной сториз»

## Формула (из сторис, которые залетели)

| Приём | Пример у Ильи |
|---|---|
| Вопрос «Кто хочет **ГОТОВОЕ** …?» — готовый инструмент, а не «научу» | «Кто хочет ГОТОВОЕ решение (скилл) для монтажа», «целый отдел маркетинга внутри Claude» |
| Подарок бесплатно + жест 🤝 | «Отправлю готовый скилл + инструкцию БЕСПЛАТНО каждому» |
| Одно кодовое слово «в ответ на сторис», заглавными, цветом | МОНТАЖ, ОТДЕЛ, ХОЧУ, «+» |
| Название инструмента, который все знают | Claude / Codex |
| Цифра охвата одной строкой | «5–7 млн просмотров каждый месяц» |
| Вовлечение «+» | «Ставьте + на эту сторис, посмотрю, сколько вас» |
| Живое фото Ильи: зал, падел, зеркало, сцена | без студийного фона |

Не продаём практикум в самой сторис прогрева: сторис дарит, приглашение приходит вторым сообщением в Директ.

## Текст

- Заголовок ≤ 12 слов, одно слово-акцент. Подзаголовок ≤ 25 слов, конкретика (что именно получит, цифры).
- Призыв: «Пиши «СЛОВО» в ответ на сторис. Отправлю … бесплатно 🤝» или «ПИШИ «СЛОВО» В ОТВЕТ НА ЭТУ СТОРИС ⬇️».
- Кодовое слово — одно короткое, своё на каждый подарок; на запись в продукт — одно общее (ПРАКТИКУМ).
- Цифры учеников — только с их разрешения. Неизвестное — `[в скобках]`.

## Серия под запуск

1. **Подарки** (до анонса): 2 сторис в день, каждая — свой готовый инструмент/план/разбор.
2. **Анонс** (за 2–3 дня): даты, формат, «скилл, который вы забрали, — 1 из N связок».
3. **Эфир**: «завтра, записи не будет» → «через час начинаем» (стикер-ссылка) → итоги дня 1 с числом
   зрителей → «сегодня последний день».
4. ChatPlace: слово → подарок → через 2 мин приглашение кнопкой → тег; напоминания по тегу накануне и за час.

## Формат stories.json

```json
{ "profile": {"handle": "ilia.paliy", "bio": "…", "posts": "887", "followers": "297K", "following": "227"},
  "stories": [ {
    "id": 2, "photo": "02", "photoNote": "Зал, зеркало", "shift": 220, "accent": "orange",
    "top":    [ {"kind": "light", "text": "Кто хочет **ГОТОВЫЙ** скилл…?"} ],
    "bottom": [ {"kind": "light", "size": "s", "text": "…"},
                {"kind": "dark", "text": "Отправлю ++БЕСПЛАТНО++ каждому"},
                {"kind": "heavy", "text": "ПИШИ «**СЛОВО**» В ОТВЕТ НА ЭТУ СТОРИС ⬇️"} ] } ] }
```

- Разметка: `**слово**` — цвет акцента (`accent`: orange по умолчанию, red, blue или `#hex`),
  `++слово++` — зелёный, `\n` — перенос, `<small>…</small>` — мелкая строка.
- `kind`: `light` (белая, обычный шрифт), `heavy` (жирный курсив, `big: true` — крупно), `bold` (жирный),
  `dark` (чёрная), `alert` (огромная чёрная «ВНИМАНИЕ !»), `yellow`, `plain` (белый текст без плашки),
  `link` (стикер-ссылка). Ещё: `size: "s"`, `wide: true` (во всю ширину), `gap` (отступ сверху, px).
- Фон: `photo` (файл `photos/<photo>.*`), `shift`/`scale` — сдвиг фото вниз / масштаб, чтобы лицо было между
  плашками; без фото — `bg: "dark"`, `bg: "card"` + `card: {kicker, title, chips[]}`, `bg: "avatar"` + `caption`.
  Вставка-скрин поверх фона: `inset: "media/путь.jpg"` (путь от папки проекта), `insetTop` (px, по умолчанию 760).
- `profile: true` — карточка профиля над нижними плашками.
- Зоны: плашки сверху начинаются с 270 px, снизу заканчиваются на 330 px от края — интерфейс Instagram их не
  перекроет.
