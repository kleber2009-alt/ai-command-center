# Ремейк залёта

Цепочка: **Instagram → отбор → оригинал → расшифровка → сценарий 2.0 → аватар HeyGen → монтаж → готовый рилс.**
Монтаж не свой: это три скилла «Студии Кадрика» (`glass-explainer-reel`, `explainer-panel-reel`,
`business-short-form-reels`), ремейк готовит для них «сырьё» — видео аватара — и запускает нужный.

`S=~/.claude/skills/remake-top-reel/scripts` (в репозитории — `.claude/skills/remake-top-reel/scripts`) ·
задачи в `~/reel-work/remake/<slug>/` · история и личные настройки в `~/.claude/creator-profile/remake/`.
Каждый скрипт печатает подсказку по `--help`. Все скрипты — стандартный Python + ffmpeg.

## Как работать

Илья приходит, ставит задачу и уходит — **все вопросы задаёшь в самом начале, одним окном, дальше без
остановок до готового рилса**. Вопросы бывают только такие, и только если ответа нет в запросе и настройках:

1. **Стиль** — если не назван и `style_mode` = `ask` (см. шаг 7).
2. **Аватар** — один раз в жизни: если `avatar.confirmed` = false (шаг 6), показать варианты и запомнить.

Всё остальное решаешь сам и пишешь решения одной строкой в отчёт. Без человека (Студия Кадрика, расписание)
не спрашиваешь ничего: стиль — ротация, аватар — по умолчанию с пометкой «временно по умолчанию».
Обязательная остановка — только если нечего делать дальше: нет данных Instagram и ссылки, не скачать видео,
кончились кредиты HeyGen. Тогда — одной фразой, что сломалось и что сделать.

Пока HeyGen рендерит (5–15 минут), не жди впустую: пиши подпись, выбирай стиль, готовь поручение монтажу.

## Шаг 0. Разобрать запрос

Из слов Ильи вытащи: период («за месяц», по умолчанию 180 дней), стиль, ссылку на конкретный рилс, сколько
рилсов сделать, нужно ли превью. Есть ссылка — шаги 1–2 пропускаешь, сразу `grab.py <ссылка>`.
Запуск из «Студии Кадрика» с текстом задачи (`sources/script.txt`) — это и есть запрос, читай его так же,
а её рабочую папку передавай каждому скрипту: `REMAKE_WORK=<папка задачи бота> python3 $S/…` (переменные между
вызовами Bash не сохраняются — пиши в каждой команде).
Настройки: `python3 $S/settings.py show`.

## Шаг 1. Выгрузить рилсы

Источник — по `references/sources.md`. В чате основной — **Windsor MCP**: вызови `get_data` ровно с полями
из sources.md, сохрани ответ в `~/reel-work/remake/_scan/windsor.json` и
`python3 $S/fetch_reels.py --windsor ~/reel-work/remake/_scan/windsor.json`.
Без MCP: `python3 $S/fetch_reels.py` (сам возьмёт Graph API по `IG_ACCESS_TOKEN` или Apify по `APIFY_TOKEN`).
Заглушка Windsor «Free plan includes 1 account» — скажи Илье, как починить (sources.md), и иди другим источником.
Запасной путь в чате без токенов — **ChatPlace + yt-dlp**: посты из `automations_triggers_list_instagram_media`
(бот @ilia.paliy), «лиды» по кодовым словам из `automations_list_with_stats`, лайки и комментарии свежих рилсов —
yt-dlp (`fetch_reels.py --chatplace … --automations …`, подробно в sources.md). Просмотров и репостов там нет.

## Шаг 2. Отобрать: залёт + говорящая голова + кодовое слово

`python3 $S/rank.py` → таблица топ-8 и `candidates.jpg` (обложки с номерами). Счёт — процентили по просмотрам,
комментариям и репостам+шерам; рилсы с кодовым словом в подписи — первыми; уже переделанные за 60 дней — убраны.

Открой `candidates.jpg` (Read) и выбери **первый по счёту рилс, где Илья в кадре говорит в камеру** (лицо крупно,
речь — главное; не скринкаст, не нарезка без лица, не карусель). Кодовое слово в подписи не нашлось — это ещё
не отказ: его часто говорят голосом, проверишь на шаге 4.

## Шаг 3. Забрать оригинал

`python3 $S/grab.py <номер>` → папка задачи, `sources/original.mp4`, `source.json`, `sheet.jpg`.
Открой `sheet.jpg`: на большинстве кадров — Илья, говорящий в камеру? Нет — следующий кандидат (`grab.py <N+1>`).
Видео не скачалось — `grab.py` скажет почему; попроси файл и `grab.py <путь к mp4>`.

## Шаг 4. Расшифровать

`python3 $S/transcribe.py <slug>` — сначала `stt.py` из скилла монтажа (ElevenLabs Scribe / локально, как в
«Студии Кадрика»), дальше ElevenLabs, OpenAI, faster-whisper. Печатает долю речи и кодовое слово из речи.
- `МАЛО РЕЧИ` → это не говорящая голова, возьми следующего кандидата.
- Нет кодового слова ни в подписи, ни в речи → следующий кандидат; если таких нет совсем — делай ремейк
  лучшей говорящей головы и добавь призыв со словом по теме (по `reels-script`), отметь это в отчёте.
Прочитай `transcript.txt` целиком и поправь явные ошибки распознавания (имена, бренды) прямо в файле.

## Шаг 5. Сценарий 2.0

По `references/script-rules.md`: разбор оригинала (почему залетел, по метрикам) → сохранить тему, каркас,
длину ±25% и **то же кодовое слово** → усилить хук, пары «не так → а вот так», микро-крючки, пруф → заменить
примеры и формулировки. Пишешь три файла в папку задачи: `script.md` (разбор + сценарий + подсказки графики +
таблица «Написание»), `script.txt` (только то, что говорит аватар), `caption.txt` (подпись к посту).

`python3 $S/check_script.py <slug>` — **гейт перед тратой кредитов**. FAIL → правишь и запускаешь снова, пока не
PASS. WARN — решаешь сам (лишняя длина допустима, если ролик стал плотнее).

## Шаг 6. Аватар HeyGen говорит голосом Ильи

Образ и голос — `avatar.look_id` / `avatar.voice_id` (`settings.py show`). Если `avatar.confirmed` = false и
Илья в чате — в стартовом вопросе покажи варианты из `avatar.alternatives` + текущий (превью:
`list_avatar_looks`), после ответа `python3 $S/settings.py set avatar.look_id=… avatar.voice_id=… avatar.confirmed=true`.

**В чате (есть MCP HeyGen):**
1. `get_current_user` — хватит ли кредитов (≈ 1 кредит на секунду видео); не хватает — стоп, скажи.
2. `create_video_from_avatar(avatarId=<look_id>, script=<script.txt слово в слово>, voiceId=<voice_id>,
   aspectRatio="9:16", resolution="1080p", engine={"type": <python3 $S/settings.py engine>}, title="Ремейк · <slug>")`.
   Движок — по настройкам на сегодня: сейчас `avatar_iii`, после сброса премиум-кредитов 1 ноября сам станет `avatar_v`
   (`avatar.engine_switch`). 402 «insufficient credit» — стоп и вопрос Илье, на другой движок молча не переходить.
3. `get_video(videoId)` до `completed`. Между опросами не простаивай: подпись, стиль (шаг 7), поручение монтажу.
   Делать больше нечего, а видео ещё `processing` — подожди тем, что позволяет среда (фоновая команда, монитор),
   и опроси снова; не пересоздавай видео. `failed` — объясни причину и остановись.
4. `python3 $S/heygen_render.py <slug> --fetch <video_url> --id <videoId>` → `<задача>/<slug>.mp4`.

**Без MCP (Студия Кадрика, скрипт):** `python3 $S/heygen_render.py <slug>` (Bash с таймаутом 600000) — REST по
`HEYGEN_API_KEY`: отправит, ждёт до 9 минут и скачает. Код выхода 3 и `PENDING` — ещё рендерит: делай другие
шаги и повтори `heygen_render.py <slug> --resume`.

Открой `avatar_sheet.jpg`: лицо в кадре, 9:16, не обрезано. Сверь длительность с оценкой из check_script.
При желании `transcribe.py <slug> --file <задача>/<slug>.mp4` — проверить, что аватар сказал всё.

## Шаг 7. Стиль

`python3 $S/style.py next --want "<слова Ильи>"` → JSON со стилем и `ask`.
- назван в запросе → он; `ask: false` → берёшь ротацию молча;
- `ask: true` и Илья в чате → это стартовый вопрос (задан ещё в начале, вместе с аватаром): три стиля,
  ротационный первым «(рекомендую)», и «Чередуй сам и больше не спрашивай» → `settings.py set style_mode=rotate`.
Описание стилей и когда какой лучше — `references/styles.md`.

## Шаг 8. Монтаж

Вызови скилл стиля через Skill и выполни его на `<задача>/<slug>.mp4` с поручением из `references/styles.md`
(видео аватара: дублей нет, режем только паузы; написание из script.md; кодовое слово акцентом; без вопросов;
профиль — по умолчанию без записи; без музыки; превью заменить собственной проверкой и сразу финал).
Запуск из «Студии Кадрика» — её поручение (превью → «ок» → финал) главнее.
Скилла стиля нет на машине — см. конец styles.md.

## Сайт-пульт (если в config.json есть `site.url`)

Без чата Илья может сделать то же сам на `site.public_url` во вкладке «Студия» (по паролю): референс → расшифровка →
сценарий 2.0 по `references/script-rules.md` с тем же `check_script.py` → образ и голос из HeyGen → монтаж скиллом
Кадрика → скачать. Студия берёт из этого скилла `config.json`, `scripts/` и правила сценария при выкладке сайта — правишь
их, сайт перевыкладывается сам (`apps/remake-site/CLAUDE.md`).

Илья смотрит прогон на странице «Ремейк залёта» — она обновляется сама. Одна страница (`apps/remake-site/index.html`)
в двух местах: артефакт claude.ai (`site.url`, база артефакта) и сайт `site.public_url` (remake.aicex.club, API по токену
`REMAKE_SITE_TOKEN`). Есть ArtifactData — пиши в артефакт; есть токен — ещё и `--push` на сайт (в Студии Кадрика
работает только он). После каждого шага:
1. `python3 $S/report.py <slug> --status running|waiting|done|failed --headline "что сейчас" --step <шаг> <run|done|wait|fail> "заметка" --log "событие"`
   (несколько `--step` и `--log` в одной команде). Шаги: scan pick grab transcribe script check avatar montage deliver.
   Разбор сценария, «почему этот», образ аватара, стиль — в `<задача>/site_extra.json` (поля как в run.json).
2. `ArtifactData set`, collection `runs`, doc_id = slug, `file_path` = `<задача>/run.json`, `if_version` — версия из прошлой
   записи (первая запись без неё; в начале прогона ещё `remake/state` = `{"current": slug}`).
3. Картинки и видео страница берёт только из своего хранилища: обложки кандидатов (уменьшить до 270 px), лист кадров,
   видео аватара и финал (до 20 МБ — для страницы копия для телефона) загрузи `Artifact` publish с `url`, `asset: true`
   (`file_paths` — пачкой), и передай id: `report.py <slug> --asset thumb_1=<id> sheet=<id> avatar=<id> final=<id>`.
4. Сайт: те же картинки и видео — `--media thumb_1=<файл> sheet=<файл> avatar=<файл> final=<файл>` (видео для сайта
   до 60 МБ, лучше копия 720p) и `--push`; уже отправленные файлы повторно не грузятся. Нет токена — сайт пропускается.
Ждёшь Илью или внешний сервис — `--status waiting` и причина в `--headline`, чтобы на странице было видно, почему стоим.

## Шаг 9. Сдать

1. `python3 $S/style.py log <slug> --style <id> --result "<мастер.mp4>" --caption <задача>/caption.txt` —
   в историю (ротация стилей и защита от повторного ремейка того же рилса).
2. Отдай файл: в облачной сессии — SendUserFile (копия для телефона), на Mac — путь; Студия Кадрика —
   последней строкой `RESULT: <путь>` по её правилам.
3. Отчёт по-русски, коротко:
   - оригинал: ссылка, просмотры / комментарии / репосты, почему выбран;
   - что усилено и что поменяно (хук: тип → тип), уникальность из check_script (`overlap`, общий кусок);
   - кодовое слово и напоминание: **после публикации привязать автоматизацию этого слова в ChatPlace к новому
     рилсу** (предложи сделать через ChatPlace MCP, когда Илья пришлёт ссылку на опубликованный рилс);
   - аватар (образ, голос), стиль и почему, «временно по умолчанию», если были;
   - файлы: мастер, копия для телефона, `script.md`, `caption.txt`;
   - из отчёта монтажа: ассеты-заглушки и тексты, которые стоит проверить; вопрос музыки.
Ничего не публикуешь сам.

## Несколько рилсов за раз

«Сделай три» → три разных оригинала из топа (не один и тот же), стили по ротации, все вопросы — одним окном
в начале. Сценарии пишешь по очереди; аватары можно отправить в HeyGen подряд и монтировать по мере готовности.

## Если что-то не так

| Что | Что делать |
|---|---|
| Windsor: «not your real numbers» | Отключить `instagram_public` в Windsor (sources.md) · пока — Graph API / Apify / ссылка |
| Ни одной говорящей головы с кодовым словом | Расширить период (`fetch_reels.py --days 365`) · или лучшая говорящая голова + новый призыв |
| `grab.py` не скачал видео | Ссылка CDN протухла → перезапусти fetch_reels · или файл от Ильи |
| Instagram «rate-limit… login page» | Анонимный лимит (~40–50 запросов подряд): подожди 15–30 минут и повтори `grab.py`; не обогащай больше 24 рилсов |
| HuggingFace 429 при расшифровке | Повтори через минуту; transcribe.py сам возьмёт уже скачанную модель поменьше |
| Расшифровка не вышла | Нет ни скиллов монтажа, ни ключей → `pip install faster-whisper` и `--engine local` |
| check_script FAIL по уникальности | Меняешь примеры и пары «не так → так», а не синонимы |
| HeyGen: кредиты / квота голоса | Стоп, сказать пополнить (app.heygen.com/settings/subscriptions) или взять другой голос-клон |
| Аватар прочитал бренд криво | Перепиши слово фонетически в script.txt, правильное — в «Написание», перерендери |
| Скилла стиля нет | `kadrik/install.sh --styles <aicex-library>` · иначе сдать видео аватара + сценарий |

## Установка

`bash ~/.claude/skills/remake-top-reel/kadrik/install.sh` (из репозитория — `.claude/skills/remake-top-reel/kadrik/install.sh`):
копирует скилл в `~/.claude/skills`, добавляет «Ремейк залёта» в каталог мини-аппа «Студии Кадрика» и
пересобирает его. `--styles <путь к aicex-library>` — заодно поставить три стиля монтажа (для новой машины
или облака).
