# 3D-взрыв-схема (Technical Exploded Illustration)

Цель — страница, которая выглядит как разворот технического мануала: объект собран из простых
примитивов, детали разнесены вдоль оси, к ним тянутся тонкие выноски от карточек-подписей.
Точность и читаемость важнее красоты: никакого фотореализма, кинематографичного света и глянца.

Готовый шаблон — `../assets/template.html` (Three.js 0.160 с unpkg, без сборки). Начинай с него:
скопируй, замени сборку и подписи под задачу, не переписывай с нуля.

## Шаги

1. **Пойми объект.** Что изображаем (продукт, сервис как «механизм», модуль, устройство) и
   для чего (лендинг, слайд карусели, кадр рилса, интерактив). Если объект абстрактный
   (например, «AI-агент» или «воронка продаж») — придумай механическую метафору: слои = диски,
   модули = кольца, ядро = цилиндр, связи = оси и болты. Назови 4–7 узлов — больше не читается.
2. **Собери из примитивов.** Только `CylinderGeometry`, `BoxGeometry`, `TorusGeometry`,
   кольца (`RingGeometry` или цилиндр с отверстием через `LatheGeometry`), диски. Все детали
   соосны и логично стыкуются в собранном состоянии (`explode = 0`).
3. **Разнеси.** Каждой детали — базовая позиция и вектор взрыва вдоль одной оси (обычно Y,
   иногда X/Z для боковых узлов). Позиция = `base + dir * explode`. Слайдер «Разнесение» 0…1.
4. **Подписи.** Карточки — в HTML-панелях слева и справа, не на меше. Каждая карточка
   привязана к якорю (`Object3D` внутри детали); выноска — SVG-ломаная от карточки к
   спроецированной точке якоря, на конце маленький кружок. Текст — заглавными, коротко:
   номер узла, название, 1 строка пояснения, при желании мини-бар или метрика.
5. **Проверь** по чек-листу ниже, сделай скриншот (Playwright есть в окружении:
   `chromium.launch()`, `page.screenshot`) и посмотри на него глазами, прежде чем отдавать.
6. **Отдай.** По умолчанию — артефакт (инструмент Artifact, перед этим загрузи скилл
   `artifact-design`) или файл в нужное приложение. Нужна картинка 1080×1350 / 1920×1080 —
   отрендерь скриншотом с параметром `?still=1` (выключает вращение и UI-контролы).

## Стиль

| Что | Правило |
|---|---|
| Фон | `#f4f4f1` … `#fafaf8`, едва заметная сетка (`GridHelper`, линии `#dcdcd6`) |
| Основной металл | `MeshStandardMaterial` `#f2f2ef`, `metalness 0.35`, `roughness 0.45` |
| Вторичный металл | `#c9cbcc`, `metalness 0.5`, `roughness 0.4` |
| Крепёж / оси | `#3a3d40`, `roughness 0.6` |
| Акцент 1 — оранжевый | `#ff6a1a` — активный узел, главная выноска. Максимум 1–2 детали |
| Акцент 2 — зелёный | `#2fb36b` — статус, вторичная информация. Максимум 1–2 детали |
| Контуры | `EdgesGeometry` + `LineBasicMaterial` `#55595d`, `opacity 0.55` — даёт «чертёжность» |
| Свет | `HemisphereLight` 0.9 + 2 `DirectionalLight` 0.8/0.35, тени мягкие или без теней |
| Камера | `PerspectiveCamera` FOV 28–32 (почти изометрия), вид чуть сверху |
| Шрифт | моноширинный или узкий гротеск (`JetBrains Mono`, `IBM Plex Mono`), 10–12px, uppercase, `letter-spacing .08em` |
| Карточки | белые, рамка 1px `#1d1f21`, без скругления или 2px, акцентная плашка с номером |
| Выноски | 1px `#1d1f21`, ломаная под 0°/45°, кружок 3px на детали |

Нельзя: тёмный фон, глянец (`metalness 1`, `roughness < 0.2`), HDRI-окружение, густые тени,
текстуры, bloom, эмодзи, больше двух акцентных цветов, подписи поверх модели.

## Компоновка

```
┌──────────────────────────────────────────────┐
│ ШАПКА: FIG. 01 — НАЗВАНИЕ СБОРКИ   REV / DATE │
│ ┌────────┐                       ┌────────┐ │
│ │ 01 ... │──────┐   [деталь]  ┌──│ 04 ... │ │
│ └────────┘      └──○          ○──┘└────────┘ │
│ ┌────────┐       [деталь]                    │
│ │ 02 ... │─────○  [деталь]   ○───┌────────┐ │
│ └────────┘                       │ 05 ... │ │
│         ─ ─ ─ ось сборки ─ ─ ─    └────────┘ │
│ ФУТЕР: масштаб, легенда цветов, слайдер       │
└──────────────────────────────────────────────┘
```

На узких экранах (< 760px) панели уходят под канвас, выноски скрываются, карточки получают номера,
а на модели остаются маленькие номерные метки.

## Реализация (шаблон)

- `parts[]` — `{ id, mesh(group), base: Vector3, dir: Vector3, accent? }`; в `tick()`:
  `part.group.position.copy(base).addScaledVector(dir, explode * spread)`.
- `labels[]` — `{ id, side: 'left'|'right', title, note, anchor: Object3D, bar? }`.
  Проекция: `anchor.getWorldPosition(v).project(camera)` → пиксели канваса → SVG `path`.
- Медленное вращение группы (`0.08 rad/s`), пауза при наведении/перетаскивании.
  `OrbitControls` — только если нужен интерактив (в шаблоне включён, `enablePan: false`).
- Анимация входа: `explode` плавно 0 → 1 за ~1.6 с (easeInOutCubic).
- `?still=1` — без вращения и без контролов (для рендера картинки); `?explode=0.6` — фиксированное разнесение.
- React Three Fiber — только если проект уже на React: `Part`-компоненты с `group position`,
  подписи — HTML-оверлей поверх `<Canvas>`, та же проекция в `useFrame`.

## Чек-лист перед отдачей

- [ ] Фон светлый и пустой, сетка едва видна.
- [ ] Формы геометрические, детали логично стыкуются при `explode = 0`.
- [ ] Разнесение явно читается, детали не перекрывают друг друга.
- [ ] 4–7 подписей, все читаются, выноски не пересекаются и не лезут на карточки.
- [ ] Акцентов ≤ 2 цветов и ≤ 3 деталей, каждый осмысленный.
- [ ] Выглядит как страница инженерной документации, а не игровой ассет.
- [ ] Нет ошибок в консоли; на ширине 390px нет горизонтального скролла.
