# Огненный сплит (Remotion)

Вертикальный рилс 1080×1920, 30 fps, собирается **кодом** из готового кита `kit/` (Remotion + React).
Источник стиля — 16 сравнительных клипов «РЕФЕРЕНС / ПЕРЕНОС В ПАК» (октябрь 2026). Делаем как **левая сторона
(референс)**; правая («перенос в пак») вышла бледнее, ошибки перечислены в §8.

- Все кадры референса: `references/atlas.jpg` (сетка) и `references/frames/*.jpg` (540×960). **Перед работой открой атлас**.
- Подробно по каждому приёму (что в карточке, тайминг, какая фраза): `references/scenes.md`.
- Код: `kit/src/tokens.ts` (все цвета, размеры, тайминги), `kit/src/ui/core.tsx`, `transitions.tsx`, `widgets.tsx`,
  пример ролика: `kit/src/Demo.tsx`.

`K=~/.claude/skills/reels-ember-split/kit` (в репозитории — `.claude/skills/reels-ember-split/kit`).

## 0. Порядок работы

1. **Сырьё.** Говорящая голова (вертикальная, лицо по центру, тёплый свет) + сценарий. Нет сценария — сначала `reels-script`.
   Чужие ники, лица и ассеты из референса не используем: в карточках ник, аватар и CTA Ильи.
   **Если прислали уже смонтированный рилс** — лицо из него не брать (в нём графика и экраны без лица). Найти чистый
   исходник: аватар HeyGen — `list_videos` по названию ролика (например «Ремейк · <slug> · look 61»), `get_video` → `video_url`.
   Перед монтажом — паузы > 0.25 с вырезать, лёгкий тёплый грейд, громкость −14 LUFS (команды — в примере, §10).
2. **Слова с таймингом.** `faster-whisper` с `word_timestamps=True` (или ElevenLabs `with-timestamps`) → `public/words.json`
   `[{text, start, end}]`. Кадр слова = `round(start*30)`. Паузы > 0.25 с вырезать заранее (ffmpeg).
3. **Раскадровка.** Таблица битов до рендера: для каждой фразы — режим (`face` / `split`), приём карточки (§5),
   какое слово уходит в оранжевую плашку, где переход. Показать Илье таблицей.
4. **Проект.** `cp -r $K reel-<slug> && cd reel-<slug> && npm i`, видео лица → `public/face.mp4`.
   Сцены собираются по образцу `src/Demo.tsx`: `CubeSwitch`/`ZoomSwitch` между режимами, внутри сплита `Sequence` на фразу,
   в каждой — `GlowCard` (с новым `swapAt`) + виджет + `CaptionLine`.
5. **Превью:** `npx remotion still src/index.ts Main out/p.png --frame=N` на ключевых кадрах, потом
   `npx remotion render src/index.ts Main out/preview.mp4 --scale=0.5`. Показать.
6. **Финал:** `npx remotion render src/index.ts Main out/reel.mp4 --codec=h264 --crf=18`, затем звук голоса (см. §7).
7. Правки — через `tokens.ts` и пропсы, не покадрово. Решения Ильи — в §11 этого файла.

## 3. Раскладка кадра (1080×1920)

**Режим `split`** (основной, ~75 % ролика):

| Элемент | Позиция | Детали |
|---|---|---|
| Карточка | x 90, y 192, 900×700, радиус 48 | `GlowCard`: обводка + свечение, сетка, серая подпись-заголовок 28 px по центру сверху (y +30) |
| Подпись | центр строки y 951 | `CaptionLine`: 46 px / 800, строчные, белые, одна строка 1–4 слова |
| Лицо | x 76, y 1012, 928×850, радиус 48 | `FaceFrame`: та же обводка; лицо крупно (масштаб ~1.18, видно от макушки до груди) |

**Режим `face`** (хук, «самое интересное», CTA): лицо на весь кадр, без рамки.
`FaceCaption`: ЗАГЛАВНЫЕ, Montserrat 900, 88 px, межстрочие 94, по центру, первая строка на y≈1265, строки
**добавляются вниз**. Длинная строка автоматически ужимается (CTA «НАПИШИ В КОММЕНТАРИЯХ» ≈ 60 px).
Одна строка на плашке: **красной** (`red`, белый текст) — главный тезис хука; **белой** (`text`, чёрный текст) — кодовое слово CTA.
Мелкая серая плашка-дисклеймер «Meta признана экстремистской…» внизу (y ≈ 1730, 17 px, 35 % белого) — в каждом кадре с лицом, если говорится про Instagram.

## 4. Анимация (кадры при 30 fps)

- **Слово**: появляется на кадре своего таймстемпа — opacity 0→1, blur 8→0, сдвиг вверх 6 px, **4 кадра**, easeOut.
- **Плашка ключевого слова**: появляется вместе со словом — scale 0.82→1, blur 6→0, **5 кадров**. Одна плашка на фразу,
  обычно последнее смысловое слово («подключаться», «скилл», «задачу», «субагентов», «11 штук», «комментарии»).
  Цифры — короткой квадратной плашкой перед словом («[21] проверенный хук»).
- **Смена фразы**: старая строка убирается жёстким катом, новая начинается с первого слова. Нет «караоке-подсветки».
- **Смена содержимого карточки** (рамка остаётся на месте!): старое уходит, новое въезжает смазом — blur 14→0,
  сдвиг −40 px, растяжение по X 1.08→1, **7 кадров** (`GlowCard swapAt`).
- **Блик**: на каждый новый контент через 3 кадра по карточке проходит диагональная световая полоса (24°, ~130 px,
  `screen`), слева направо за **14 кадров**.
- **Внутри карточки** — каскады: строки по одной с шагом 3–5 кадров (rise + blur), чипы pop с шагом 2 кадра,
  полосы растут за 14–30 кадров easeOut, числа считаются вместе с полосой, печать 14–30 симв/с с оранжевым блок-курсором.
- **Ритм**: новое событие (слово, строка, плашка, смена карточки) каждые 0.3–0.8 с. Статики > 1 с нет.

## 5. Переходы

- **Куб** (`CubeSwitch`, 12 кадров, inOut cubic): весь кадр поворачивается влево вокруг вертикальной оси, следующая сцена —
  правая грань куба; в середине куб отъезжает до 0.86, motion blur до 7 px, видно тлеющий фон. Используется
  **лицо → сплит** и **сплит → лицо** (01→02, 04→05, 11→12, 15→16).
- **Зум-сквозь** (`ZoomSwitch`, 10 кадров): старая сцена улетает в камеру (scale 1→1.6, blur до 16, исчезает), новая
  проявляется из 0.88 с размытием. Для «удара» — вход в лицо с крупной фразой («ПОЛНОСТЬЮ БЕСПЛАТНЫЙ», CTA).
- Внутри сплита сцена не переключается — меняется только содержимое карточки (смаз + блик) и подпись.

## 7. Звук

Клипы референса без звука, поэтому звук задаём сами: голос −14 LUFS; тихие SFX −24…−20 дБ: `whoosh` на куб и зум,
`pop` на плашку, `tick` на строку каскада, мягкий `type` на печать; музыка — в Instagram при публикации.
Склейка голоса: `ffmpeg -i out/reel.mp4 -i voice.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -shortest out/final.mp4`.

## 8. Чем «перенос в пак» хуже референса — не повторять

- Свечение рамок тонкое и тусклое → у референса **3 слоя**, ярко-оранжевое ядро и широкий ореол (`T.glow`).
- Плашка ключевого слова приглушённая, полупрозрачная → нужна **сплошная `#F65A0A`**, белый текст 800.
- Текст в карточках мельче, заголовки 60–64 px → в референсе **80–92 px** и карточка заполнена.
- Лицо в рамке мелкое, видно комнату → **крупнее**, лицо занимает рамку.
- Подписи-ярлыки карточек едва видны → 28 px, `#8C8580`.
- Хук на лице: строки в пак-версии мельче → **88 px, 900**, плашка на всю строку.

## 9a. Озвучка: ударения и темп

TTS-голос HeyGen путает ударения и «ё». Текст для HeyGen готовится отдельно от подписей:
- все «ё» на месте (ведёт, берёт, выдаёт, продаёт, моё, трёхсот);
- знак ударения ◌́ (U+0301) на каждом многосложном слове, где ошибка возможна (виру́сится, автопило́те, тра́тя, ро́лики,
  залете́ли, ни́ше, сценари́ста, ко́довое, полу́тора, Пра́ктикум…);
- **голос — родной голос образа** (`default_voice_id` образа в `list_avatar_looks`; для «ilia.paliy -- 61» — `8124c638…`,
  движок ElevenLabs), а не `avatar.voice_id` из конфига ремейка: так решил Илья 31.10;
- бренды и числа словами: Клод, Хе́йген, «два́дцать четы́ре на семь», «И-И́ аге́нт»;
- темп: `speed` в `create_speech` ElevenLabs-голоса ускоряет слабо (1.1 дал ~4 %). Ускорение добивается `atempo`
  (высота голоса не меняется) до нужной длины — исходник ÷ 1.1, затем аудио загружается в HeyGen (`create_asset_upload` →
  PUT → `complete_asset_upload`) и идёт в `create_video_from_avatar` как `audioAssetId`. Ускорять готовое видео нельзя — ускорятся и анимации.
Порядок: `create_speech_without_player` (дёшево) → проверка расшифровкой, что не выпали слова, → mp3 Илье послушать →
`create_video_from_avatar` с этой озвучкой (образ тот же). Пример текста: `kit/src/examples/blog-avtopilot/script-heygen.txt`.
Новый дубль подхватывается без ручной правки кадров: `python3 -I scripts/prep_face.py <raw.mp4> <проект>` режет паузы, грейдит,
расшифровывает и перекладывает `words.json` на новый дубль по тем же индексам слов; границы блоков в `Reel.tsx` считаются от слов.

## 10. Пример целого рилса

`kit/src/examples/blog-avtopilot/Reel.tsx` — готовый 55-секундный рилс (лицо Ильи, аватар HeyGen look 61): список блоков
`face`/`split` с переходом в конце каждого, карточки по кадру старта, фразы из `words.json` по индексам слов
(текст пишется руками — так исправляются ошибки распознавания: «клод» → Claude, «Хейджен» → HeyGen, «блок» → блог).
Для нового ролика копируй его, меняй `BLOCKS`. Подключение: в `Root.tsx` `<Composition id="Reel" component={Reel} durationInFrames={REEL_FRAMES} …/>`.

Подготовка лица (Python + ffmpeg): `faster-whisper small` с `word_timestamps=True` (аудио передавать numpy-массивом из wav 16 кГц) →
отрезки речи с полями 0.08 с, склейка `trim/atrim + concat` с микро-фейдами 15 мс → `fps=30,colorbalance=rs=0.06:gs=-0.04:bs=-0.06:rm=0.05:gm=-0.03:bm=-0.05,eq=saturation=0.92:contrast=1.04,vignette=PI/5`,
`loudnorm=I=-14` → `public/face.mp4`; повторная расшифровка уже порезанного файла → `words.json` (`{text, f}` в кадрах).
Кадр для карточек: `public/avatar.jpg`. Видео рендерится без звука, голос подклеивается из `face.mp4` (§7).
