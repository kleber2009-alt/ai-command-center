# Референс по сценам (16 клипов «РЕФЕРЕНС / ПЕРЕНОС В ПАК»)

Ролик референса — 40–50 с, тема «бесплатный Instagram Agent Skill для Claude». В шапке каждого клипа был код
приёма из пака (`X.*` — приём, `K.*` — компонент, `SPARK` — иконка Claude); он указан для связи с паком.
Кадры: `frames/<NN>-*.jpg`. Время — от начала клипа.

| # | Код в паке | Режим | Фраза (слова → **плашка**) | Что происходит |
|---|---|---|---|---|
| 01 | `X.face_lines + куб (css-3d + css-push)` | face | CLAUDE / ОСТАВИЛ / SMM-ЩИКОВ / **[красн.] БЕЗ РАБОТЫ** | Слова по одному, строки копятся вниз; 3-я строка на красной плашке. В конце — куб влево в сплит |
| 02 | `X.connect: SPARK + K.ig + draw()` | split | теперь **Claude** · может **напрямую** · **подключаться** | Карточка «прямое подключение»: плитка Claude по центру → уезжает влево, справа плитка Instagram, линия прорисовывается, белая пилюля «✓ подключено»; заголовок «напрямую» белым + «к Instagram» оранжевым |
| 03 | `X.profile: сетка s01-hook + de-chip` | split | к вашему **Instagram-аккаунту** · и **вести** его за вас | Профиль: аватар, ник, оранжевый бейдж «Claude ведёт аккаунт», вкладки Публикации/Reels/Отметки; плитки-посты (оранжевые, фиолетовые, тёмно-бирюзовые) заполняют сетку 3×2 по одной |
| 04 | `X.title_type: печать s12/s13` | split | это называется **Instagram** Agent Skill | Иконка IG + печать «Instagram» белым, затем «Agent Skill» оранжевым, блок-курсор; ссылка github серым под заголовком. Конец — куб в лицо |
| 05 | `zoom through (css-scale) + X.face_lines` | face | ПОЛНОСТЬЮ / **[красн.] БЕСПЛАТНЫЙ** | Влёт зумом с размытием в лицо; затем куб обратно в сплит |
| 06 | `X.chips: pop-стаггер s01-hook` | split | причём не **один скилл** · их целых **11 штук** | Один чип `/ig-reel` в центре → сетка 3×4 чипов, pop по одному |
| 07 | `X.tasks: каскад строк s12-skill` | split | и каждый **скилл** выполняет свою **задачу** | 5 строк `/ig-reel → сценарий и хук для рилса` … каскадом сверху вниз |
| 08 | `X.post: печать + бары/счётчик K.count` | split | один пишет вам **посты** используя **[21]** проверенный хук | Чип `/ig-reel` + «новый пост», текст печатается; бейдж «проверенные формулы хуков»; 3 бара с числами 86/79/71 растут |
| 09 | `X.week: календарь coaching-call-clips` | split | другой будет вам полностью **планировать** **контент** на **определённое время** | Колонки Пн–Вс; оранжевые «Reels» и фиолетовые «Карусель» падают в дни; позже белые бейджи времени ◷ 18:00 |
| 10 | `X.comments: строки + печать` | split | следующий **отвечает** на **комментарии** которые вы получаете | 3 комментария (цветные аватары-буквы), под каждым ответ автора с оранжевым бейджем, ответ печатается. Конец — куб в лицо |
| 11 | `X.face_lines (красный блок) + куб` | face | САМОЕ ИНТЕРЕСНОЕ / **[красн.] HUMANIZER** | Как 01; затем куб в сплит |
| 12 | `X.humanize: strike/hl из K.notion` | split | он не только удаляет **длинные тире** но и **убирает** **водяной знак** Claude из текста | Текст поста: тире «—» в красных рамках → заменяются запятыми, пилюля «✓ длинные тире → запятые»; ярлык меняется на «водяной знак Claude», невидимые символы подсвечены красными квадратиками → удалены, «✓ невидимые символы удалены» |
| 13 | `X.checks: agent-progress-theater` | split | а затем прогоняет их через 5 разных **субагентов** | 5 строк (Ритм, Конкретика, Штампы, Почерк ИИ, Голос автора) с моно-подписями, полосы растут с разной скоростью, зелёные галочки |
| 14 | `X.slider: слайдер s02 BB_ALT` | split | чтобы понять что текст написан **не как ИИ** | «результат проверки»: шкала красный→зелёный, бегунок слева направо, «текст написан» белым + «не как ИИ» оранжевым |
| 15 | `X.claude: окно K.chat + печать` | split | и чтобы **установить** просто зайди в **Claude** скинь ему ссылку и скажи чтобы он всё **поставил** | Окно Claude: приветствие «Чем займёмся, …?» печатается, ссылка github вставляется в поле, уходит пузырём, ответ «Готово: 11 скиллов установлены ✓». Конец — куб в лицо |
| 16 | `zoom through + X.face_lines (белый блок)` | face | НАПИШИ В КОММЕНТАРИЯХ / **[бел.] «ИНСТАГРАМ»** / Я ТЕБЕ ВСЁ СКИНУ | Влёт зумом в лицо, строки копятся, кодовое слово на белой плашке чёрным |

## Структура ролика

`face-хук (3 с)` → куб → `split ×3` → куб → `face-удар` → куб → `split ×5` → куб → `face-поворот` → куб →
`split ×4` → зум → `face-CTA`. Сплит-блоки идут без пауз: карточка не исчезает, меняется содержимое.
