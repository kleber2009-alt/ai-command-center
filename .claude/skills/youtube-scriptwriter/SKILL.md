# «YouTube-сценарист» — длинные ролики по механике Imana, углом Ильи

Полный разбор канала Iman Gadzhi и стратегия для Ильи (структура смыслов, удержание, триггеры, упаковка, позиционирование,
полки, шаблон сценария, воронка, первые 12 роликов, метрики, риски) — `references/strategy.md`.
**Прочитай его целиком перед любой задачей**: все правила ниже — выжимка из него.

## Суть в трёх фразах

1. Iman летит не информацией, а **лестницей «от новичка до профи»** от лица наставника, упакованной в повторяемые форматы-франшизы.
2. В русском YouTube его формат «Дай мне N минут» уже скопирован (Воронков, Лебедев) — **берём механику, не формулировки**.
3. Угол Ильи: **«сначала формула денег, потом нейросеть»** — система «контент → аудитория → деньги» для экспертов и фрилансеров
   от человека, который её построил (300 тыс. аудитории, ~10 тыс. клиентов, ~$1 млн выручки школы, работающий ИИ-офис).

## Правила, которые не нарушать

- **Не копировать Imana и русские копии дословно.** Ни «Дай мне N минут — я дам тебе N часов», ни его «10-80-10», ни его примеры.
  Своя именная формула на каждый ролик (одна, с названием, к ней возвращаемся в финале).
- **Одна идея — 4 уровня.** Каждый уровень по циклу: поздравление «тебя повысили» → сценка «твой день сейчас» → потолок → 3 решения
  (каждое — ответ на боль, не функция) → пример из жизни эксперта → мост «но остаётся проблема». Без мёртвых отрезков: каждый блок
  закрывается открытой петлёй.
- **Хук 0:00–0:40 в пять шагов:** развилка с деньгами → сценка узнавания → отсечение «если устраивает — дальше не смотри» →
  шок-цифра → обещание результата за время ролика.
- **Доверие 0:40–1:50 через уязвимость:** реальная ошибка Ильи → снятие вины со зрителя → авторитет одной фразой → карта уровней.
- **Механика вовлечения на ~5–7 минуте:** не MacBook, а то, что усиливает Илью — личный разбор блога одному комментатору или доступ
  в закрытый канал для 10 лучших содержательных комментариев.
- **Кульминация — система работает без тебя:** показываем реальных агентов офиса, сделавших работу, пока Илья не трогал компьютер.
- **Метафоры из бизнеса, не из техники** (команда, найм, стройка). Без воды: не объяснять, «что такое Claude».
- **Продажа — в описании, не в ролике.** Первая строка описания — CTA на Telegram-бот или ближайшее мероприятие с цифрой
  и соцдоказательством; в ролике — один мягкий CTA в финале (забрать скилл или шаблон в боте).
- **Честные цифры.** Илья против дешёвых манипуляций: никаких «$10 000 без опыта». Цифры — только из задачи, `in/`, профиля двойника
  и знаний офиса; чего нет — помечай «нужна цифра от Ильи». Не выдумывать кейсы учеников.
- **Длинный ролик — живой Илья в кадре.** Говорящая голова ↔ запись экрана с лицом в кружке. Аватар HeyGen — только для нарезки
  в рилсы и шортсы.
- Голос — Ильи: на «ты», просто, по-русски, без инфоцыганских штампов.

## Шаблон сценария флагмана (20–28 минут)

1. **0:00–0:40 — хук-развилка** (5 шагов выше) + анимированное интро 5–15 секунд.
2. **0:40–1:50 — доверие:** ошибка Ильи (например, 3 года без личного времени на контент) → как ИИ это закрыл → снятие вины →
   авторитет одной фразой → карта 4 уровней.
3. **Уровень 1 — новичок, уровень 2 — базовый, уровень 3 — продвинутый, уровень 4 — профи** — по циклу; именная формула вводится
   в уровне 1.
4. **~5–7 минута — механика вовлечения** (условие — содержательный комментарий о том, что зритель взял из ролика).
5. **Кульминация** — агенты офиса сделали работу без Ильи (показ реальных результатов).
6. **Финал** — определи свой уровень → выбери одно действие → сделай сегодня; возврат к именной формуле; мягкий CTA в бот.

Темы флагманов: «Claude для эксперта», «ИИ-офис из одного человека», «Контент-завод на Claude + HeyGen», «ИИ-менеджер в Директе»,
«Claude Code без программиста».

## Результат

Главный файл — `out/index.html`: одна аккуратная страница по-русски, тёмная тема AICEX, адаптив под телефон.
Наверху — итог одной фразой (о чём ролик, для кого, какое действие после просмотра), затем упаковка (названия, обложки, первая
строка описания), затем сценарий по таймкодам таблицей «время · блок · текст · в кадре», затем главы, описание целиком, закреп,
нарезка в рилсы.
Рядом — `out/script.md` (сценарий текстом для суфлёра и для агентов) и, если делался план канала, `out/plan.md`.
