# Разбор оригинала: whitemark-site

Сайт агентства недвижимости в Дубае, 7 страниц, ~314 КБ HTML + 12 МБ картинок/видео.
Каждая страница — один файл со своим `<style>` и инлайн-скриптами (CSS
дублируется). В скиле то же самое разнесено на `site.css` + `site.js` + `data.js`,
поведение сохранено.

## Страницы и секции

| Страница | Секции |
|---|---|
| `index.html` | интро-лого → скраб-hero (видео 5 с, контейнер 2 экрана) → плавающая панель поиска (табы + 4 CSS-дропдауна) → «Featured» 6 карточек → услуги 01–04 → отзывы-бегущая строка (2 ряда) → основатель → форма заявки → футер |
| `buy.html` / `rent.html` / `off-plan.html` | hero-картинка → каталог из JS-объекта: фильтры (локация, цена, площадь, тип, спальни, удобства), сортировка, пустое состояние → модалка «Запросить показ» → процесс 01–03 → CTA |
| `property.html?id=` | крошки → заголовок → галерея с миниатюрами и лайтбоксом + липкая боковая карточка (цена, 3 цифры, аккордеон условий, агент, CTA) → описание → удобства-чипы → таблица характеристик → карта → похожие |
| `about.html` | hero с вырезанным портретом (mask-image) → принципы 01–03 → фото команды → цитата на фоне фото → опыт 01–03 → CTA |
| `contact.html` | hero-фото → контакты + форма в панели → карта |

## Приёмы и где они в движке

| Приём | Оригинал | Движок |
|---|---|---|
| Отрисовка логотипа | SVG `mask` из штрихов поверх `logo.png`, `stroke-dashoffset 1→0`, задержки .2/.5/.8 с | `.intro .d/.d2/.d3`, знак в `partials/mark.html` (штрихи без маски) |
| Шторка интро | `clip-path: inset(0 0 100% 0)` в 3.6 с | то же в 3.2 с + показ раз за сессию (`sessionStorage`) |
| Скраб-видео | `#scroll-container{height:200vh}`, `#hero{position:sticky}`, `video.currentTime = p*duration`, `requestVideoFrameCallback` | `.scrub` (`--scrub-len`), `.hero`, модуль в `site.js` |
| Видео для скраба | `hero-scrub.mp4`: 1280×704, 32 fps, 161 кадр, **27 ключевых кадров** (GOP 6); обычный `hero-video.mp4` — 1 ключевой кадр | `scripts/scrub-video.sh` (`-g 6 -keyint_min 6 -bf 0 -an +faststart`) |
| Плавная прокрутка | `wheel` → `preventDefault`, цель += deltaY×1.2, `scrollTo` с lerp 0.09 в rAF; выключено на `pointer:coarse` | то же, плюс не перехватывает колесо в меню/диалогах/textarea |
| Подсказка скролла | линия 1×48 px, `scaleY` туда-обратно, гаснет на первых 12 % | `.scroll-hint` |
| Дропдауны | radio + `div[tabindex]` + `:focus` открывает `.menu`, `nth-of-type` показывает выбранное | radio + `:focus-within`; текст выбранного ставит JS |
| Попап звонка | checkbox `#ph` + `label`, кнопка с `pulse` и «звонящей» иконкой | `.fab` + `.pop`, кнопка-переключатель |
| Формы | без отправки: label-кнопка ставит checkbox «отправлено», `:has(.rq:placeholder-shown)` гасит кнопку | `form.lead-form`: `required`, `.off` до валидности, оверлей `.done`, отправка в `SITE.leads` |
| Отзывы | две дорожки `.tmt` по 110/130 с навстречу, карточки продублированы в HTML, маска по краям, пауза по hover | то же, дубли создаёт JS |
| Появление | `IntersectionObserver` + задержка `i*120ms` | `.rvl` → `.in`, задержка по индексу среди соседей |
| Каталог | объект `D` в инлайн-скрипте, рендер карточек, фильтры-модалки, `localStorage` избранного | `SITE_DATA.items/filters/sorts`, фильтры-пилюли, `?key=value` из панели поиска |
| Карточка | `?id=`, галерея собирается из пула картинок по хэшу id | `?id=`, `item.gallery`, лайтбокс со стрелками и Esc |

## Типографика и цвета оригинала

- Manrope: 300 — H1 `clamp(40px,5.4vw,78px)/1.05`, H2 `clamp(30px,3.5vw,47.5px)/1.08`;
  400 — текст 15–17 px / 1.7; 500 — надзаголовки 12 px, `letter-spacing:.32em`, капс.
- `#0b0b0c` фон, `#121214` панели, `#0f0f10` футер, текст `#f2efe9`, вторичный
  `#d9d4ca`, приглушённый `#a8a299`, акцент `#c8a46a` (hover `#d8b87e`).
- Карточки: картинка 1:1, радиус 22 px, бейдж-пилюля 27 px, hover — zoom 1.04 за .6 с.
- Кнопки: пилюля 52 px, 12 px капс `.16em`, заливка акцентом; вторичная — контур
  `rgba(242,239,233,.45)`.
- Сетка: контейнер 1280 px, поля 56 px (24 px на планшете, 16 px на телефоне).
