# Кинематографичный сайт (технология White Mark)

Статический сайт без фреймворков: HTML + один CSS + один JS, грузится с любого
хостинга (Caddy, Netlify, GitHub Pages). Вся «магия» — в пяти приёмах, они уже
реализованы в `template/assets/site.css` и `site.js`. Ты пишешь только контент.

Рабочий пример, собранный этим скилом: `landings/ai-office-noir/` (AI Growth Office).
Подробный разбор оригинала: `reference/anatomy.md` — прочитай, если меняешь движок.

## Что делает сайт «дорогим»

1. **Интро** (только главная, раз за сессию): SVG-знак рисуется штрихом
   (`stroke-dasharray` + `pathLength="1"`), проявляется название, шторка уезжает
   вверх `clip-path` за 1.1 с. Есть «Пропустить» и `prefers-reduced-motion`.
2. **Hero со скраббингом видео**: секция `position:sticky` внутри контейнера
   высотой 2–2.2 экрана; позиция скролла → `video.currentTime`. Ключ к плавности —
   видео с ключевым кадром каждые 6 кадров (`scripts/scrub-video.sh`) и
   `requestVideoFrameCallback`, чтобы не ставить seek, пока прошлый не отрисован.
3. **Плавная прокрутка колесом** (десктоп, только на странице со скраб-hero):
   колесо двигает цель, страница догоняет её с коэффициентом 0.09 — эффект
   «операторской тележки». На тач-устройствах — нативный скролл.
4. **Сдержанная система**: Manrope 300/400/500, почти чёрный `#0b0b0c`, один
   металлический акцент `#c8a46a`, линии `rgba(255,255,255,.14)`, кнопки-пилюли,
   надзаголовки капсом с разрядкой .32em. Цвета — только токены в `:root`.
5. **Живые детали**: появление блоков по скроллу с задержкой по порядку, бегущие
   отзывы в два ряда навстречу (пауза при наведении, на мобиле — свайп),
   пульсирующая кнопка звонка с попапом, выпадающие списки на чистом CSS.

## Порядок работы

1. **Собери вводные** (спроси, если нет): название и что продаём; 4–6 страниц
   (по умолчанию: главная, каталог, карточка, тарифы/услуги, о нас, контакты);
   список позиций каталога; контакты; куда слать заявки (webhook, Supabase,
   Telegram-прокси); есть ли фото/видео. Тексты — только реальные факты клиента:
   не выдумывай отзывы, цифры и регалии. Нет отзывов — делай блок «Примеры задач»
   и честно подпиши, что это сценарии.
2. **Каркас**: `bash scripts/new-site.sh landings/<slug>` — скопирует движок,
   партиалы, страницы-пример и 3D-сцену, соберёт HTML.
3. **Контент**:
   - `assets/data.js` — `SITE` (имя, отправка заявок) и `SITE_DATA` (позиции
     каталога, фильтры, сортировки). Карточки, каталог, страница позиции и
     «похожие» рендерятся отсюда. Поля позиции — см. шаблон `data.js`.
   - `_source/partials/` — head, header (меню), footer, fab (звонок), dialog
     (заявка), mark (SVG-знак: 2–3 пути с классами `d d2 d3`, рисуются в интро).
   - `_source/pages/*.html` — страницы. Первая строка
     `<!--page nav=... title="..." desc="..."-->`, вставка блоков `<!--@header-->`.
     Пример страниц — AI Office: перепиши тексты, состав секций оставь.
   - Данные уже есть в другом приложении (каталог, команда, история) — не копируй руками,
     напиши импорт, который генерирует `data.js` (пример: `landings/ai-office-noir/_source/import-hq.js`).
   - Сборка: `python3 scripts/build.py landings/<slug>`. Правь только `_source`
     и `assets`, корневые `*.html` генерируются.
   - Палитру клиента клади отдельным `assets/theme.css` поверх `site.css` (только токены
     `:root` и пара уточнений) — движок остаётся общим.
4. **Визуал** — нужно: `hero-scrub.mp4` + `hero-poster.jpg`, фото для карточек
   (1:1), широкие кадры для hero внутренних страниц (16:9), портрет 4:5 для блока
   основателя, `og.jpg` 1200×630.
   - Есть видео клиента (дрон, пролёт камеры, 4–6 с, плавное движение без склеек):
     `bash scripts/scrub-video.sh in.mp4 img/hero-scrub.mp4`, постер — первый кадр
     (`ffmpeg -i img/hero-scrub.mp4 -frames:v 1 img/hero-poster.jpg`).
   - У клиента уже есть 3D/WebGL-сцена (офис, шоурум, конфигуратор) — снимай её саму:
     локальный сервер, интерфейс скрыт CSS, `performance.now` подменён виртуальными часами,
     камера ставится на каждый кадр, кадр = скриншот. Готовый пример —
     `landings/ai-office-noir/_source/hq-capture.js` (живой офис hq2: видео, общие планы,
     кадр каждого персонажа за своим столом). Так сайт и продукт выглядят одинаково.
   - Нет видео — строй 3D-сцену бренда на three.js по образцу
     `_source/scene.html` (контракт: `SCENE_READY`, `SHOTS`, `renderAt(shot,t)`)
     и рендери всё из неё одним скриптом:
     `node scripts/render-frames.js --scene _source/scene.html --out img --video hero`
     и `--stills <shot,...> --still-w 1000 --still-h 1000` для кадров.
     Один свет, одна палитра, разные ракурсы — так сайт выглядит как съёмка.
   - Можно сгенерировать фото/видео в Higgsfield/HeyGen, если пользователь
     согласен тратить кредиты — спроси перед генерацией.
5. **Проверка**: `node scripts/check.js landings/<slug> <scratchpad>/qa` —
   скриншоты 1440 и 390 px, ошибки консоли, битые картинки, горизонтальный
   скролл. Посмотри скриншоты сам. Отдельно проверь скраббинг: прокрути главную
   на 0/50/100 % и убедись, что `video.currentTime` меняется.

## Правила

- Язык UI — язык клиента; иконки — инлайн-SVG, без эмодзи.
- Hero-текст всегда слева, затемнение `.shade` слева направо и к низу —
  видео справа должно «дышать».
- Акцентный цвет — только на надзаголовках, цифрах, ценах и главной кнопке.
- Одна главная кнопка на экран; вторая — контурная `.btn.o`.
- Каждая форма — `form.lead-form` с `data-source`; обязательные поля — `required`.
  Ключи и токены, которые нельзя светить в браузере, — только через серверный
  прокси (как `/api/notify-tg`), не в `data.js`.
- Видео hero ≤ 5 МБ (1280 px, CRF 23). Тяжелее — понизь `CRF` или `WIDTH`.
- Перед коммитом — `check.js` без ошибок и просмотр скриншотов.
