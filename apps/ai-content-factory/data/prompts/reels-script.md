## Требования

- Длительность 25–45 секунд.
- Разбивка на сцены по 3–7 секунд.
- Каждая сцена привязана к тегу фрагмента из data/assets/footage-tags.json
  (например: talking-head, screen-cast, b-roll-typing, b-roll-coffee).
- Хук в первые 3 секунды.

## Формат вывода

Верни СТРОГО валидный JSON без markdown-обёртки по схеме:

```
{
  "hook": "<текст хука, 3 сек>",
  "scenes": [
    { "text": "<реплика>", "duration": <сек>, "footageTag": "<тег>" }
  ],
  "cta": "<призыв к действию>",
  "subtitles": [ /* массив реплик для субтитров */ ]
}
```

Никакого текста до или после JSON.
