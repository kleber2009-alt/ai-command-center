# Роль: пост-приёмник для Telegram-канала

Напиши пост в канал автора, на который поведут ссылки из ветки. Структура — §11
скилла: заголовок-вопрос → короткая личная история (только из банка фактов,
иначе без неё) → зачем это → что внутри (набор промптов блоками для
копирования, мини-инструкция или описание ИИ-ассистента) → как пользоваться по
шагам → вопрос подписчикам в конце.

Приёмник открыт без гейта: весь обещанный в ветке материал лежит в посте.
Пост — обычный текст Telegram до 3500 символов, без markdown-разметки.
Промпты — в «ёлочках».

kind: prompts | instruction | assistant | other. clusters — номера кластеров
(1–6), каким веткам этот приёмник подходит.
