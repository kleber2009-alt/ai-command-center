# Threads → Telegram: система «ветка-инструмент»

Скилл воспроизводит механику аккаунта @petkova_anjela (Threads: 143K подписчиков, ~1,9 млн просмотров за последний период; Telegram @anjela_p: 78K подписчиков). Разобрано ~380 публикаций за май–октябрь 2026 (244 уникальных хука), 4 ветки целиком и посты-приёмники в Telegram. Цифры и подробности — в `references/analysis.md` (если файла нет рядом, всё нужное для работы уже есть ниже).

Берём механику. Чужие формулировки, промпты и результаты не копируем: у Анжелы это правило тоже есть («забираем механику, формулировки не копируем»).

## 0. Что нужно на входе

Перед генерацией спроси (или возьми из памяти/брифа) то, чего не хватает:

1. **Ниша и продукт**: что продаём в конце воронки (курс, наставничество, клуб, фокус-группа).
2. **Telegram-канал и библиотека приёмников**: список постов канала с лид-магнитами (ссылка + что внутри). Без приёмника ветку не публикуем.
3. **Голос**: 3–5 собственных текстов автора + желаемая громкость (см. §8).
4. **Подтверждённые результаты и кейсы**: цифры, скрины, истории учеников. Только реальные.
5. **Табу**: темы, слова, обещания, которые автор не использует.

Если чего-то нет, ставь `[уточнить]` и продолжай. Результаты и цифры никогда не выдумывай.

## 1. Шесть принципов системы

1. **Ветка = упакованный инструмент, а не мнение.** Каждая ветка отдаёт готовый промпт / пошаговую связку, которую можно применить за 5–40 минут. Такую ветку сохраняют и пересылают: у лучших публикаций «отправить» ≥ лайков (1,5K шеров при 2,5K лайков; 1,2K шеров при 1,1K лайков).
2. **Широкая жизненная боль × твой инструмент.** Больше всего трафика собирают не темы «ИИ для бизнеса», а ИИ, применённый к личной жизни массовой аудитории: психология, деньги, стиль, отношения, тело, английский, путешествия. Ветка про метод продвижения в Threads у неё же набрала 613 просмотров; прожарка «что о тебе знает GPT» — 1,1 млн.
3. **Объём + повтор победителей.** 3 слота в день, публикация по расписанию (точно в :00–:02, вторая часть ветки через ~13 секунд, т.е. автопостинг). ~35% публикаций — перевыпуски победителей. Лучшую ветку (ревизия гардероба) она выпустила 24 раза за 5 месяцев.
4. **Хук решает всё, тело переиспользуется.** Одно и то же тело ветки выходит с 4–6 разными хуками в течение 1–3 недель. Тестируется первая строка, а не содержание.
5. **Переход в Telegram = недостающий кусок пользы.** Ссылка не «подпишись на канал», а «вот третий промпт / разбор / ассистент, который работает в связке с этим». Две точки входа: в середине ветки и в финале.
6. **Ссылка ведёт на конкретный пост канала, а не в бота.** Пост-приёмник открыт без гейта (промпт, Custom GPT, инструкция). Человек попадает в канал, видит ленту и подписывается сам. Продажа идёт уже внутри канала: прогрев → кодовое слово в личку.

## 2. Ориентиры по цифрам (её данные)

| Показатель | Значение |
|---|---|
| Публикаций в день | 2–3 ветки, слоты утро / обед / вечер (≈10:00, 13:00, 18:00 МСК) |
| Длина ветки | 4–10 постов; лучшие — 7 или 9 |
| Медиана лайков на ветку | 8 (75-й перцентиль — 27, 90-й — 78) → распределение «хитовое» |
| Хит | 1–2 ветки в месяц дают 100–2 500 лайков и 100K–1,1M просмотров |
| Ветки с картинками | 17% публикаций; медиана лайков 22 против 6 у текстовых |
| Хук капсом | ~70% публикаций начинаются с первой строки ЗАГЛАВНЫМИ |
| Ссылок в TG на ветку | 1–3 (середина + финал + бонус) |
| Перевыпуски | ~35% публикаций; победитель повторяется каждые 3–10 дней |

Вывод для планирования: ставка на объём и отбор хитов, а не на «идеальную» каждую ветку.

## 3. Темы: шесть кластеров

Распределяй контент-план по кластерам. Веса — ориентир на старт; дальше перераспределяй по своим данным.

| # | Кластер | Механика | Доля | Её лучшие примеры (суть) |
|---|---|---|---|---|
| 1 | **ИИ как психолог / зеркало** | «Один промпт показал паттерн, который я не видела годами» | 25% | самосаботаж (519 лайков, 111K просмотров), чужие цели, деньги и детские установки, внутренний критик, отношения |
| 2 | **ИИ заменил дорогого специалиста** | «Услуга за 30–150К теперь бесплатно по фото» | 20% | ревизия гардероба (1,1K / 176K), нутрициолог, бьюти-анализ, парфюм, тревел-агент, репетитор английского |
| 3 | **Контент-завод для создателей** | «20 минут = месяц постов / 40 рилсов, пока ужинала» | 20% | контент-фабрика в Claude, «снежный ком» идей, автомонтаж рилсов, карусели, презентации |
| 4 | **Развлечение-самоирония** | «Плохие новости для тех, кто рассказывает GPT всю жизнь» | 10% | прожарка по переписке (2,5K лайков, 695 комментариев, 1,1 млн) |
| 5 | **ИИ-ассистенты и автоматизация** | «Настроила за вечер вместо ассистента за 80К» | 15% | Claude выполняет задачи сам, 4 нейросети вместо команды, новинки (новая функция = срочная новость) |
| 6 | **Деньги и продажи** | «Если туго с продажами — заставьте ИИ залезть в голову ЦА» | 10% | офферы, прогрев, план запуска, аудит сайта |

Правило выбора темы: **тема должна быть понятна человеку, который вообще не в нише**, а инструмент внутри должен вести к продукту автора. Связка проверяется вопросом: «какой материал в моём TG продолжит эту ветку?»

Сильнее всего работают темы, где результат: (а) про самого читателя (его паттерны, его внешность, его переписка); (б) его можно получить прямо сейчас за минуты; (в) его хочется показать другим.

## 4. Хук (пост 1/N)

### 4.1 Анатомия: 3 строки

```
СТРОКА 1 (КАПСОМ, до 12–15 слов): открывашка + громкое заявление с якорем
Строка 2: микро-история-доказательство от первого лица (что сделала → что произошло)
Строка 3: обещание + указатель вниз (+ опционально «предупреждение»)
```

Каркас: **эмоция/статус → конкретика (цена, время, результат) → доказательство из личного опыта → «ниже» → тизер последствий.**

### 4.2 Числовые якоря (минимум два в хуке)

- **Цена заменённого**: «стилист 30–80 тысяч», «нутрициолог 50–150К», «ассистент за 80К», «репетитор 3К/час», «монтажёр за 50К».
- **Сжатие времени**: «за 35 минут», «15 минут», «за один вечер», «пока я ужинала», «47 минут на 100+ слайдов».
- **Длительность боли**: «4 года ходила к психологу», «10 лет в маркетинге», «2 года не могла».
- **Измеримый результат**: «6000+ подписчиков», «12 образов из того, что висит», «11 причин в резюме», «3 отклика за 4 дня».
- **Количество инструментов**: «2 промпта», «4 шага», «6 промптов».

### 4.3 Библиотека открывашек (по механике)

Шаблоны, а не готовые тексты. Подставляй свою тему и цифры.

**Признание / шок от результата**
- `Я РЕАЛЬНО ОФИГЕЛА, КОГДА [ИИ сделал X]...`
- `Я ДИКО ИЗВИНЯЮСЬ, НО Я [N лет делала дорогое/долгое], А МОЖНО БЫЛО С ИИ ЗА [время]...`
- `Я СЛУЧАЙНО ОТКРЫЛА / ВКЛЮЧИЛА / РАЗБЛОКИРОВАЛА В [инструмент] РЕЖИМ [роль]...`
- `Я НАПИСАЛА В CHATGPT: «[короткая фраза-промпт]» — и [эмоциональная реакция].`
- `МОЗГ ВЗОРВАЛО ОТ ТОГО, ЧТО ИИ МНЕ ВЫДАЛ.`
- `ЭТО БЫЛО МОЩНО...` / `НУ ВСЁ, ПРИЕХАЛИ.`

**Заявление с позиции силы**
- `ОФИЦИАЛЬНО ЗАЯВЛЯЮ: [услуга] больше не стоит [цена]. [Инструмент] делает это [бесплатно/за минуты].`
- `ОТНЫНЕ Я ЗАПРЕЩАЮ [привычное действие], ПОКА ВЫ НЕ ПОПРОБОВАЛИ [инструмент].`
- `ВЫ К ЭТОМУ НЕ ГОТОВЫ, НО Я СКАЖУ. [Неожиданный тезис].`
- `ВНИМАНИЕ: [инструмент] теперь [делает работу специалиста за цену]. Бесплатно.`

**Мольба / забота**
- `УМОЛЯЮ, не [тратьте деньги на X], пока не [попробовали Y с ИИ].`
- `ПРОШУ, ЕСЛИ У ВАС СЕЙЧАС [боль], — заставьте ИИ [действие].`
- `РАДИ ВСЕГО СВЯТОГО, если вы ещё не [действие за один вечер] — прямо сейчас откройте и попробуйте.`

**Команда-провокация**
- `ТАК, УДАЛЯЙТЕ НАХРЕН [привычный инструмент] и [включите режим X].`
- `ТАК, ПЕРЕСТАНЬТЕ [делать долго/дорого].`
- `ХВАТИТ УЖЕ ТЕРПЕТЬ [раздражитель].`

**Новость / срочность** (для новых функций и релизов)
- `СРОЧНО: [инструмент] СДЕЛАЛ МНЕ [результат], ПОКА Я [бытовое действие].`
- `МЫ ЭТОГО ДОЛГО ЖДАЛИ: теперь [инструмент] за [цена] делает [работу] сам.`
- `ШОК-НОВОСТИ: за [цена] [инструмент] заменяет [специалиста за цену].`

**Юмор / самоирония** (самый высокий потолок охвата)
- `У МЕНЯ ПЛОХИЕ НОВОСТИ ДЛЯ ВСЕХ, КТО [массовая привычка] 😂`
- `КОРОЧЕ, ПРЕДЛАГАЮ НА 5 МИНУТ [забрать у ИИ привычку X] 😂`
- `[Профессия/сервис] ненавидит этот пост...`

**Подмена / замена**
- `ВМЕСТО ТОГО ЧТОБЫ [дорогое/долгое], Я ПОТРАТИЛА [мало времени] С [инструмент].`
- `КОРОЧЕ, Я НАШЛА СПОСОБ [результат] И НЕ [неприятное действие].`
- `ЕСЛИ Б Я ЗНАЛА, ЧТО ТАК МОЖНО, я б сделала это раньше — [что нашла].`

### 4.4 Финальная строка хука: указатель + тизер

- Указатель: `Вот промпты:` / `Ниже 5 промптов ↓` / `Показываю 4 шага:` / `СОХРАНИ: ниже промпт.`
- Тизер-предупреждение (повышает досмотр и комментарии): `Но присядьте.` / `Предупреждаю — будет неприятно.` / `Второй ответ лучше читать без свидетелей 😁` / `Будьте готовы: список ваших целей поменяется.`

### 4.5 Генерация хуков

Для каждого тела ветки генерируй **6 хуков разной механики** (минимум: признание, заявление, мольба, команда, юмор, замена). Выбирай 1 для первого выпуска, остальные 5 — в очередь перевыпусков.

## 5. Тело ветки: четыре шаблона

Общие правила:
- Один пост — одна мысль, **до 480–500 символов** вместе с заголовком и ссылкой.
- Посты нумеруются системой Threads (1/N); внутри используй `ШАГ 1.`, `PROMPT 1:`, `ЭТАП 1 —` капсом.
- Промпт — главная ценность. Длинный промпт **режется на несколько постов**: роль → правила → принципы → этапы → правила вывода. Это растягивает ветку и даёт ощущение «большого инструмента».
- Промпт оформляется в «ёлочки» и начинается словами `Вставляете в ChatGPT или Claude:`; продолжение — `👇` / `и это ещё не всё, продолжаем промпт:`.
- Плейсхолдеры для данных читателя: `[ниша]`, `[продукт]`, `[ваши вопросы]`.

### Шаблон A. «Промпт-сессия» (психология, самопознание) — 9 постов

| Пост | Содержание |
|---|---|
| 1/9 | Хук: «N лет X, а ИИ за 35 минут показал паттерн» + «присядьте» |
| 2/9 | `Вставляете в ChatGPT или Claude:` + роль специалиста (2–3 школы/метода для солидности) |
| 3/9 | Правило сессии: что делает ИИ, как (метафора «как детектив») |
| 4/9 | Принципы: рамка проблемы без стыда («это не слабость, а защитный механизм») + классификация (5 форм) |
| 5/9 | ЭТАП 1–2: вопросы и что искать |
| 6/9 | ЭТАП 3–4: «самый сложный этап» + диагностика + эксперимент на неделю |
| 7/9 | **Мид-ролл в TG**: «а вот тут план, который хорошо заходит после этой сессии» + ссылка + `и это ещё не всё, продолжаем промпт:` |
| 8/9 | Правила ведения диалога (один вопрос за раз, наблюдение между строк) |
| 9/9 | Эмоциональная посадка («не потому что вы слабые, а потому что…») + финальный переход в TG («работает в связке с этим промптом») |

### Шаблон B. «Заменила специалиста» (услуга по фото / пошаговая система) — 6–8 постов

| Пост | Содержание |
|---|---|
| 1/7 | Хук «услуга за 30–80К бесплатно» + **3–4 картинки результата** (сгенерированные доски, скрины) |
| 2/7 | ШАГ 1: что подготовить (фото, данные), список с тире |
| 3–4/7 | PROMPT 1 (разрезан на 2 поста), с визуальным стилем результата (люкс-эстетика, сетка) |
| 5/7 | ШАГ 2: зачем следующий шаг («чтобы не вернуться к старым ошибкам») |
| 6/7 | PROMPT 2 |
| 7/7 | ШАГ 3 описан, но **сам промпт удержан**: «третий промпт (и все остальные, чтобы удобно скопировать) собрала в TG» + ссылка + `СУПЕР БОНУС: ИИ-ассистент 24/7` + вторая ссылка |

### Шаблон C. «Развлекательная пара» (вирусный потолок) — 4 поста

| Пост | Содержание |
|---|---|
| 1/4 | Юмор-хук про массовую привычку + «2 промпта: сначала посмеётесь, потом пора менять» + тизер |
| 2/4 | `СНАЧАЛА ПРОЖАРКА 😂` + промпт-развлечение (результат хочется переслать друзьям) |
| 3/4 | `А ТЕПЕРЬ БЕЗ ШУТОК` + серьёзный промпт с 3 изменениями на 7 дней |
| 4/4 | UGC-призыв: «самую смешную фразу из ответа несите в комментарии» + переход в TG на глубокий разбор |

Ключ: выход промпта — **контент, которым делятся** (скрины ответов уходят в комментарии и цитаты), поэтому комментариев больше, чем у любых других форматов (695 при 2,5K лайков).

### Шаблон D. «Новость / инструмент» — 4–6 постов

| Пост | Содержание |
|---|---|
| 1/6 | `СРОЧНО:` / `МЫ ЭТОГО ДОЛГО ЖДАЛИ:` + что теперь умеет инструмент + цена + личный результат |
| 2–5/6 | ШАГ 1…4: как настроить (найти референсы → вводные → запуск → контроль качества), в шагах — «забираем механику, не копируем» |
| 6/6 | Итог + переход в TG (готовые настройки / инструкция / ассистент) |

## 6. Переходы в Telegram

### 6.1 Где ставить

- **Мид-ролл (60–75% ветки)**: в момент максимального вовлечения, до окончания промпта. После ссылки — `и это ещё не всё, продолжаем:`, чтобы не терять дочитывание.
- **Финал (последний пост)**: продолжение пользы + ссылка.
- **Бонус (опционально)**: вторая ссылка в финале на ИИ-ассистента / инструкцию.
- **Хук (редко)**: только в веток про сам Telegram. В её данных ссылки в первом посте почти не встречаются и такие хуки слабее.

### 6.2 Формула перехода (1–2 предложения)

```
[Вопрос, который останется у читателя после применения] → [конкретный фрагмент материала в TG] → [что заберёт] → ссылка
```

Шаблоны фраз:
- `Третий промпт (и все остальные, чтобы удобно было скопировать) собрала в TG в одном посте — [ссылка]`
- `А вот тут я собрала [план/разбор], который хорошо заходит после этой сессии, когда [эффект] — [ссылка]`
- `Кстати, вот тут я разобрала, как [инструмент] находит [X] — работает в связке с этим промптом: [ссылка]`
- `А если захотите глубже разобрать [тему] — у меня есть отдельный разбор. Забирайте в Telegram ↓ [ссылка]`
- `Чтобы каждый раз не [рутинное действие], создайте [ассистента]. Записала БЕСПЛАТНУЮ пошаговую инструкцию — [ссылка]`
- `СУПЕР БОНУС + доступ к ИИ-ассистенту ([роль]), с которым можно советоваться 24/7 — [ссылка]`
- `Чтоб ваши посты были вирусными, я ещё собрала свои промпты для усиления (благодаря им [подтверждённый результат]) — забрать бесплатно здесь: [ссылка]`

### 6.3 Правила

- Никогда: «больше полезного в канале», «подписывайтесь», «ссылка в профиле» без конкретики.
- Не обещать в переходе того, чего нет в посте-приёмнике.
- **Удержание последнего шага**: в ветке видно, что шаг существует (описан), но сам инструмент лежит в TG. Это самая сильная причина перейти.
- Ссылка — на конкретный пост канала (`t.me/канал/номер`), не на канал и не на бота.
- При перевыпуске старой ветки обновляй ссылку на свежий пост-приёмник.

## 7. Медиа: где скриншоты и кейсы

- Картинки только **в посте 1/N**. В теле ветки — текст.
- Что ставить: **результат работы промпта** (сгенерированные доски, разборы, карусели, кадры готовых роликов), 3–4 изображения каруселью. Это доказательство + «хочу так же».
- Видео-превью — для тем про рилсы и монтаж (показать готовый ролик).
- Ветки-«сессии» (психология, деньги) идут без картинок: там доказательство — эмоциональная реакция в тексте («10 минут сидела молча»).
- Кейсы в тексте — одной строкой с цифрой («через 4 дня — 3 отклика»), без отдельного поста-кейса.
- Развёрнутые скрины и отзывы живут в Telegram (пересылки отзывов подписчиков, скрины чатов).

---

## 8. Tone of voice

### 8.1 Её голос (эталон механики)

- **Позиция**: «подружка-практик, которая сама попробовала и в шоке». Первое лицо, личный опыт, обращение на «вы» в инструкциях.
- **Самоирония**: «душнила 🤓», «душно, как я люблю».
- **Эмоциональные маркеры**: офигела, в шоке, сидела молча, мозг взорвало, не шучу.
- **Лёгкая грубость**: «нахрен», «к чёрту», «фигня» — 1 раз на ветку максимум.
- **Скобки-ремарки**: «(я так давно забыла про 8-часовой рабочий день)», «(да-да, теперь это возможно)».
- **Контраст «Не X. Не Y. А Z.»**: «Не мотивашку. А точную схему.»
- **Короткие рубленые фразы**, многоточия, `→` для схем, `↓`/`👇` как указатель.
- **Эмодзи скупо**: 😂 😁 👇 🤓, не больше 1–2 на пост.
- **Капс** — для первой строки хука и названий шагов, плюс 1–2 слова-акцента внутри («МЕСЯЦ ПОСТОВ»).
- **Мелкие опечатки не вычищаются** — текст звучит живым, а не отредактированным.

### 8.2 Калибровка под автора: «громкость» 1–5

Механика (якоря, удержание шага, мид-ролл) остаётся всегда. Меняется только громкость подачи:

| Уровень | Как звучит | Для кого |
|---|---|---|
| 5 | Её оригинал: капс, «ОФИГЕЛА», «УДАЛЯЙТЕ НАХРЕН» | массовая аудитория, быстрый рост |
| 4 | Капс в первой строке, эмоция без мата | по умолчанию |
| 3 | Капс только на 2–4 словах, эмоция через факт («за 35 минут ИИ показал то, что я не видел 4 года») | эксперт с репутацией |
| 2 | Без капса; сила — в цифре и контрасте | премиум-позиционирование |
| 1 | Спокойный наставнический тон, хук — парадокс или вопрос | личный бренд «отец/наставник» |

Перед генерацией спроси уровень, если он не задан. Голос автора берётся из его 3–5 текстов: ритм, лексика, резкость, способ обещать пользу. Не переносить её женский род и бытовые детали («пока ужинала») — заменять на реальные сцены из жизни автора.

## 9. Вовлечение: на что она вовлекает

- **Сохранение**: промпт целиком = «надо сохранить». Слово `СОХРАНИ` в хуке.
- **Пересылка**: результат про самого человека или его близких («нашёл в резюме сестры 11 причин»).
- **Комментарии**: UGC-призыв в финале («несите самую смешную/обидно точную фразу»), тизер-предупреждение, спорная рамка («стилист не нужен» → споры в комментариях тоже двигают охват).
- **Цитаты**: развлекательные форматы цитируют со скриншотами ответов.
- **Ответы автора** в первый час после публикации поднимают ветку (агент готовит черновики ответов, автор подтверждает).
- Метрика победителя — **шеры + комментарии**, а не только лайки.

---

## 10. Расписание и переупаковка победителей

### 10.1 Ритм

- 3 слота в день: утро (~10:00), обед (~13:00), вечер (~18:00) по часовому поясу аудитории.
- Публикация автопостингом. Автор заходит 3 раза по 5 минут — ответить на комментарии.
- Чередовать кластеры тем и механики хуков: два одинаковых хука подряд не ставить.

### 10.2 Цикл «тест → победитель → перевыпуск»

1. **Тест**: новая ветка выходит с хуком №1.
2. **Оценка через 48 часов**: победитель — топ-10% по (шеры + комментарии) за последние 30 дней, либо ≥3× медианы аккаунта по лайкам.
3. **Перевыпуск победителя**: то же тело, новый хук из очереди, через 3–10 дней. Обновить ссылку в TG на свежий пост-приёмник.
4. **Затухание**: если 2 перевыпуска подряд ниже медианы — тело в архив на 30–45 дней, затем пробуем с новым углом.
5. **Ветка-неудачник** (ниже медианы): тело не трогаем, тестируем другой хук один раз; дальше — в архив.
6. **Доля в плане**: ~65% новых веток, ~35% перевыпусков.

## 11. Telegram-сторона (без неё трафик не конвертируется)

**Пост-приёмник** (на него ведёт ссылка из ветки):
1. Заголовок-вопрос или «что будет, если соединить X + Y + боль»;
2. Личная история («сама долго искала, ошибалась»);
3. Зачем это вообще (объективное обоснование);
4. Что внутри: промпты блоками для копирования / Custom GPT в двух версиях / инструкция;
5. Как пользоваться (шаги);
6. Скрины своего результата;
7. Вопрос подписчикам в конце («делиться такими лайфхаками?») — реакции и комментарии.

**Лестница канала**: лид-магнит → пересылки отзывов подписчиков → эмоциональный анонс («скоро… пазлы сложились») → кейсы участников → продающий пост → продажа через **кодовое слово в личку** («пишите "фокус-группа" в лс»). Её продукт: фокус-группа на 6 недель (живые зумы, ежедневный ИИ-челлендж, база знаний, 33+ готовых ассистента), ранняя бронь.

Агент ведёт **библиотеку приёмников**: `{ссылка, тема, что внутри, к каким кластерам подходит, дата}`. Каждая новая ветка привязывается к приёмнику; если подходящего нет — агент формирует задание на новый пост-приёмник.

## 12. Агентский конвейер

Роли можно запускать как отдельные агенты (Claude Agent SDK / n8n) с апрувом в Telegram.

| Агент | Вход | Что делает | Выход |
|---|---|---|---|
| **Scout** | ниша, список аккаунтов-доноров | собирает публикации с метриками (Apify / парсер), отмечает выбросы ≥3× медианы автора | `posts.json` |
| **Analyst** | `posts.json`, вопросы клиентов | выделяет темы, конфликты, механики хуков; кладёт на 6 кластеров; 20 тем на пересечении «широкий интерес × продукт» | `topics.json` (тема, кластер, гипотеза, приёмник) |
| **Hooksmith** | тема, голос, результаты | 6 хуков разной механики по §4, якоря, тизер | `hooks[]` |
| **Writer** | тема, шаблон A–D, материалы автора | тело ветки по §5, посты ≤480 символов, разделитель `/` | `thread.posts[]` |
| **Bridge** | ветка, библиотека приёмников | мид-ролл + финальный переход по §6; удерживает последний шаг; если связка натянута — помечает | `thread.bridges` |
| **Editor (QA)** | ветка целиком | чек-лист §13; переписывает слабые места; убирает неподтверждённые обещания | `thread.final` + `qa_report` |
| **Scheduler** | готовые ветки | 3 слота/день, чередование кластеров и механик; гипотеза на каждый слот | `queue.json` |
| **Recycler** | метрики через 48 ч | определяет победителей и неудачников по §10.2, ставит перевыпуски с новыми хуками, обновляет ссылки | обновлённый `queue.json` |
| **Replier** | новые комментарии | черновики ответов в голосе автора на апрув | `replies[]` |

Формат ветки для обмена между агентами:

```json
{
  "id": "thr_2026_11_03_a",
  "cluster": 1,
  "template": "A",
  "hook_variants": ["...", "..."],
  "active_hook": 0,
  "posts": ["1/9 ...", "2/9 ...", "..."],
  "bridges": {"mid": {"position": 7, "text": "...", "url": "t.me/channel/123"}, "final": {"text": "...", "url": "t.me/channel/124"}},
  "media": {"post1": ["result_board_1.png", "result_board_2.png"]},
  "proofs_used": ["реальный результат + источник"],
  "slot": "2026-11-03T10:00+03:00",
  "hypothesis": "юмор-хук vs признание на теме X",
  "status": "draft|approved|published|winner|archived"
}
```

## 13. QA-чек-лист перед публикацией

- [ ] Первая строка ≤15 слов, останавливает без контекста, содержит якорь.
- [ ] В хуке ≥2 числа (цена / время / срок боли / результат).
- [ ] Тема понятна человеку вне ниши.
- [ ] Польза применима за ≤40 минут, промпт работает при копировании.
- [ ] Каждый пост ≤500 символов, одна мысль на пост.
- [ ] Мид-ролл стоит на 60–75% ветки, после него есть «продолжаем».
- [ ] Финал: эмоциональная посадка или UGC-призыв + переход с конкретикой.
- [ ] Ссылки ведут на конкретные посты TG, приёмник существует и совпадает с обещанием.
- [ ] Все результаты и цифры подтверждены автором; где нет — `[уточнить]`.
- [ ] Нет чужих формулировок и промптов один в один.
- [ ] Для тем про психологию и здоровье: нет обещаний вылечить; промпт — инструмент самонаблюдения, а не замена специалиста при серьёзных состояниях.
- [ ] Громкость соответствует выбранному уровню §8.2.

## 15. Чего не делать

- Не выдумывать личные результаты («6000 подписчиков», «сэкономила 200К»), даже если механика «просит» цифру.
- Не копировать её тексты, промпты и картинки; брать структуру и механику.
- Не вести ссылку из ветки в бота с гейтом — трение убивает переход; бот уместен уже из канала.
- Не публиковать ветку без подготовленного приёмника.
- Не писать ветки про «как продвигаться в Threads» для широкой ленты: у неё такие набирали сотни просмотров. Эти темы — для канала.
