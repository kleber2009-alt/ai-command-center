# HQ — 3D-офис команды (hq.aicex.club)

Статичный сайт: Three.js-офис, отделы, руководители и их ИИ-агенты с досье.

| Файл | Что внутри |
|---|---|
| `index.html` | сцена, UI, массив `DEPTS` — отделы, руководители, агенты |
| `agent-content.js` | досье агентов: описание, процесс, скиллы, работы, шаблоны задач |
| `dept-content.js` | материалы из marketing.aicex.club (работы, скиллы, артефакты), из них собираются досье |
| `people/` | фото руководителей и 3D-модель Фирузы (`firuza.glb`) |

## Команда

| Отдел (`id`) | Руководитель | Агенты |
|---|---|---|
| Стратегия и продукт (`ceo`) | Илья — основатель | Разработка продуктов, Исследования рынка, Утренний брифинг, ТЗ и документы, Скиллы и автоматизации |
| Отдел маркетинга (`marketing`) | Фируза | Презентации, Креативы, Воронки, Публикации, Аналитика, Анализ аудитории, Сценарии, Монтаж видео, Карусели, Лендинги, Лид-магниты, Видео с аватаром |
| Отдел продаж (`sales`) | Богдан — РОП | Переписки, Ответы на комментарии, ИИ-консультации, Рассылки, Закрытие сделок |
| Реклама Meta (`traffic`) | Нуркен | Рекламные кампании, Отчёты по рекламе |

Агент называется по своей зоне ответственности, без человеческих имён. Скиллы в досье — те, что
реально подключены в Claude (скиллы, ChatPlace, Higgsfield, HeyGen, Windsor.ai, Notion, Gmail…),
материалы — артефакты claude.ai (`AR` в `agent-content.js`) и работы с marketing.aicex.club.

Количество комнат берётся из `DEPTS` — планировка подстраивается сама. В комнате до 12 агентов (`SLOTS`).

## Демо

`VirtualOffice.openDemo(id)`: `'office'` — весь офис, id отдела — отдел, id руководителя или агента — его личное демо.
Кнопки: «Демо офиса» на плане, «Демо отдела» в комнате, «Демо» в карточке сотрудника и в досье агента.

## Локально

```bash
cd apps/hq && python3 -m http.server 8000   # http://localhost:8000
```

`?room=marketing` открывает сразу отдел, `?debug` — отладка.

## Деплой

Сайт отдаётся через Cloudflare — содержимое папки выкладывается как есть, без сборки.
