# HQ — 3D-офис команды (hq.aicex.club)

Статичный сайт: Three.js-офис, отделы, руководители и их ИИ-агенты с досье.

| Файл | Что внутри |
|---|---|
| `index.html` | сцена, UI, массив `DEPTS` — отделы, руководители, агенты |
| `agent-content.js` | досье агентов: описание, процесс, скиллы, работы, шаблоны задач |
| `dept-content.js` | материалы из marketing.aicex.club (работы, скиллы, артефакты), из них собираются досье |
| `people/` | фото руководителей и 3D-модель Фирузы (`firuza.glb`) |

## Команда

| Отдел (`id`) | Руководитель | Агенты |
|---|---|---|
| Стратегия и продукт (`ceo`) | Илья — основатель | Разработка продуктов |
| Отдел маркетинга (`marketing`) | Фируза | Презентации, Креативы, Воронки, Публикации, Аналитика, Анализ аудитории |
| Отдел продаж (`sales`) | Богдан — РОП | Переписки, Закрытие сделок |
| Реклама Meta (`traffic`) | Нуркен | Рекламные кампании |

Агент называется по своей зоне ответственности, без человеческих имён.

Количество комнат берётся из `DEPTS` — планировка подстраивается сама. В комнате до 6 агентов (`SLOTS`).

## Локально

```bash
cd apps/hq && python3 -m http.server 8000   # http://localhost:8000
```

`?room=marketing` открывает сразу отдел, `?debug` — отладка.

## Деплой

Сайт отдаётся через Cloudflare — содержимое папки выкладывается как есть, без сборки.
