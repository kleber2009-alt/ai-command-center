# Трек v2 «Свой ИИ-офис» — контент шагов

Ученик живёт внутри своего 3D-офиса. Офис сначала пустой. Модули — это комнаты, шаги — пустые рабочие места. Каждый шаг — **найм одного агента**: ученик отвечает на вопросы про свой бизнес, получает готовое решение AICEX (скилл, артефакт, продукт, коннектор, шаблон), запускает его на своём проекте в Claude, приносит результат и утверждает регламент агента. После этого агент садится за стол в офисе.

**Чего НЕТ в треке:** уроков маркетинга, квизов на знание, теории «как писать оффер». Мы не учим маркетингу — мы даём готовые решения и учим ими пользоваться: скиллы, артефакты, проекты Claude, коннекторы, внедрение.

Файлы пишутся параллельно:

- `src/content-a.js` — шаги 0.1, 0.2, 1.1, 1.2, 1.3, 2.1, 2.2, 2.3, 2.4, 2.5, 2.6, 3.1, 3.2 (13 шагов)
- `src/content-b.js` — шаги 3.3, 3.4, 3.5, 4.1, 4.2, 4.3, 4.4, 4.5, 5.1, 5.2, 6.1, 6.2, 6.3 (13 шагов)

Формат файла:

```js
(function () {
  var A = window.ACADEMY = window.ACADEMY || {};
  A.steps = (A.steps || []).concat([
    { /* шаг */ },
  ]);
})();
```

## Правило 15 лет (как и раньше)

1. Одна мысль — одно короткое предложение, до 15 слов.
2. Только действия: «вставь», «нажми», «скопируй», «запусти».
3. На «ты». Без канцелярита. Без эмодзи.
4. Термины из глоссария можно помечать `[[скилл]]`, `[[агент]]`, `[[коннектор]]`, `[[проект Claude]]`, `[[знания проекта]]`, `[[инструкция проекта]]`, `[[регламент]]`, `[[артефакт]]`, `[[промпт]]`, `[[контекст]]`, `[[бот]]`, `[[воронка]]`, `[[лид-магнит]]`, `[[кодовое слово]]`, `[[лендинг]]`, `[[рилс]]`, `[[карусель]]`, `[[креатив]]`, `[[директ]]`, `[[база знаний]]`, `[[босс]]`.

## Схема шага

```js
{
  id: '2.2', module: 2, room: 'marketing', agent: 'scripts', title: 'Сценарии', minutes: 40,
  context: null,                              // или 'context/audience.md' — по карте
  brief: '2–3 фразы: что этот агент будет делать в твоём офисе.',
  aicex: {                                    // как это устроено у AICEX — только факты из AGENTS-REAL.md
    text: '2–4 короткие фразы про реальный процесс AICEX.',
    links: [{ title: 'Нейроворонка — 10 продающих рилс', url: 'https://claude.ai/artifact/...' }]   // 1–3 реальные ссылки
  },
  questions: [                                // 2–3 вопроса про бизнес ученика
    { id: 'topics', label: 'Про что твой блог? Назови 3 темы.', hint: 'Подсказка, до 140 знаков.',
      example: 'Как у AICEX: …',             // реальный пример, без выдуманных цифр
      rows: 3,
      help: [                                 // 2–3 штуки — открываются по кнопке «Не знаю»
        { type: 'skill', title: 'Найди темы скиллом niche-outlier-research', text: 'Что сделать: 2–3 фразы.', prompt: 'Готовый запрос в Claude' },
        { type: 'example', title: 'Темы AICEX', text: '…', url: 'https://…' },
        { type: 'template', title: 'Шаблон ответа', text: 'Тема 1 — …\nТема 2 — …\nТема 3 — …' }
      ] }
  ],
  gifts: [                                    // 2–4 готовых решения (подарок шага)
    { type: 'skill', name: 'reels-script', title: 'Сценарии рилсов', what: 'Что делает, одна фраза.', guide: 'claude-skill-upload' },
    { type: 'artifact', title: '…', url: 'https://claude.ai/artifact/…', what: '…' },
    { type: 'product', title: 'Бот монтажа', url: 'https://reels.aicex.club', what: '…' },
    { type: 'connector', name: 'Chat Place', title: '…', what: '…', guide: 'claude-connector' },
    { type: 'template', title: '…', what: '…', text: 'Заготовка (документ, регламент, таблица)' }
  ],
  task: {                                     // задание: запустить решение на своём проекте
    title: 'Сделай 5 сценариев на неделю',
    steps: ['Открой свой проект в Claude.', 'Вставь промпт ниже.', 'Выбери лучший сценарий.', 'Вставь его сюда.'],   // 3–5 действий
    prompt: 'Готовый промпт. Подставь ответы: {{topics}}, {{code_word}}. Проект: {{@project}}.',
    result: 'Что вставить в поле результата — одна фраза.',
    resultType: 'text',                       // 'text' (вставить текст) или 'link' (ссылка на артефакт, бота, пост)
    check: ['Критерий 1', 'Критерий 2', 'Критерий 3']   // ровно 3, проверяемые по результату
  },
  regulation: {                               // черновик регламента агента — ученик потом правит
    when: 'Когда запускать: «каждый понедельник», «на каждую заявку»…',
    input: 'Что агент получает на вход.',
    output: 'Что отдаёт на выходе.',
    owner: 'Кто отвечает: ты, маркетолог, РОП…',
    check: 'Как проверяют результат и сколько это занимает.',
    tools: ['reels-script']                   // скиллы, коннекторы, продукты
  },
  boss: null                                  // у боссов: { task, proof, placeholder, days: 7 }
}
```

### Типы помощи (`help[].type`) — когда ученик нажал «Не знаю»

- `instruction` — как сделать по шагам (`text` с пунктами через `\n- `).
- `recommendation` — что выбрать и почему, если вариантов несколько.
- `lecture` — мини-лекция: 3–5 коротких фраз, объяснение на пальцах.
- `skill` — какой скилл запустить и готовый `prompt`.
- `material` — продукт или артефакт AICEX (`url` обязателен).
- `example` — как это сделано в AICEX (`url`, если есть).
- `template` — заготовка ответа, которую можно скопировать и дописать.

В каждом вопросе — 2–3 разных типа помощи. Хотя бы в одном — готовое решение (`skill`, `material` или `template`).

### Готовые решения (`gifts[].type`)

`skill` (обязательно `name` — реальное имя скилла из AGENTS-REAL.md), `artifact` (`url` claude.ai), `product` (`url` *.aicex.club), `connector` (`name` из списка коннекторов), `template` (`text` — сама заготовка).

### Задание (`task`)

- Промпт — рабочий, его можно сразу вставить в Claude. Плейсхолдеры: `{{id_вопроса}}` (ответ ученика), `{{@project}}`, `{{@name}}`, `{{@niche}}`.
- Результат — то, что реально получилось у ученика: текст из Claude или ссылка.
- `check` — 3 критерия, по которым ИИ проверит результат: «Есть 5 сценариев», «В каждом есть кодовое слово», «Темы — из ответов ученика, а не общие».

### Инструкции «куда нажать» (`guide`)

`claude-new-project`, `claude-instructions`, `claude-knowledge`, `claude-prompt`, `claude-skill-upload`, `claude-connector`, `office-open`.
