# 🎯 Шаблоны: Сегменты

**Коллекция:** [🎯 Сегменты](https://www.notion.so/9f3497a8dce948c7a093adfa719dec5a)

## Минимум для MVP: 3-5 сегментов

Сегмент = архетип клиента. Не «маркетологи» вообще, а «маркетолог в EdTech-агентстве с 5-10 клиентами».

---

## Шаблон записи сегмента

**Название:** [Имя сегмента, например «EdTech-агентство»]

### 1. Кто это (1 абзац)
```
Профессия, возраст, доход, ниша, размер бизнеса.
Конкретно. Не «предприниматели», а «владелец агентства 5-15 человек».
```

### 2. ICP-маркеры — как Аналитик распознаёт сегмент
```
Сильные сигналы (если есть — точно этот сегмент):
- [Маркер 1, например «упоминает «мои клиенты»»]
- [Маркер 2]
- [Маркер 3]

Слабые сигналы:
- ...
```

### 3. Боли — что у них болит (3-5 пунктов)
```
1. [Боль 1] — описание + почему болит
2. [Боль 2] — ...
3. [Боль 3] — ...
```

### 4. Как они говорят — язык сегмента
```
Используют слова: [список профессиональных терминов]
Не используют: [список — что для них «не своё»]
Метафоры: [как они думают о своём бизнесе]

Пример сообщения этого сегмента:
«[Реальная цитата из переписки]»
```

### 5. Что им предлагать
```
Основной продукт: [связь с Продуктами]
Дополнительные: ...
Не предлагать: ...
```

### 6. Скоринг — как Аналитик оценивает
```
+20 за ICP match с этим сегментом
+15 если упоминает [специфичный маркер]
-10 если [красный флаг — например «студент в этой нише»]
```

### 7. Средний цикл сделки
```
Время от hello до won: [N дней]
Средний чек: [N ₽]
Конверсия hello→won: [%]
```
