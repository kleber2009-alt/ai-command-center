# 🛒 Шаблоны: Продукты

**Коллекция:** [🛒 Продукты](https://www.notion.so/be0939e113f54707a47d1ae4ce4a064b)

## Структура записи каждого продукта

**Название:** [Имя продукта] (например «Автопилот SMM», «Консультация 90 мин»)

**Что внутри (страница):**

### 1. Описание в одной строке
```
Что это, для кого, что даёт. Одно предложение.
```

### 2. Подробное описание (2-3 абзаца)
```
Развёрнуто — что входит, как работает, для кого подходит.
Избегай рекламы — пиши как объясняешь другу.
```

### 3. Цена и условия
```
Стоимость: [N ₽]
Формат: разовая / подписка / абонемент
Длительность: [месяцы / навсегда]
Что включено: [список 5-10 пунктов]
Что не включено: [список 2-3 пунктов]
```

### 4. Для кого
```
✅ Идеально подходит:
- [Профиль 1]
- [Профиль 2]

❌ НЕ подходит если:
- [Маркер несовместимости 1]
- [Маркер несовместимости 2]
```

### 5. Результаты клиентов (3-5 кейсов)
```
Кейс 1: [Имя/анон], [ниша], [было] → [стало] за [N времени]
Кейс 2: ...
```

### 6. Частые вопросы про этот продукт (5-10)
```
Q: [Вопрос]
A: [Ответ]
```

### 7. Скрипт презентации (1-3 варианта)
```
Когда питчить: [условие]
Текст: «...»
```

---

## Что заполнять в полях БД

Зависит от схемы (проверь в Notion). Если есть поля:
- **Тариф/цена** — числом
- **Статус** — Active / Draft / Retired
- **Сегмент** — какой ICP покупает (связь с коллекцией Сегменты)
- **Приоритет** — основной / дополнительный
