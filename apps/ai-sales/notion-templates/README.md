# 📚 Шаблоны для Notion коллекций

**Версия:** v1.0 · 15 мая 2026
**Назначение:** заготовки записей для 5 коллекций базы знаний

Здесь — **скаффолдинг** для каждой из 5 коллекций. Открываешь файл, копируешь, вставляешь в Notion, заполняешь содержимым.

---

## Зачем шаблоны

Когда коллекция пустая — непонятно как её заполнять. Когда уже есть 3-5 примеров с правильной структурой — добавлять остальные легко.

Я (Claude) могу читать твой Notion через MCP, но **не могу за тебя решить какой у тебя голос, какие у тебя продукты, как ты обрабатываешь возражения**. Это твой бизнес. Шаблоны — это лестница, а не лифт: ты идёшь сам, но не с нуля.

---

## Порядок заполнения (рекомендую)

1. **Сначала Голос** — это фундамент. Без него остальное звучит generic.
2. **Потом Сегменты** — определяешь ICP, который потом будет проверять Аналитик.
3. **Потом Продукты** — что именно продаём, под какие сегменты.
4. **Потом Возражения** — на основе реальной переписки за последний месяц.
5. **Контент-память** — заполняется по ходу, не критично для запуска.

---

## Связь с агентами

Когда заполнишь Notion, эти данные попадут в Qdrant через эмбеддинги Voyage-3 (этап 3.3-3.4), и агенты будут читать их через RAG в реальном времени.

Поле `Когда применять` — критичное для RAG. Оно даёт агенту контекст «в какой ситуации использовать эту запись». Без него RAG возвращает похожие по семантике записи, но не понимает когда применять.
