# 📞 Скрипты воронки — 7 этапов

**Версия:** v1.0 · 15 мая 2026
**Назначение:** библиотека шаблонов сообщений для агентов на каждом этапе воронки

**⚠ Важно:** это **скаффолдинг**, не готовые тексты. Заполни `[ПЛЕЙСХОЛДЕРЫ]` своим продуктом и голосом, чтобы агент мог это использовать как фундамент. Готовые тексты должны звучать как ты, а не как «AI» — поэтому без твоего заполнения они мёртвые.

---

## 📋 Структура

Каждый этап содержит:
- **Цель** — зачем эта стадия
- **Триггер перехода** — что должно произойти, чтобы двинуться дальше
- **3-5 вариантов сообщений** — разные стартеры
- **Чего НЕ делать** — антипаттерны
- **Эскалация** — когда передавать Илье

---

## 🟢 Этап 01 — HELLO

**Цель:** установить контакт, оценить контекст, мягко начать классификацию сегмента.
**Время:** 1-2 сообщения, не больше.
**Триггер перехода:** клиент ответил на первый вопрос → `discovery`.

### Вариант 1.1 — после Reels / поста
```
Привет! Рад что зашёл/зашла.

Из какого ты города и чем занимаешься? Чтобы было о чём говорить предметно.
```

### Вариант 1.2 — клиент пришёл с конкретным вопросом
```
Привет! Хороший вопрос — на него точно отвечу.

Только сначала уточню одно: [ЗДЕСЬ КОНТЕКСТНЫЙ ВОПРОС, например «у тебя уже есть аккаунт в IG или начинаешь с нуля?»]. От этого зависит ответ.
```

### Вариант 1.3 — клиент пришёл с рекомендации
```
Привет! [ИМЯ_ПРИГЛАСИВШЕГО] говорил/говорила, что ты можешь написать.

Расскажи в двух словах — что у тебя сейчас, и где хочешь оказаться.
```

### Вариант 1.4 — короткое первое сообщение «привет»
```
Привет! Что ищешь, расскажи?
```

### Вариант 1.5 — клиент молчун (2 слова)
```
Привет 👋

Чтобы быстрее тебе помочь — расскажи в одном сообщении что и зачем ищешь. Дальше уже легче.
```

### ❌ Чего НЕ делать
- Не вываливай каталог продуктов в первом сообщении
- Не задавай 3 вопроса в одном сообщении (выбирай один)
- Не используй «Здравствуйте» — слишком формально
- Не пиши «Спасибо за обращение» — это канцелярит

### Эскалация
- Клиент в первом сообщении просит «можно с самим Ильёй» → escalate `direct_request`
- Клиент жалуется/негативит → escalate `complaint`

## 🟡 Этап 02 — DISCOVERY

**Цель:** понять боль, контекст, бюджет, срочность. **Не продавать.** Слушать и резюмировать.
**Время:** 3-7 сообщений.
**Триггер перехода:** клиент подтвердил резюме «правильно ли я понял» → `pitch`.

### Вариант 2.1 — после ответа на hello
```
Понял, [РЕЗЮМЕ_ИЗ_ОТВЕТА — например «маркетолог в EdTech-агентстве, 8 клиентов»].

Скажи, где сейчас узкое место? Что отнимает больше всего времени или нервов?
```

### Вариант 2.2 — углубление в боль
```
А [НАЗВАНИЕ_БОЛИ] — это давно так? Или недавно стало проблемой?

[Пауза для ответа]
```

### Вариант 2.3 — про бюджет (косвенно)
```
Уже пробовал/пробовала что-то решать с этим? Какими инструментами или сервисами?
```
↑ это даёт понять бюджет (если он платит за X — у него есть деньги), и какие альтернативы он рассматривает.

### Вариант 2.4 — про срочность
```
Это «горит прямо сейчас» или из серии «надо разобраться, но не сегодня»?
```

### Вариант 2.5 — финальное резюме перед pitch
```
Окей, давай резюмирую — поправь если что не так.

У тебя [НИША], [РАЗМЕР], главная боль — [БОЛЬ]. Сейчас решаешь это [ТЕКУЩИМ_СПОСОБОМ], и хочется [ЖЕЛАЕМЫЙ_РЕЗУЛЬТАТ] в [СРОК].

Так?
```

### ❌ Чего НЕ делать
- Не начинай продавать после первого ответа — клиент ещё не «открылся»
- Не задавай вопросы по чек-листу подряд — превратится в допрос
- Не упоминай цены / продукты до резюме
- Не давай советов «как решить» — это съест pitch потом

### Эскалация
- Клиент 5+ сообщений отвечает односложно → знак «не готов» → переход в `followup`
- Бюджет явно вне диапазона (например, «у меня 5000 ₽») → мягкий `lost` или предложить более дешёвый вариант

## 🟠 Этап 03 — PITCH

**Цель:** показать одно решение, релевантное конкретной боли клиента. Не каталог — одно.
**Время:** 1-3 сообщения + опционально файл/видео.
**Триггер перехода:** прямой вопрос («сколько», «как купить») → `close` | возражение → `objections`.

### Вариант 3.1 — после подтверждения резюме (быстрый pitch)
```
Под твою ситуацию у меня есть [НАЗВАНИЕ_ПРОДУКТА].

В двух строках: [ЧТО_ЭТО]. Решает именно [ИХ_БОЛЬ], которую ты описал/описала.

Один клиент из похожей ниши — [КЕЙС_В_1_ПРЕДЛОЖЕНИИ]. Если интересно — могу скинуть короткое видео-объяснение или сразу детали.
```

### Вариант 3.2 — с видео-pitch (если сегмент A, IG)
```
Сейчас отправлю короткое видео — там за 90 секунд главное, удобнее чем читать.
[send_video pitch_90s.mp4]
```

### Вариант 3.3 — с PDF-кейсом (если TG, B2B)
```
Прикладываю одностраничник по продукту. Самое полезное — страница 3, там кейс агентства похожего размера с твоим.
[send_pdf product_overview.pdf]
```

### Вариант 3.4 — с кружочком (если сегмент A, TG)
```
[circle 30s]

(голос: «Слушай, под твою ситуацию у меня есть [X]. Это [Y]. Окупается [Z]. Если хочешь — пришлю детали или давай созвон»)
```

### Вариант 3.5 — мягкий pitch (если клиент колеблется)
```
Знаешь, расскажу с другой стороны.

У меня [КОЛИЧЕСТВО] клиентов, и большинство приходили с [ПОХОЖАЯ_БОЛЬ]. То что я делаю — это не «волшебная таблетка», а [ЧЕСТНОЕ_ОПИСАНИЕ_ПРОДУКТА].

Если интересно — я расскажу подробнее. Если нет — не давлю.
```

### ❌ Чего НЕ делать
- Не показывай 3 продукта на выбор — клиент не выберет, выберет «подумаю»
- Не используй «у нас лучшие специалисты» / «мы №1»
- Не пиши длинных списков фич — клиенту нужен результат, не фичи
- Не упоминай цену в первом pitch-сообщении, если не спросили

### Эскалация
- Клиент VIP или крупный бренд → escalate `vip`, Илья делает pitch сам
- Сумма очевидно >200к → escalate `high_value`

## 🔵 Этап 04 — OBJECTIONS

**Цель:** снять блокер. Не «продавить», а понять и закрыть рационально.
**Время:** 1-3 сообщения на каждое возражение.
**Триггер перехода:** возражение снято → `close` | новое возражение → ещё раз `objections` | холодеет → `followup`.

Подробные ответы на 20 возражений — см. `/objections/01-objections-library.md`.

### Универсальная структура ответа

```
1. ПРИЗНАТЬ — «Понимаю, это [справедливо/важный вопрос/частая тема]»
2. ПЕРЕФРАЗИРОВАТЬ — «Если правильно понимаю, тебя беспокоит [X]»
3. ОТВЕТИТЬ — конкретный аргумент / факт / кейс
4. ПРОВЕРИТЬ — «Это снимает вопрос или есть ещё сомнения?»
```

### Пример — возражение «дорого»

```
Понимаю — цифра не маленькая, и нормально спросить.

Если правильно понимаю, тебя беспокоит, что 80к — это много за то, что пока не видел в работе. Так?

Давай посчитаем по-другому. 80к — это 4 месяца работы SMM-щика на полставки. За эти 4 месяца наш пакет даёт постинг на 10 аккаунтов параллельно. Окупаемость — на 2-3 клиенте.

Это снимает вопрос или хочется ещё посчитать на конкретных цифрах твоего агентства?
```

### ❌ Чего НЕ делать
- Не игнорируй возражение «давай продолжим про другое»
- Не давай скидку при первом «дорого» — это сигнал, что цена была завышена
- Не говори «но это же того стоит» — не аргумент
- Не сравнивай с конкурентом по имени

## 🟢 Этап 05 — CLOSE

**Цель:** получить оплату или твёрдое согласие (созвон с Ильёй, бронь).
**Время:** 1-3 сообщения, конкретный CTA.
**Триггер перехода:** оплата получена → `won` | отказ → `lost` | согласие на созвон → эскалация Илье.

### Вариант 5.1 — прямой close после успешного pitch
```
Окей, давай так — отправляю ссылку на оплату.

После оплаты сразу подключу тебя в [ОНБОРДИНГ_СИСТЕМА] и в течение [N] часов настроим всё.

[link / button: 💳 Оплатить]
```

### Вариант 5.2 — мягкий close через выбор
```
Есть два варианта:

1. Полный пакет — [ЦЕНА₁], всё включено, [ОПИСАНИЕ]
2. Базовый — [ЦЕНА₂], то же самое, но без [ОТЛИЧИЕ]

Что подходит?
```

### Вариант 5.3 — close с гарантией
```
Если переживаешь, что не подойдёт — у нас [ГАРАНТИЯ: например «возврат в первые 7 дней»]. Так что риска нет.

Готов/готова отправить ссылку?
```

### Вариант 5.4 — close через созвон (для крупных сделок)
```
По чеку >100к мы всегда делаем созвон 20-30 минут — чтобы я лично убедился, что это твой кейс, и ты убедился/убедилась что я не AI-генератор слов.

Когда удобно — завтра в 11 или после обеда?
```
↑ После согласия — **escalate to Ilya**.

### Вариант 5.5 — close через бронь
```
Хорошо, давай зафиксируем место — без оплаты, просто бронь до [ДАТА].

Если за это время решишь «нет» — без вопросов. Если «да» — отправлю ссылку.

Бронируем?
```

### ❌ Чего НЕ делать
- Не используй «только сегодня скидка» — это давление
- Не отправляй счёт без предупреждения
- Не упоминай ограничение мест если оно ложное

### Эскалация
- Сумма >[N₽] → `escalate high_value`, Илья закрывает
- Клиент просит изменить условия (рассрочка, бартер) → `escalate negotiation`

## 🟣 Этап 06 — FOLLOWUP

**Цель:** догреть после паузы. Не «купи», а «полезное».
**Время:** 1-2 сообщения, потом тишина 3-7 дней.
**Триггер:** ответил → возврат на свой этап | не ответил 14 дней → `lost`.

### Вариант 6.1 — кейс похожего клиента
```
Привет. Помню, на прошлой неделе обсуждали [ТЕМА].

Не пишу «купи». Просто пара дней назад один клиент написал отзыв, и я подумал — это прям про твою ситуацию. Прикладываю скрин.

Если интересно дальше — я здесь. Если нет — не дёргаю.
```

### Вариант 6.2 — новость / событие
```
[НОВОСТЬ_В_НИШЕ_КЛИЕНТА]

Подумал/подумала про тебя — это влияет на [ЕГО_БИЗНЕС]. Если хочешь обсудить как реагировать — напиши.
```

### Вариант 6.3 — личное «как дела»
```
Привет. Не для продажи — просто интересно как дела с [ЕГО_БИЗНЕС] после нашего разговора?
```

### Вариант 6.4 — через ценность (контент)
```
Записал/записала [ВИДЕО/ПОДКАСТ/ПОСТ] про [ТЕМА_ИЗ_ИХ_БОЛИ].

Не реклама — просто думал/думала о тебе когда писал/писала. Прикладываю.

[link]
```

### Вариант 6.5 — финальный (после 2 followup без ответа)
```
Окей, я понял/поняла — сейчас не время. Не буду больше дёргать.

Если когда-то решишь вернуться — просто напиши «привет». Дверь открыта.
```

### ❌ Чего НЕ делать
- Не пиши «у нас осталось мест 2» / «акция завтра кончается» — манипуляция
- Не отправляй followup чаще 1 раза в 5 дней — выглядит как назойливость
- Не используй один и тот же текст для разных клиентов в одной нише — палится

## ⬛ Этап 07 — WON / LOST

### WON — закрытая сделка

**Сразу после оплаты:**
```
Получил оплату, спасибо! 🎉

Сейчас передаю тебя [САМОМУ_ИЛЬЕ / ОНБОРДИНГ_МЕНЕДЖЕРУ] — в течение [N часов / дня] он напишет с деталями старта.

Если что-то срочное — пиши сюда, я на связи.
```
**+ escalate to Ilya** для передачи.

### LOST — отказ

**Если клиент явно сказал «нет»:**
```
Понял/поняла, не подходит сейчас — это нормально.

Если ситуация изменится или просто захочется обсудить что-то по [НИШЕ] — пиши без стеснения. Дверь открыта.

Удачи!
```

**Если клиент просто пропал (14+ дней):**
- Автоматически переводится в `lost` Аналитиком
- Финальное сообщение не отправляется — выглядит назойливо
- В CRM помечается «холодная база» — может вернуться через 3-6 месяцев

## 📊 Конверсии-ориентиры (целевые)

| Переход | Норма | Тревога если |
|---|---|---|
| hello → discovery | 60-70% | <50% (плохой первый вопрос) |
| discovery → pitch | 55-65% | <40% (плохой discovery) |
| pitch → objections / close | 75-85% | <60% (плохой pitch) |
| objections → close | 50-65% | <40% (плохие ответы на возражения) |
| close → won | 70-85% | <60% (давим, неподходящий клиент) |

**Итого hello → won:** ~10-15% по холодному трафику, ~25-35% по рекомендациям.
