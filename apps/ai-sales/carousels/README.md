# 🎠 IG-карусели — система

**Версия:** v1.0 · 15 мая 2026
**Назначение:** генерация Instagram-каруселей по дизайн-системе AI Mastery

---

## Что это

3 HTML-драфта каруселей, каждая на 10 слайдов 1080×1350px (вертикаль IG). Цель — продемонстрировать как карусели могут выглядеть в твоей дизайн-системе, и дать рабочую болванку для системы генерации.

Файлы:
- `carousel-01-pain-solution.html` — структура «боль → причина → решение» (10 слайдов)
- `carousel-02-case-study.html` — кейс клиента (10 слайдов)
- `carousel-03-list-mistakes.html` — список «5 ошибок» (10 слайдов)

---

## Как смотреть

Открой HTML-файл в браузере на десктопе — все 10 слайдов покажутся вертикально один под другим, каждый в формате 1080×1350.

Чтобы экспортировать в PNG для постинга:
1. Открыть в Chrome
2. F12 → Device Toolbar → задать 1080×1350
3. Скриншот каждого слайда (можно через `Cmd+Shift+P` → Capture full size screenshot)

Либо использовать Puppeteer для batch-экспорта (можно автоматизировать на этапе 4).

## Структура для AI-генератора (будущее)

Каждая карусель — это **шаблон с переменными**:

```json
{
  "template": "pain-solution",
  "topic": "автоматизация SMM для агентств",
  "segment": "edtech_agency",
  "voice_ref": "voice/tone-of-voice",
  "product_ref": "products/autopilot-smm",
  "slides": 10,
  "format": "1080x1350"
}
```

AI:
1. Читает топик + сегмент
2. Заходит в базу знаний за tone of voice
3. Генерирует контент по шаблону
4. Рендерит HTML
5. Экспортирует PNG-серию

Это полный сценарий **связки по каруселям** из задачи 1 TODO.md.

## Шаблоны структуры

### Тип 1: «Боль → Причина → Решение»
1. Hook: что-то крутое / провокация
2. Назвать боль
3. Усилить боль (почему это плохо)
4. Распространённая попытка решить (которая не работает)
5. Почему не работает
6. Настоящая причина проблемы
7. Решение (намёк)
8. Решение (раскрыть)
9. Результат / кейс
10. CTA + подпись

### Тип 2: «Case study»
1. Hook: цифра / результат клиента
2. Кто это (анонимно)
3. Ситуация ДО (3 буллета)
4. Боль / что не работало
5. Что попробовали и почему провалилось
6. Что мы сделали (1 главное)
7. Что мы сделали (детали)
8. Результат — цифры
9. Что клиент сказал (цитата)
10. CTA «хочешь так же?»

### Тип 3: «N ошибок»
1. Hook: «5 ошибок которые ___»
2. Ошибка 1 — название
3. Ошибка 1 — объяснение + что делать
4. Ошибка 2 — название
5. Ошибка 2 — объяснение
6. Ошибка 3 — название + объяснение
7. Ошибка 4 — название + объяснение
8. Ошибка 5 — название + объяснение
9. Главное правило сверху всех
10. CTA + подпись
