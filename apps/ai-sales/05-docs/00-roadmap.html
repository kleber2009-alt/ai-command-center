Section 03Стек

Что выбрали и почему.

LLM
Claude Opus 4.7 + Sonnet 4.6 + Haiku 4.5
Opus — мозг агентов на сложных задачах. Sonnet — для Аналитика и фоновых. Haiku — классификация и быстрые действия. Маршрутизация экономит до 70% бюджета
RAG
Voyage-3 + Qdrant self-hosted
Voyage-3 — лучшие эмбеддинги для русского. Qdrant — self-hosted, контроль над данными для 152-ФЗ
Голос
ElevenLabs Professional Voice Clone
Лучшее клонирование голоса на русском. Кэш популярных фраз снижает API-стоимость в 3–5 раз
Видео-кружочки
HeyGen + Wav2Lip гибрид
HeyGen — генеративный аватар для редких сценариев. Wav2Lip — подмена губ на твоих живых кружочках, естественнее
Транскрипция
Whisper Large v3
Распознаёт входящие аудио клиентов. На GPU быстрее в 5–10 раз
Бэкенд
Python 3.12 + FastAPI + LangGraph
LangGraph — оркестрация мульти-агентного state machine, идеально для 4 ролей
Очереди
Redis + Celery
Человеческие паузы перед ответом, retry, отложенные дожимы, кэш аудио
База данных
PostgreSQL 16
Клиенты, диалоги, действия, аналитика. Шифрование на уровне таблиц
Дашборд
Next.js 15 + shadcn/ui
Дизайн-система AI Mastery встроена. Server Components для скорости
Хостинг
Selectel VPS (РФ) + Hetzner (бэкап)
152-ФЗ требует данные россиян в РФ. Selectel 8CPU/32GB на старт
Каналы
IG Graph API + Telegram MTProto
IG — официально через Business-аккаунт. TG — MTProto-сессия через Telethon для личного аккаунта
Мониторинг
Grafana + Prometheus + Loki
Метрики, логи, алерты на сбои и аномалии в поведении агентов

TG-агент
Неделя 7–9 P1 / на платформе Разработчики + ты
Агент в личном Telegram: текст + аудио + кружочки.
  • Получить api_id и api_hash на my.telegram.org→ для MTProto
  • Подключить Telethon с personal-сессией→ внимательно к ToS
  • Обработчик входящих NewMessage→ только директ, не каналы

  • Pipeline кружочка: ElevenLabs аудио → Wav2Lip + видео-шаблон → 640×640 mp4→ нужен GPU
  • Отправка через MTProto: send_file с типом video_note→ круглый формат
  • Логика человеческих пауз для TG→ Celery
  • Защита от триггеров «массовая рассылка» Telegram→ ограничение rate
  • Тестовый прогон с командой→ 5 человек, 1 неделя
Работающий TG-агент в shadow mode
08
Аналитик + РОП
Неделя 8–10 P1 / на платформе Разработчики
Запустить два управляющих агента, замыкающих контур качества.
  • Промпт Аналитика: чек-лист скоринга 0–100 баллов→ Sonnet 4.6 (дешевле)
  • Cron каждый час: пройти открытые диалоги, поставить скор→ Celery beat
  • Логика рекомендаций: конкретные фразы для агентов→ запись в диалог
  • Эскалация диалогов со скором ≤ 40 на РОПа→ алерт
  • Промпт РОПа: декомпозиция плана продаж→ Opus 4.7
  • Утренний дайджест: 9:00, в Telegram тебе→ вчера / сегодня / риски
  • Вечерний дайджест: 21:00, итоги дня→ план vs факт
  • Алерты по горячим лидам (скор ≥ 85, готов к оплате)→ push в TG
  • Постановка задач IG/TG-агентам через РОПа→ внутренние сообщения

Section 07Риски и митигация

Что может пойти не так и как заранее закрыть.

Бан личного TG-аккаунта
High
Telegram банит MTProto-сессии за «массовость», особенно при единообразных ответах.
Жёсткие rate limits, человеческие паузы, вариативность ответов, прогрев аккаунта 1–2 нед
Отказ в Meta App Review для IG
High
Без advanced permissions IG-агент не видит входящие. Review требует тестового видео и обоснования.
Готовить App Review с первой недели; план Б — instagrapi (есть риск бана)
Клиенты узнали что ИИ — обиделись
Medium
Кто-то воспримет дисклеймер негативно. Особенно «старые» клиенты, привыкшие к личному общению.
Прозрачность с первого сообщения; премиум-клиентов оставить в личном ведении
Стоимость Claude API превысит бюджет
Medium
При росте объёма Opus 4.7 на каждом сообщении = сотни долларов в день.
Маршрутизация: Haiku для классификации → Opus только для сложных ответов + кэш аудио
Качество ответов не дотянет до ручного
Medium
Конверсия упадёт на 30–50% по сравнению с тем как ты продаёшь лично.
Запуск через shadow mode: 2 недели ты валидируешь каждый ответ, только потом авто
Сроки сдвинутся
Medium
12 недель — для опытной команды. Без опыта в LLM-агентах может затянуться до 16–20.
Технический ауд после этапа 5: если отставание >2 нед — резать scope
Голосовой клон звучит «неживо»
Low
Дешёвая запись или мало материала — «ИИ-эффект» в голосе.
PVC ElevenLabs + 30–60 мин качественной записи; тест на команде до клиентов
Утечка переписок клиентов
High
База диалогов — лакомая цель. Утечка = иск + репутация.
Шифрование at-rest, VPN, 2FA для админов, токенизация ПДн, регулярные пентесты
