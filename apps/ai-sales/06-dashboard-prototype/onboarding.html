/ Step 03 of 06 · ~3 минуты

Дай мне свой голос.

Без него агенты звучат как generic AI. С ним — звучат как ты. Выбери способ.

/ 01 — РЕКОМЕНДУЮ Загружу подкасты Свои аудио (1-2 эпизода) → whisper-транскрипция → извлечение голоса, ценностей, любимых фраз. Самый точный способ.
/ 02 Пройду интервью 5 блоков по 10-15 минут. Я задаю вопросы — ты отвечаешь. Подходит, если нет аудио-записей.
/ 03 Загружу переписки Экспорт IG/TG чатов → анализ стиля. Точно по текстовому общению, но без голоса как тона.
/ 04 Позже Пропустить этот шаг. Агенты будут работать в generic-режиме до настройки голоса.

API-ключи и подключения.

Без ключей агенты в mock-режиме. Можно пропустить — настроишь в Settings потом.

ElevenLabs → голос

/ Step 05 of 06 · ~3 минуты

Где будут общаться агенты?

Подключи каналы. Можно начать с одного — например, TG для теста.

Telegram Bot → быстрее всего

5 минут через @BotFather. Хороший вариант для тестового запуска перед IG.

Instagram Graph API → нужна модерация Meta

Требует Facebook Business Manager + верифицированный аккаунт. 1-3 дня на модерацию.

Какие каналы запустить сейчас?

/ 01 Только TG · тестовый Бот только для меня. Я тестирую → ловлю баги → потом подключу клиентов.
/ 02 TG · боевой Бот для клиентов. Реальный трафик.
/ 03 TG + IG · оба Полный запуск. IG webhooks подключаются после модерации Meta.
/ 04 Пока не запускать Сначала наполню базу знаний, потом активирую агентов.
