Покупка и настройка VPS

Первый шаг к рабочей платформе. Покупаем сервер, заходим по SSH, делаем безопасным.

Время
40–60 мин
Сложность
Низкая

~3000₽/мес
Что нужно
Карта + почта

Section 01Что такое VPS и зачем

VPS — виртуальный сервер, всегда работающий компьютер в дата-центре. На нём будут жить наши агенты, база данных, дашборд.

Локальный компьютер для этого не подходит: ты выключаешь его, теряешь интернет, уезжаешь. Платформа должна работать 24/7 — отвечать клиентам в любое время.

Альтернативы вроде «облачных функций» (AWS Lambda и т.д.) — сложнее и дороже для нашей задачи. VPS — золотая середина.

Section 02Выбор провайдера

У нас есть данные российских клиентов → серверы в РФ обязательны по 152-ФЗ.

Рекомендую → главный

Selectel

~2 800 ₽/мес за нужную конфигурацию

Российский провайдер. Серверы в Москве и СПб. Соблюдение 152-ФЗ из коробки, оплата с российских карт.

Конфиг: 8 vCPU · 16 ГБ RAM · 200 ГБ NVMe SSD · Ubuntu 24.04

Альтернатива

Timeweb Cloud

~3 200 ₽/мес

Тоже российский, проще интерфейс. Подходит, если Selectel показался сложным.

Альтернатива

VK Cloud (Mail.ru)

~3 500 ₽/мес

Крупный игрок, подойдёт если важна высокая SLA.

Не бери Hetzner и AWS на старте — несмотря на качество, серверы за рубежом создадут юридические проблемы по 152-ФЗ.

Section 03Покупка сервера в Selectel

01
Регистрация
5 мин

Открой selectel.ru, нажми «Регистрация». Используй рабочий email и телефон. Тариф для физлица — норм для старта, потом перейдёшь на ИП.

02
Раздел «Облачные серверы»
2 мин

В панели — раздел «Облачная платформа» → «Серверы». Нажимаешь «Создать сервер».

03
Параметры сервера
5 мин

Выбери эти параметры:

РегионМосква (ru-1)
ТипCloud Server (Standard line)
ОСUbuntu 24.04 LTS
vCPU8
RAM16 GB
Диск200 GB NVMe SSD
СетьПубличный IPv4

Имя сервера: aisales-prod-01 — удобно для админки.

04
SSH-ключ
5 мин

Не выбирай «пароль» — это небезопасно. Только SSH-ключ.

На своём Маке открой Терминал (Spotlight → Terminal):

ssh-keygen -t ed25519 -C "ilia@aisales"

Нажми Enter три раза (без пароля для простоты). Затем выведи публичный ключ:

cat ~/.ssh/id_ed25519.pub

Скопируй всю длинную строку (начинается с ssh-ed25519) и вставь в Selectel в поле «SSH-ключ» при создании сервера.

05
Оплата и запуск
3 мин

Пополни баланс на сумму ~5000 ₽ (хватит на 1.5 месяца с запасом). Нажми «Создать». Сервер запустится за 1–2 минуты.

На карточке сервера ты увидишь публичный IP — что-то вроде 89.108.xxx.xxx. Запиши его.

Проверка после шага: в админке Selectel сервер со статусом «Active», виден IP-адрес, есть SSH-ключ.

Section 04Первое подключение

06
SSH-вход
2 мин

На Маке в Терминале выполни (замени IP на свой):

ssh root@89.108.xxx.xxx

При первом подключении спросит "Are you sure?" — пиши yes. Если всё ок, увидишь приветствие Ubuntu и приглашение root@aisales-prod-01:~#.

Если не пускает: проверь, что IP правильный и SSH-ключ загружен в Selectel. Если всё равно — пиши мне сюда с текстом ошибки.
07
Обновление системы
5 мин

На сервере выполни две команды:

apt update apt upgrade -y

Подожди, пока скачаются и установятся обновления.

Section 05Безопасность

Сервер открыт во внешний мир. До установки приложений закроем его как сейф.

08
Отдельный пользователь
5 мин

Никогда не работай под root. Создаём пользователя aisales:

adduser aisales # задай пароль (запомни/запиши), остальные поля Enter usermod -aG sudo aisales

Скопируем SSH-ключ root для нового пользователя:

rsync --archive --chown=aisales:aisales ~/.ssh /home/aisales
09
Проверь нового пользователя
2 мин

Открой новое окно Терминала (старое не закрывай). В новом:

ssh aisales@89.108.xxx.xxx

Должно пустить. Если работает — закрой старое окно с root, дальше работаем под aisales.

10
Firewall (UFW)
5 мин

Под пользователем aisales (а не root) выполни:

sudo ufw allow OpenSSH sudo ufw allow 80/tcp sudo ufw allow 443/tcp sudo ufw enable

На вопрос «Proceed?» — y. Это открыло только HTTP, HTTPS и SSH.

Проверь статус:

sudo ufw status
11
Запрет входа по паролю
3 мин

Чтобы никто не подобрал пароль брутфорсом:

sudo nano /etc/ssh/sshd_config

Найди (Ctrl+W в nano) и измени строки:

PasswordAuthentication no PermitRootLogin no

Сохрани: Ctrl+O → Enter → Ctrl+X. Перезапусти SSH:

sudo systemctl restart ssh
12
Установка fail2ban
3 мин

Автоматический бан тех, кто долбится в SSH:

sudo apt install fail2ban -y sudo systemctl enable fail2ban sudo systemctl start fail2ban
Проверка после раздела: ты заходишь по SSH только как aisales, root и пароли заблокированы, открыты только нужные порты.

Section 06Что дальше

Сервер куплен, защищён, готов к нагрузке. Следующий шаг — установить Docker и развернуть все базы.
