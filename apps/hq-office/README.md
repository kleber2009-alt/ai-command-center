# hq-office — живой офис агентов (hq2.aicex.club)

Вторая версия `hq.aicex.club`: один open-space вместо четырёх комнат. Агенты стоят
за пультами отделов, сами носят друг другу готовые работы, приходят к вашему
столу, ходят в библиотеку, к принтеру, на кофе и на планёрки. Справа — **история
реальных задач** с доказательствами: её можно открыть на вебинаре и показать,
что это действительно сделали вы, команда и агенты.

Статический сайт без сборки: `index.html` + файлы данных. Three.js 0.160 с jsDelivr
через import map, шрифты Google Fonts.

## Файлы

| Файл | Что внутри | Откуда |
|---|---|---|

| `tasks.auto.js` | задачи, которые добавляются сами: новые PR и ссылки из формы | `sync/sync.mjs` |
| `works.js` | работы агентов сверх копий с hq.aicex.club: превью сайтов и страниц, свои блоки работ и скиллы | этот репозиторий |
| `works/` | превью для карточек работ: снимки живых публичных сайтов и страниц | этот репозиторий |
| `assistant/` | личный ассистент: сервер `/api/assistant/*` (Claude + голос ElevenLabs) | этот репозиторий, на сайт не выкладывается |
| `office.config.js` | отделы, руководители, продукты | копия с hq.aicex.club |
| `agent-content.js` | досье агентов: что умеют, процесс, скиллы, работы, шаблоны задач | копия с hq.aicex.club |
| `dept-content.js` | окна отделов и руководителей | копия с hq.aicex.club |
| `people/*.jpg` | фото руководителей | копия с hq.aicex.club |
| `deploy/` | выкладка: блок Caddy и установка на свой сервер | — |
| `sync/` | сборщик истории из GitHub (не выкладывается на сайт) | — |

Чтобы обновить досье и материалы, скопируйте свежие `office.config.js`,
`agent-content.js`, `dept-content.js` с hq.aicex.club — формат тот же. Добавки hq2
(превью, свои работы и скиллы агентов) лежат в `works.js` и копированием не затираются.
Новая работа агента появляется в досье сама, как только она есть в истории задач.

## История задач (`tasks.js`)

Каждая задача подтверждается ссылкой и датой, которую можно проверить:

- PR или коммиты в публичном репозитории GitHub — дата слияния/коммита;
- артефакт в Claude — дата последнего обновления (открывается под аккаунтом
  владельца или если им поделились);
- живой сайт продукта, файл, видео или страница на marketing.aicex.club.

Сейчас в истории 47 задач с 16 мая по 28 октября 2026: 25 подтверждены GitHub
(69 PR и история коммитов), 24 — артефактами Claude, плюс сайты, ролики и страницы. Отдел и агенты
у задачи — по оргструктуре из `office.config.js`; поправьте `people`/`agents`,
если задачу делал конкретный человек.

Добавить задачу — новый объект в массиве:

```js
{ id:'webinar-nov', date:'2026-11-05', dateNote:'слияние PR на GitHub', kind:'Разработка',
  dept:'marketing', people:['ilia'], agents:['slides', 'landings'],
  title:'…', summary:'…',
  proof:[...pr(150), art('ID', 'Название артефакта'), site('https://…', 'Сайт')],
  media:[vid('video/x.mp4', 'Ролик', 'img/shots/x.jpg'), img('img/…', '…'), page('pages/…', '…')] },
```

## История пополняется сама

`.github/workflows/hq-office-history.yml` запускает `sync/sync.mjs` после каждого пуша в
`main` и раз в сутки (04:17 UTC):

1. берёт PR, слитые в `main` с прошлого запуска; пропускает ботов, обновления зависимостей,
   правки CI, правки самой истории, PR с меткой `hq:skip` (или «не в историю») и PR, которые
   уже упомянуты в `tasks.js`;
2. PR одной ветки одного продукта, слитые в пределах трёх дней, — одна задача. Продукт, отдел
   и агенты — по папке `apps/<продукт>` (таблица `PRODUCTS` в `sync.mjs`);
3. Claude пишет по PR русское название и одно-два предложения «что это даёт» (секрет
   `HQ_OFFICE_ANTHROPIC_API_KEY` — отдельный ключ для истории, расходы видны отдельно). Без ключа или
   если вызов не удался — название PR и первый абзац его описания; такая задача помечена
   `draft` и перепишется Claude при первом запуске с ключом, если её текст не правили руками;
4. дописывает задачи в `tasks.auto.js`, коммитит в `main` и запускает выкладку.

Готовую задачу в `tasks.auto.js` можно поправить руками — синк её не перезаписывает, только
добавляет к ней новые PR той же ветки. Удалённая задача не вернётся (её PR остаются в `seen`).
Чтобы задача стала «ручной», перенесите её в `tasks.js`.

**Добавить по ссылке** (артефакт Claude, PR, сайт): GitHub → Actions → hq-office-history →
Run workflow → ссылка, название (для артефакта Claude обязательно — снаружи он закрыт),
отдел, пара предложений. Или напишите Claude «добавь в историю офиса <ссылка>» — скилл
`.claude/skills/hq-history` прочитает артефакт и добавит задачу в `tasks.js`.

Локально:

```bash
cd apps/hq-office/sync && npm ci
GITHUB_TOKEN=… node sync.mjs prs --dry                     # что добавится, без записи
node sync.mjs add --url https://claude.ai/artifact/… --title '…' --dept marketing
```

Задачи за последние 7 дней помечены в панели меткой «новое».

## Что на экране

- **Панель «История задач»** справа: вкладки «Задачи», «Команда», «Скиллы»,
  фильтр по отделам, поиск. Кнопка «Скрыть» убирает панель, кнопка
  «История задач» в углу возвращает (запоминается). Клик по агенту или
  руководителю в 3D — его задачи в панели.
- **Окно задачи**: описание, люди и агенты, доказательства (GitHub / Claude /
  сайт / файл), видео, картинки, живые страницы, процесс работы агента и его
  скиллы. Стрелки ← → листают задачи, Esc закрывает. У каждой задачи свой адрес:
  `https://hq2.aicex.club/#task-funnel-analytics` — удобно открыть сразу нужную.
- **Досье** агента (`#agent-montage`) и руководителя (`#head-firuza`): что умеет,
  задачи, готовые работы, скиллы, как поставить задачу — как на hq.aicex.club.
- **Готовые работы** агента (`#agent-montage/works`) собираются сами: витрина из досье +
  всё, что есть у агента в истории задач — ролики, картинки, живые страницы, документы
  Claude, сайты, файлы, код на GitHub — карточками с превью и ссылкой на задачу. У
  руководителя — «Работы отдела» (`#head-bogdan/works`). Вкладка **«Работы»** в панели —
  все агенты с превью и сводкой, сколько и чего сделано.
- **3D-офис**: движение агентов — визуализация того, как устроена работа; в руках
  у агентов и на их мониторах — названия реальных задач из истории. Доска на
  стене и ноутбук на вашем столе показывают последние задачи.
- **Ассистент** (кнопка в доке): личный помощник, с которым говорят голосом или
  текстом. Подробнее — раздел «Личный ассистент».
- **Док**: Обзор, Мой стол, Задачи, План, Ассистент, Экскурсия, Подписи; темы Волна,
  Обсидиан, Атриум.

## Личный ассистент

Кнопка «Ассистент» в доке открывает чат с офисом. Сервер — `assistant/server.mjs`
(Node, официальный SDK Claude), на сайте он отвечает по адресу `/api/assistant/*`.

- **Владелец** входит паролем (секрет `HQ_ASSISTANT_PASSWORD`, вход живёт 90 дней). Можно
  писать или нажать микрофон и говорить: речь распознаёт ElevenLabs Scribe, ответ печатается
  и сразу озвучивается клоном голоса из Persona Train — по предложениям, не дожидаясь конца.
  «Доложи обстановку» — короткая голосовая сводка по офису. Галочка «озвучивать и текст»
  включает голос и для текстовых вопросов. Голос выбирается один раз ссылкой «Голос: …»
  (или переменной `HQ_ASSISTANT_VOICE_ID`); без выбора ищется клон с именем Ильи.
- **Что знает**: всё про офис из тех же файлов, что грузит сайт (отделы, агенты, работы,
  история задач, сводка за 7 дней), карту продуктов из корневого `CLAUDE.md` и долгую
  память: последние 40 реплик идут в разговор целиком, более старые Claude сворачивает
  в заметки (`assistant-data/owner.json` на сервере).
- **Гости** видят текстовое демо: ассистент рассказывает только о публичной истории задач,
  без голоса, 20 вопросов в час с одного адреса и 400 в сутки на всех.
- Модель — `claude-opus-5-5` (effort `low`, при отказе — запасная модель Anthropic).
  Задачи агентам ассистент пока не ставит — только разговор, отчёты и советы.

Локально, с офисом на том же адресе:

```bash
cd apps/hq-office/assistant && npm ci
ANTHROPIC_API_KEY=… ELEVENLABS_API_KEY=… HQ_ASSISTANT_PASSWORD=… npm run dev   # → http://localhost:8787/
```

## Выкладка

`.github/workflows/deploy-hq-office.yml` — на каждый пуш в `main` с изменениями
в `apps/hq-office/` (и вручную из Actions):

1. проверяет файлы данных (синтаксис, у каждой задачи `tasks.js` и `tasks.auto.js` дата и доказательство),
   собирает ассистента (`npm ci`, карта проектов из корневого `CLAUDE.md`);
2. по SSH (`HETZNER_SSH_KEY`, `vars.HETZNER_HOST` — сервер, на который смотрит
   `*.aicex.club`) заливает релиз в `/opt/hq-office/releases/<id>`;
3. `deploy/server.sh` атомарно переключает `/opt/hq-office/current`, держит
   контейнер со статикой `aicex-hq-office` в сети `edge` и файл сайта
   `/opt/edge/sites/hq-office.caddy` для edge-Caddy (проверка → reload, при
   ошибке файл восстанавливается); хранит три последних релиза. Ассистент — отдельный
   контейнер `aicex-hq-assistant` (`node:22-alpine`, код в `/opt/hq-office/assistant/current`,
   ключи в `/opt/hq-office/assistant.env` из секретов `HQ_OFFICE_ANTHROPIC_API_KEY`,
   `PERSONA_TRAIN_ELEVENLABS_API_KEY`, `HQ_ASSISTANT_PASSWORD`, память в
   `/opt/hq-office/assistant-data`); Caddy отправляет к нему `/api/assistant/*`;
4. проверяет, что `https://hq2.aicex.club/`, `tasks.js` и `/api/assistant/health` отвечают 200.

Откат: в Actions перезапустить успешный прошлый прогон или вернуть коммит.
