# hq-office — живой офис агентов

Концепт новой версии `hq.aicex.club`: вместо четырёх отдельных комнат — один
open-space по референсу «Виртуальный офис агентов». Агенты стоят за пультами
отделов, сами носят друг другу готовые материалы, приходят к вашему столу за
решением, ходят в библиотеку, к принтеру, на кофе и на планёрки.

Один файл `index.html`, без сборки. Three.js 0.160 подключается с jsDelivr
через import map, шрифты — Google Fonts (Manrope, JetBrains Mono).

## Запуск

```bash
cd apps/hq-office
python3 -m http.server 8765   # → http://localhost:8765/
```

Параметры адреса:

| Параметр | Что делает |
|---|---|
| `?theme=wave\|obsidian\|atrium` | стартовая тема (иначе — последняя выбранная или по системной теме) |
| `?noao` | без ambient occlusion (слабые видеокарты, скриншоты) |
| `?debug` | `window.__hq`: сцена, агенты, `step(сек)` — прокрутить симуляцию без рендера |

## Что на экране

- **3D-зал** (32 × 19,5 м): LED-стена с «прибоем», доска задач, стеллаж с тёплой
  подсветкой и архивом готовых работ (папки появляются по мере согласований),
  синий куб, ваш стол-«лента», пульты четырёх отделов, лаунж и кофе у окна.
- **Пульты**: у каждого агента монитор с тем, что он делает прямо сейчас
  (код, документ, графики, переписка, календарь, монтажная дорожка, слайды,
  схема воронки, аватар), прогресс задачи, стопка бумаг — растёт, когда
  коллеги приносят материалы.
- **Панель «Команда»** справа: карточка агента (что делает, прогресс,
  «Нужно ваше решение» с кнопками «Одобрить» / «Вернуть на доработку»,
  материалы на столе, ссылки на готовые работы), список всех агентов
  со статусами и «Лента» передач в реальном времени.
- **Док** снизу: Обзор, Мой стол (вид из вашего кресла), Команда, План,
  Экскурсия (камера сама облетает отделы с подписями), Подписи.
- **Темы**: Волна (как на референсе), Обсидиан (ночной штаб), Атриум (тёплый день).

## Как живут агенты

Каждый агент крутит цикл: работает над задачей → несёт результат тому, кто
работает дальше (`out` в данных) → возвращается → следующая задача. Если
результат нужно согласовать (`to: 'you'`), агент идёт к вашему столу и ждёт
~40 секунд; не дождался — оставляет документ во входящих. Решение, которое
лежит больше трёх минут, принимает руководитель отдела по делегированию,
чтобы демо не застывало. Агенты с `needsInput` (карусели, аватар, рассылки,
брифинг) ждут входящий материал. Оркестратор обходит отделы и раз в несколько
кругов собирает планёрку у доски задач. Руководители сидят за столами,
поворачиваются к тем, кто приносит материалы, и иногда уходят за кофе.

Маршруты — A* по сетке 20 см с обходом мебели; позы (ходьба, печать, «думаю»,
несу документ, разговор, сидя, радость, «развёл руками») смешиваются по весам.

## Данные

Блок `window.OFFICE_DATA` в начале файла: отделы и руководители (как в
`office.config.js` на hq.aicex.club) и каталог агентов — имя, роль, цвет,
тип экрана, очередь задач, кому передаёт результат и ссылки на готовые
работы. Если на странице до основного скрипта подключён `office.config.js`
(`window.OFFICE_CONFIG`) или каталог (`window.AGENT_CATALOG`), они имеют
приоритет.

API для встраивания:

```js
VirtualOffice.setAgent('montage', { task: 'Монтирует рилс «ИИ-офис»' });
VirtualOffice.select('scripts');          // выбрать и лететь за агентом
VirtualOffice.view('desk' | 'overview' | 'plan' | 'tour');
VirtualOffice.theme('obsidian');
// из <iframe>: postMessage({ type: 'office:agent', id, task }), 'office:focus', 'office:theme'
```

## Чего пока нет по сравнению с текущим hq.aicex.club

Досье агента с вкладками, демо-презентации отделов, игровой трек `?game`,
3D-модель руководителя из `.glb` и фото лиц. Состав офиса и тексты задач
перенесены, ссылки на готовые работы — тоже.
