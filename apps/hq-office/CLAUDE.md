# hq-office — CLAUDE.md

Живой офис агентов, вторая версия `hq.aicex.club` → `hq2.aicex.club`. Статика без сборки. Подробности — `README.md`.

- `index.html` — классические скрипты данных (`office.config.js`, `dept-content.js`,
  `agent-content.js` — копии с hq.aicex.club, `tasks.js` — история задач, `works.js` — превью
  и добавки к работам), затем `window.OFFICE_DATA` (тип экрана и цепочки передач агентов для
  визуализации), затем модуль.
- Модуль по разделам: планировка → рендер (GTAO + bloom) → текстуры/материалы →
  навигация (A* по сетке 0,2 м) → здание и мебель → риги и позы → класс `Agent`
  (план действий walk/do/work/call) → экраны на canvas → история задач и досье →
  камера/экскурсия → цикл.
- **Правая панель показывает только реальные задачи из `tasks.js`** — у каждой дата
  и ссылка-доказательство (PR/коммиты на GitHub, артефакт Claude, сайт, файл). Не добавлять
  туда выдуманные задачи; симуляция в 3D — только визуализация.
- «Готовые работы» в досье и вкладка «Работы» в панели собираются из витрины досье и истории
  задач (`collectWorks` в модуле) — новую работу достаточно добавить задачей. `works.js` — добавки
  hq2 поверх копий с hq.aicex.club: превью (`works/`, только публичные страницы), свои блоки работ
  и скиллы агентов.
- Личный ассистент — `assistant/` (Node, SDK Claude, голос ElevenLabs): сервер `/api/assistant/*`,
  на сайт не выкладывается, свой контейнер `aicex-hq-assistant`. Знания — те же файлы данных
  (`assistant/office.mjs`), история хранится текстом без блоков thinking, старое сворачивается в
  долгую память. Владелец — по паролю; гость — текстовое демо с лимитами. Владельцу ставит задачи
  агентам (инструмент `create_task`).
- Двойник — `twin/index.html` (`hq2.aicex.club/twin/`; кнопка «Двойник» в доке ведёт на `twin/concepts.html`): цифровой двойник Ильи и Claude —
  сцена с карточками, камера, разговор голосом/текстом, орб; вкладки «Что знает» и «План развития» (этапы 0–5).
  Без входа — демо-сценарий «утро с двойником» (пример, не данные Ильи); владелец говорит вживую через
  `/api/assistant/chat` с `twin:true` (роль и знания — `assistant/twin.mjs`: `twin-profile.md` + правила скиллов
  `remake-top-reel`/`carousel-pro`, при выкладке копируются в `assistant/twin-skills/`) и `image` — JPEG-кадр камеры,
  только в этом ходе, не сохраняется. Разделы профиля «(заполняет Илья)» двойник не додумывает.
  `twin/concepts.html` — тот же двойник в 25 дизайнах (`V`, `?v=1…25`; №18–25 — лица на той же оболочке: робот, андроид-визор,
  пришелец, звёздный медиум, аура, энергетическое поле, голограмма из точек и голограмма-срез — голова `headPt`/`headProj`, моргание `blinker`, взгляд `lookAt`; №13–17 — «живой организм» на общей оболочке
  `organism()`: клетка, мицелий, сифонофора-колония агентов, морфогенез Грея — Скотта, анатомия-взрыв-схема; живут сами — сердцебиение, спонтанные события, тянутся к курсору,
  отвечают на касание через `o.ptr` / `o.onPoke`), каждый рабочий: один движок (`ask`) — ответ
  потоком (`api.open()` → текст по дельтам, `api.close`), голос по предложениям (`speakPart`: `/tts` клоном или голос
  браузера), режим «Говорить» без кнопки (на компьютере — Web Speech `ru-RU`; на телефонах всегда своя запись по голосу:
  порог по шуму комнаты, пауза 0,8 с → `/stt`; звук — через Web Audio, разблокируется первым тапом), перебивание голосом,
  тапом по сцене или Esc, кадр камеры по «посмотри»/«Посмотри». Без входа — демо по `SCRIPT`; после входа разговор (`HIST`)
  переносится при смене дизайна. Нейрограф — в нано-стиле, узлы знаний подсвечиваются по словам (`guess`).
  Распознавание на телефонах — потоковое ElevenLabs realtime Scribe прямо из браузера (`startRealtime`: одноразовый токен
  `POST /api/assistant/stt-token`, PCM 16 кГц, VAD сервера), при сбое — запись по паузе → `/stt`. Память двойника —
  инструмент `remember` (только `twin:true`): что Илья рассказал об аудитории, tone of voice, рубриках, стратегии, фактах —
  в `DATA_DIR/twin-memory.json` на сервере, попадает в знания двойника; кнопка «Интервью» со счётчиком заполненного профиля.
  База знаний двойника — `assistant/kb.mjs`: при выкладке `node kb.mjs build` собирает `twin-kb/index.json` (реестр проектов
  `apps/command-center/registry/projects.mjs`, все README/CLAUDE.md/спеки монорепо, тексты лендингов, скиллы); сводка (реестр
  + архитектура + список документов) всегда в промпте двойника, остальное — инструменты `search_knowledge` / `read_document`.
  Свои материалы Илья загружает кнопкой «Материалы» (`POST /api/assistant/twin/kb?name=…`: .md/.txt/.csv/.html/.json и выгрузка
  claude.ai — каждый чат и проект отдельным документом) в `DATA_DIR/kb-private` на сервере, в git они не попадают.
  Двойник — пульт Claude Code: инструменты `run_claude_code` (прямая задача исполнителю без диспетчера, агент `claude-code`
  в `desk.mjs`, все скиллы сервера), `desk_tasks` / `desk_task` / `desk_action` (статусы, ответ на вопрос, принять, правка,
  повтор, отмена — `desk.act`). Исполнитель при старте шлёт все скиллы сервера (`POST desk/runner/skills` → `DATA_DIR/desk/skills.json`):
  список — в сводке двойника, тексты — в поиске. Чат принимает `images` (до 4 картинок) и `uploads` (файлы `desk/upload` → в первую
  задачу хода). Дизайн №1 «Claude» — чат с markdown, история с сервера, панель задач с действиями.
- Голограмма двойника в офисе — кнопка «Голограмма» в доке (`holoSummon` в `index.html`, 3D — `holo.js`): проектор на полу,
  световой конус и голова из точек (та же процедурная голова, что `twin/concepts.html?v=24`) появляется в центре зала —
  в «Галерее» на свободном месте у центра (`holoSpot`), в «Ночном Сити» над столом оркестратора (`NIGHT.look`). Говорит тем же
  двойником (`/api/assistant/chat` с `twin:true`), голос — общая очередь ассистента (`enqueueSpeech`). С каждым вопросом уходит
  `office` — снимок офиса (`officeSnapshot`: агенты в 3D и что делают, задачи рабочего стола со статусами и вопросами, последние
  задачи истории, что открыто), сервер вставляет его в ход и не сохраняет. Об агентах, которых называет, голограмма
  поворачивается к ним и тянет луч (`holoPoint`); события рабочего стола видит сама (`holoEvent`).
- Рабочий стол — `assistant/desk.mjs` (`/api/assistant/desk/*`, только владелец): диспетчер (Claude по
  каталогу агентов) → очередь → исполнитель `runner/runner.py` (служба `hq-runner` под пользователем ботов
  на сервере `*.aicex.club`, Claude Code со скиллами команды, общий слот `~/.heavy-slot.lock`) → проверка
  владельцем → история (`/api/assistant/desk/history.js`, `window.OFFICE_TASKS_DESK`). В `index.html` —
  раздел «РАБОЧИЙ СТОЛ»: вкладка «В работе», окно `#desk-<id>`, 3D (`Agent.live`, оркестратор относит задачу).
  Память исполнителя ограничена (`MemoryMax=4608M`, `OOMPolicy=continue` в `runner/hq-runner.service`): при нехватке
  ядро убивает только тяжёлый процесс, исполнитель жив и сдаёт ошибку с причиной; проверка сервера — workflow
  `hq-runner-diagnose.yml` (только чтение).
  **Сначала стиль**: задача на монтаж, видео, рилс или карусель (диспетчер ставит `visual`) не уходит агенту, пока Илья
  не выберет стиль — вопрос `{from:'style', options}` (`STYLE_MENU` в `desk.mjs`: стили Кадрика и рилс-скиллы сервера,
  стили `carousel-pro`, «Выбери сам»), в офисе — кнопками, у двойника — кнопками и через `desk_action answer`. Если стиль
  назван в задаче (`style_named`), не спрашивает. Стиль-скилл заменяет обычный скилл, а `remake-top-reel`/`carousel-pro`
  остаются и получают стиль строкой в ТЗ.
  **Связка с Транскрибатором** (агент `transcriber`, отдел «Стратегия», в «Ночном Сити» — в контент-студии): если в задаче
  ссылка на ролик (Instagram, YouTube, TikTok, VK…) или видеофайл и результат строится на том, что в нём говорят, диспетчер
  ставит `transcribe` — задача сначала уходит этапом `pending.kind = 'transcribe'`: исполнитель без Claude запускает скрипт
  скилла `.claude/skills/transcribe-reference` (yt-dlp/Apify → ElevenLabs Scribe → OpenAI → stt.py → faster-whisper), расшифровки
  ложатся в `in/transcript-<n>.md`, и задача сама переходит выбранному агенту (`t.transcribed`, в промпте — «строй на расшифровке,
  не копируй»). Задача «просто расшифруй» — агенту `transcriber`, результат — страница `out/index.html`. Скилл ставится
  выкладкой рядом с исполнителем и в `~/.claude/skills` пользователя ботов; ключ ElevenLabs — из `assistant.env` в `runner.env`.
  **Утренние агенты** (`ROUTINES` в `desk.mjs`, время МСК, состояние `DATA_DIR/desk/routines.json`, выключить — `HQ_ROUTINES=off`):
  «Балансы и подписки» (`billing`, 08:50 — исполнитель без Claude запускает скилл `service-balances`: ключи Anthropic/OpenAI/
  ElevenLabs/HeyGen/Apify/Deepgram/kie.ai/Meta Ads + `HQ_SUBSCRIPTIONS_JSON`; нет предупреждений — задача закрывается сама,
  без публикации) и «Статистика соцсетей» (`socialstats`, 09:10 — Claude Code по скиллу `social-daily-stats`, снимки для
  приростов в `~/.local/state/aicex-social`). Итоги, предупреждения и ошибки утренних задач — в Telegram владельца ботом
  Office Worker (`HQ_NOTIFY_TG_TOKEN`/`HQ_NOTIFY_TG_CHAT` в `assistant.env`). Ключи этих скриптов — `~/hq-runner/keys.env`
  (`HQ_KEYS_FILE`, пишет шаг «Keys of the morning agents»), в окружение исполнителя и Claude Code не попадают.
  **Материалы** — файлы прикрепляются к новой задаче, к правке и к ответу на вопрос (`PUT desk/upload` → `uploads` в
  `POST tasks`, `tasks/<id>/revise`, `tasks/<id>/answer`; `takeUploads` кладёт их в `in/` задачи, при совпадении имени — `-2`):
  исполнитель докачивает новые файлы перед каждым запуском, а промпт правки/ответа называет их отдельной строкой.
  Страницы агентов — только в песочнице (CSP `sandbox` + `iframe sandbox` без `allow-same-origin`).
- **Команда — 33 агента, у каждого свой стол** (в «Волне» дуга отдела вмещает до 16, `slice(0, 16)` в `DEPTS`; в «Ночном Сити» —
  `ROOM_OF`, лишние — `OVERFLOW`). Каждый проект реестра `apps/command-center/registry/projects.mjs` закреплён за агентом-хозяином:
  `OWN_PRODUCTS` в `agent-content.js` → блок «Продукты и боты» в досье и строка «Продукты и боты» в каталоге диспетчера (`desk.mjs`).
  Скиллы последних недель — `MORE_SKILLS` там же. Новый агент = карточка `AGENT_CATALOG` + досье `AGENT_CONTENT` + отдел в
  `office.config.js` и в запасном `config` `index.html` + передачи `OFFICE_DATA.catalog` + комната `ROOM_OF` в `night.js` + `TEAM` в `concepts/`.
- **Переговорная легенд** (`council` в `office.config.js`, скилл «Команда 8 легенд»): ИИ-советники по методам Хормози (оффер),
  Гэри Ви (контент), Година (бренд), Брансона (воронки), Уокера (запуски), Кеннеди (прямой отклик), Кардона (продажи), Брэнсона
  (стратегия, 90 дней) + `legends` «Совет легенд» (все восемь, без фигуры в 3D). Не отдел: в «Волне» — стеклянная комната
  `COUNCIL_ROOM` справа (стол на восемь, вход с запада, табличка → досье совета), псевдо-отдел `COUNCIL` для `agentMeta`, без обходов
  оркестратора; в «Ночном Сити» — 8 кресел стола «Переговорной» (`ROOM_OF` → `meet`, `MEET_TAKEN`), два у торца — гостям, планёрка
  стоит у экрана. Диспетчер видит комнату в каталоге; задачи советникам — промпт «собеседование/исправление: оценка по критериям
  метода → исправленная версия», совет — по разделу на каждого и общий вердикт (`jobPrompt`, `a.dept === 'council'`).
- **Дизайн рабочего стола.** Маршрут задачи `deskStages(t)` (Поставлена → Диспетчер → (Транскрибатор) → агент → Ваша проверка →
  Готово/В истории; состояния done/now/queue/need/err/off) — крупно в окне (`flowHTML`), сегментами на карточке (`flowBar`) и
  превью «Что будет дальше» в форме. Источник задачи `t.source` (`office` | `assistant` | `twin` | `routine`, ставит `desk.mjs`
  при создании; `deskSource`). «В работе»: счётчики и группы «Ждут вас / В работе / В очереди / Закрыто», карточка `.dkc` с
  кнопкой действия. Окно задачи: шапка (агент, статус, источник, скилл, стиль), «Ждёт вас», «Результат» (markdown `mdLite`,
  превью, файлы с иконками по типу), «Что вы просили» / «Как понял диспетчер», «Ход работы» — лента по дням, кто сделал шаг
  (`stepActor`). Форма: поле с материалами и подсказкой про ссылку на ролик, «Кому» — диспетчер или сетка агентов с поиском.
  **Выдача результата.** Агент сдаёт отчёт по шаблону (`RULES` в `desk.mjs`): `## Что сделано` / `## Главное` / `## Материалы`
  (`- out/<путь> — что это`) / `## Что дальше`, правка — плюс `## Что изменено`; до 8000 знаков (runner и desk). В окне:
  `deskResultHTML` → `parseReport` (раздел «Материалы» становится подписями к файлам, остальное — документ `mdRich`: заголовки,
  списки, таблицы, цитаты, код) → просмотрщик выбранного файла `viewerHTML` (страница/PDF — окно-песочница, видео, картинка,
  .md/.txt/.csv/.json — оформленным текстом; «Открыть» и «Скачать») → материалы по типам, картинки миниатюрами (`desk.pv`).
