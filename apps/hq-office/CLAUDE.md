# hq-office — CLAUDE.md

Концепт «живого офиса» для `hq.aicex.club`: один `index.html` (Three.js 0.160
через import map с jsDelivr, без сборки). Не задеплоен, в Command Center нет.
Подробности — `README.md`.

- Данные офиса — классический `<script>` с `window.OFFICE_DATA` (config + catalog);
  `window.OFFICE_CONFIG` / `window.AGENT_CATALOG`, если подключены, перекрывают его.
- Модульный скрипт по разделам: планировка → рендер (GTAO + bloom + vignette) →
  текстуры/материалы → навигация (A* по сетке 0,2 м) → здание и мебель →
  риги людей/роботов и позы → класс `Agent` (план действий: walk/do/work/call) →
  экраны на canvas → панель «Команда» → камера и экскурсия → цикл.
- Неподвижная мебель после постройки сливается по материалам (`mergeStatic`);
  всё, что меняется (экраны, стопки бумаг, LED, реквизит с анимацией), помечено
  `userData.keep = true`.
- Проверка без GPU: `?debug&noao` + `__hq.step(секунды)` прокручивает симуляцию.
- UI-строки на русском, идентификаторы и комментарии к коду — как в остальном файле.
