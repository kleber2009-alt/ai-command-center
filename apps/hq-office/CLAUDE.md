# hq-office — CLAUDE.md

Живой офис агентов, вторая версия `hq.aicex.club` → `hq2.aicex.club`. Статика без сборки. Подробности — `README.md`.

- `index.html` — классические скрипты данных (`office.config.js`, `dept-content.js`,
  `agent-content.js` — копии с hq.aicex.club, `tasks.js` — история задач, `works.js` — превью
  и добавки к работам), затем `window.OFFICE_DATA` (тип экрана и цепочки передач агентов для
  визуализации), затем модуль.
- Модуль по разделам: планировка → рендер (GTAO + bloom) → текстуры/материалы →
  навигация (A* по сетке 0,2 м) → здание и мебель → риги и позы → класс `Agent`
  (план действий walk/do/work/call) → экраны на canvas → история задач и досье →
  камера/экскурсия → цикл.
- **Правая панель показывает только реальные задачи из `tasks.js`** — у каждой дата
  и ссылка-доказательство (PR/коммиты на GitHub, артефакт Claude, сайт, файл). Не добавлять
  туда выдуманные задачи; симуляция в 3D — только визуализация.
- «Готовые работы» в досье и вкладка «Работы» в панели собираются из витрины досье и истории
  задач (`collectWorks` в модуле) — новую работу достаточно добавить задачей. `works.js` — добавки
  hq2 поверх копий с hq.aicex.club: превью (`works/`, только публичные страницы), свои блоки работ
  и скиллы агентов.
- `media/` — сжатые копии наших работ из приватной библиотеки `aicex-library` для задач
  (`img/vid/page('media/…')` в `tasks.js`); сторонние демо-ролики наборов скиллов не выкладывать.
  `skills-library.js` — названия скиллов библиотеки и русские карточки тех, что не описаны в досье.
- `tasks.auto.js` пишет только `sync/sync.mjs` (workflow `hq-office-history.yml`: новые PR после
  каждого пуша в `main` и раз в сутки, ссылки из Run workflow). Новые PR руками не добавлять;
  PR из `pr(…)` в `tasks.js` синк пропускает. Задача по ссылке от пользователя — скилл
  `.claude/skills/hq-history`.
- Неподвижная мебель сливается по материалам (`mergeStatic`); всё изменяемое помечено
  `userData.keep = true`.
- Выкладка: `.github/workflows/deploy-hq-office.yml` → релиз в `/opt/hq-office/releases`, `deploy/server.sh`
  переключает `current`, контейнер `aicex-hq-office` в сети `edge`, сайт `/opt/edge/sites/hq-office.caddy`.
- Проверка без GPU: `?debug&noao` + `__hq.step(секунды)`.
