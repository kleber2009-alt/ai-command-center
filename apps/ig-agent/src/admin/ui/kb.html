База знаний в разработке

Сейчас «знания» агента — это system_prompt активной версии в Agents. Responder при каждом ответе подгружает только этот текст; внешних документов / RAG / vector-store не подключено.

Что появится здесь позже

  • Markdown-документы которые загружаются как контекст в responder (примеры успешных диалогов, FAQ, прайс)
  • Эмбеддинги через Qdrant — semantic retrieval по запросу клиента, выдача топ-3 релевантных фрагментов в промпт
  • Учёт «вопросов без ответа» — analyst пометит сообщения с intent=knowledge_gap, чтобы было видно что добавить в KB
  • Версии KB по аналогии с prompt_versions — A/B знаний для разных сегментов аудитории

Сейчас редактируется

Поведение бота правится через active prompt в Agents — там можно создать новую версию, залить в неё нужный текст и активировать. Изменения подхватываются на следующее же входящее сообщение без рестарта.
