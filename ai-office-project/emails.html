7 готовых HTML-писем под полную цепочку: от первого касания до повторной продажи. Скопируй HTML — вставь в Resend / Brevo / Sendpulse / Mailchimp. Подставь свои переменные через {{var}}.

📥 Лид-магнит → День 0 → +1 → +3 → +5 → +7 → +10 → 💰 Покупка

📚 Как подключить в Resend / Brevo / Sendpulse

  1. Resend: создай шаблон в дашборде → вставь HTML из вкладки «HTML-код» → используй {{var}} синтаксис в коде и передавай данные через data в API-вызове
  2. Brevo (Sendinblue): Templates → HTML editor → paste → переменные через {{ contact.NAME }} или {{ params.X }}
  3. Sendpulse: Шаблоны → Создать HTML → вставить → переменные {{var}} работают из коробки
  4. Mailchimp: Templates → Code your own → Paste in code → используй *|FNAME|* для динамических полей (замени {{name}} на *|FNAME|*)
  5. Триггеры: настрой автоматические цепочки — Day 0 на регистрации, +1, +3, +5, +7, +10 по таймеру + условные ветки (купил → стоп цепочки, ушёл → дожим)
