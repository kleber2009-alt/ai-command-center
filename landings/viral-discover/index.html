/02 как устроен конвейер
I
CRON

08:00 МСК каждое утро

Внутренний scheduler разворачивает cron-rule в задачи. Один тик — fan-out на всех юзеров с настроенным конфигом. Падение одного не валит остальных.

schedule_rules · 0 5 * * *
II
SCRAPE

Обходим конкурентов и хэштеги

Apify-actor забирает посты за последние 7 дней с каждого источника. По 25 на источник, до десятков аккаунтов на профиль. Никакого ручного логина в IG.

apify · instagram-scraper
III
RANK

Считаем velocity

Каждый пост классифицируется (рилс / карусель / single), считаются views/h, engagement/h и ratio. Composite-score берёт топ-5 каждого типа.

lib/scoring.js · composite norm
IV
SCORE + DELIVER

Claude и в Telegram

Топ-10 уходит в Claude с описанием твоей ниши. На выходе — оценка 1–10 и одно предложение почему. Отдельным сообщением с кнопками ✅/❌ в TG.

claude-haiku · sendDeliverable
/03 из чего складывается рейтинг
01
Velocityскорость набора
Не «сколько собрал», а как быстро. Просмотры и engagement делятся на возраст поста — старые залётчики не попадают в выдачу. Свежий пост, который набирает +10K/час, обгоняет недельный «миллионник».
reels = 0.55·views/h + 0.30·eng/h + 0.15·eng_ratio
carousels = 0.70·eng/h + 0.30·likes_total
02
Classifyчто это вообще
Apify отдаёт сырые items без разделения. Мы по productType и type определяем тип контента, фильтруем мусор (картинки-обложки, репосты, истории), дедуплицируем по URL.
reel ← productType=clips · type=Video
carousel ← type=Sidecar
image ← type=Image (skip)
03
Fit-score«а у меня зайдёт?»
Velocity показывает что взлетело у конкурента. Fit-score — что подойдёт тебе. Claude читает описание твоей ниши и для каждого поста ставит 1–10 + одно предложение причины. Никаких размытых «может быть».
claude-haiku · strict JSON
{ idx, score: 1–10, why: 6–12 слов }

/06 частые вопросы
/01 А TikTok? YouTube Shorts? +
Сейчас только Instagram (reels + carousels). Это сознательное решение: у инфобизнес-ниши русскоязычного сегмента 80%+ контента живёт именно там. TikTok/Shorts в roadmap — но это отдельный actor и отдельная классификация, добавим когда дойдёт спрос.
/02 Это легально? Что про IG ToS? +
Парсер не логинится в твой аккаунт и не делает действий от твоего имени. Это публичные посты публичных аккаунтов, которые ты сам выбрал — фактически то же что ручной просмотр через браузер, только автоматизированный. Сервис не качает видео и не публикует ничего — отдаёт только ссылки и метрики. Клонирование (/clone) — отдельный процесс, и переписывает сценарий через Claude, чтобы не было плагиата.
/03 Сколько аккаунтов и хэштегов можно добавить? +
Технически — без ограничений. Реально — 5–8 аккаунтов и 2–4 хэштега — оптимум: больше и сигнал размывается, выдача начинает повторяться. Управляешь командами /add @acc · /add #tag и /remove прямо в чате с ботом (или через /menu).
/04 Что если у меня нет нишевого описания? +
Без описания Claude не сможет ставить fit-score — выдача придёт без оценок, только velocity-рейтинг. Ниша задаётся в wizard'е сразу после /start (или потом командой /niche) одной строкой: «коуч по продажам B2B для собственников малого бизнеса» — этого достаточно. Можно менять в любой момент.
/05 Я могу пропускать дни? Останавливать на время? +
Да. Команда /pause ставит на паузу, /resume возобновляет. На отпуск, во время фокус-недель, в любой момент. Подписка при этом продолжает действовать — это просто переключатель.
/06 Можно ли получать в другое время, не в 8:00? +
В первой версии — нет, время фиксировано на 08:00 МСК. Но в любой момент можно форсить вручную командой /discover — выдача придёт через 1–3 минуты. Кастомное время доставки — в roadmap на ближайшие недели.
