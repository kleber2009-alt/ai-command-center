# Продающий сайт «Нейроворонка» — neuro.aicex.club

Собран агентом «Лендинг» офиса Нейроворонки (hq2.aicex.club/?theme=neuro, задача desk-adbae78b, 05.11) из артефакта
Claude. Одна страница + `oferta.html`, `soglasie.html`, `privacy.html`, картинки в `img/`. Выкладка —
`.github/workflows/deploy-neuro-landing.yml` при пуше в main (контейнер `aicex-neuro-landing`, сайт `/opt/edge/sites/neuro-landing.caddy`).

Всё, что меняется к запуску, — блок `var NF` в конце `index.html`:
- `price` — тарифы (решение 05.11: «Уроки» 14 900 ₽, «Уроки + поддержка» 34 900 ₽);
- `text` — строки из оферты (график уроков, поддержка, доступ, возврат);
- `deadline` — конец окна набора, таймер (16.11 23:59 МСК);
- `pay` — ссылки на оплату: **пусто, пока не прошла тестовая покупка с чеком 54-ФЗ** (стоп-условие дорожной карты);
- `bot` — ссылка на бота: включается вместе с цепочкой бота Нейроворонки.

Пустая ссылка не ломает страницу: кнопка ведёт к тарифам или программе. Метка источника `nf-…` берётся из
`utm_content` или `start` и уходит дальше в ссылки оплаты и бота (сквозная аналитика кабинета).
Оферта, согласие и политика сейчас — заготовки с реквизитами ИП; текст оферты готовит агент «Оферта и юридический контур».
